# 扩展方法

JBaseLibrary 提供了丰富的扩展方法，覆盖字符串、日期、集合、对象、类型、LINQ 等常用场景。所有扩展方法位于 `JBaseLibrary.Extensions` 命名空间。

## 1. StringExtensions - 字符串扩展

### 1.1 空值判断

```csharp
string str = null;

// 判断是否为空
str.IsNullOrEmpty();      // true
str.IsNotNullOrEmpty();  // false

// 判断是否为空或仅包含空白
str.IsNullOrWhiteSpace();     // true
str.IsNotNullOrWhiteSpace(); // false
```

### 1.2 字符串截取

```csharp
"HelloWorld".Left(5);   // "Hello" - 从左边截取5个字符
"HelloWorld".Right(5);  // "World" - 从右边截取5个字符

// 带省略号
"HelloWorld".Left(5, "...");  // "Hello..."
```

### 1.3 正则匹配

```csharp
"abc123".IsMatch(@"\d+");           // true - 包含数字
"abc123".IsMatch(@"^[a-z]+$");        // false - 不是纯字母

// 忽略大小写
"ABC".IsMatch("abc", RegexOptions.IgnoreCase);  // true
```

### 1.4 字符串转枚举

```csharp
// 转枚举
"Active".ToEnum<Status>();           // Status.Active
"active".ToEnum<Status>(ignoreCase: true);  // Status.Active
```

### 1.5 字符串分割

```csharp
// 分割并去空格
"a, b, c".SplitAndTrim(',');       // ["a", "b", "c"]
"a;b;c".SplitAndTrim(';');          // ["a", "b", "c"]

// 指定多个分隔符
"a,b;c|d".SplitAndTrim(',', ';', '|');  // ["a", "b", "c", "d"]
```

### 1.6 文件名/路径验证

```csharp
"file.txt".IsValidFileName();   // true
"file<.txt".IsValidFileName();  // false - 包含非法字符

"C:\\folder".IsValidPathName();  // true
```

### 1.7 字符串转换

```csharp
// 日期格式转换
"20240101".ToFormatDateString("yyyyMMdd", "yyyy-MM-dd");  // "2024-01-01"

// 字符串转布尔值
"true".ToBool();   // true
"yes".ToBool();    // true
"1".ToBool();      // true
"否".ToBool();     // false

// 阿拉伯数字转中文数字
"123".ToChineseNumber();  // "一二三"
```

### 1.8 其他方法

```csharp
// 重复字符串
"ab".Repeat(3);  // "ababab"

// 首字母大写/小写
"hello".FirstUpperCase();  // "Hello"
"Hello".FirstLowerCase();  // "hello"

// 字符串格式化
"Hello, {0}".Format("World");  // "Hello, World"
"Hello, {name}".Render(new { name = "World" });  // "Hello, World"

// 判断 JSON
"{ \"name\": \"test\" }".IsJson();  // true

// JSON 渲染模板
"Hello, {name}".Render(new { name = "张三" });  // "Hello, 张三"
```

## 2. DateTimeExtensions - 日期扩展

### 2.1 日期判断

```csharp
var date = new DateTime(2024, 4, 15);

// 日期范围判断
date.IsBetween(startDate, endDate);              // 是否在范围内
date.IsBetween(startDate, endDate, compareTime: true);  // 包含时间比较

// 周末/工作日
date.IsWeekend();   // true (周六)

// 闰年
date.IsLeapYear();  // false

// 月末
date.IsLastDayOfTheMonth();  // false
```

### 2.2 日期差异

```csharp
var start = new DateTime(2024, 1, 1);
var end = new DateTime(2024, 4, 15);

// 相差天数
start.DiffDays(end);       // 105

// 相差小时
start.DiffHours(end);      // 2520

// 相差分钟
start.DiffMinutes(end);    // 151200

// 相差秒
start.DiffSeconds(end);    // 9072000

// 相差月数
start.DiffMonths(end);     // 3
```

### 2.3 日期格式

```csharp
var date = DateTime.Now;

// 常用格式
date.ToCommonString();        // "2024-04-15 10:30:45"
date.ToCommonDateString();    // "2024-04-15"
date.ToCommonTimeString();    // "10:30:45"
date.ToCommonStampString();   // "2024-04-15 10:30:45.123"

// 中文格式
date.Week();                 // "星期一"
date.DateToUpper();          // "二〇二四年四月十五日"

// 自定义格式
date.ToCommonDateString("yyyy年MM月dd日");  // "2024年04月15日"
```

### 2.4 时间戳转换

```csharp
var date = DateTime.Now;

// DateTime -> 时间戳
date.ToUnixTimeSeconds();      // 10位时间戳: 1713153600
date.ToUnixTimeMilliseconds();  // 13位时间戳: 1713153600000

// 时间戳 -> DateTime
var ts = 1713153600;
ts.FromUnixTimeSeconds();      // DateTime

var tsMs = 1713153600000;
tsMs.FromUnixTimeMilliseconds();  // DateTime
```

### 2.5 年龄计算

```csharp
var birthday = new DateTime(2000, 4, 15);
birthday.Age();  // 24（当前日期为2024年）
```

## 3. NumericExtensions - 数值扩展

### 3.1 金额转换

```csharp
// 元 -> 万元
10000m.YuanToWY();    // 1m
10000m.YuanToWY(2);    // 1.00m

// 万元 -> 元
1m.WYuanToY();        // 10000m
1.5m.WYuanToY();      // 15000m
```

### 3.2 小数处理

```csharp
// 去除尾随零
123.4500m.TrimZero();    // 123.45
0.1000m.TrimZero();      // 0.1

// 设置小数位数（截取）
123.456789m.SetDigits(2);  // 123.45

// 四舍五入
123.456789m.RoundTo(2);    // 123.46
```

### 3.3 百分比

```csharp
// 小数转百分比
0.9535.ToPercentage();           // "95.35%"
0.9535.ToPercentage(1);         // "95.4%"

// 可空类型
((decimal?)0.9535).ToPercentage();  // "95.35%"
((decimal?)null).ToPercentage();     // "-"

// 两个数相除转百分比
int passed = 85;
int total = 100;
passed.ToPercentage(total);  // "85.00%"
```

### 3.4 数字转中文

```csharp
// 数字转中文格式
123.NumberToUpper();           // "一百二十三"
12345.NumberToUpper();         // "一万二千三百四十五"

// 金额转中文大写
165.7m.MoneyToUpper();        // "壹佰陆拾伍点柒"
1234.56m.MoneyToUpper();      // "壹仟贰佰叁拾肆点伍陆"

// 月/日转大写
4.MonthToUpper();              // "四"
12.MonthToUpper();              // "十二"
15.DayToUpper();               // "十五"
```

### 3.5 时间格式化

```csharp
// 秒转时间格式
3661.FormatSeconds();  // "1小时1分1秒"
60.FormatSeconds();    // "1分0秒"
3600.FormatSeconds();  // "1小时0分0秒"
```

## 4. ObjectExtensions - 对象扩展

### 4.1 类型转换（ObjTo）

```csharp
// 基础类型转换
"123".ObjTo<int>();           // 123
"true".ObjTo<bool>();         // true
"2024-01-01".ObjTo<DateTime>();

// 枚举转换
"Active".ObjTo<Status>();
123.ObjTo<Status>();

// 可空类型
"123".ObjTo<int?>();         // 123
null.ObjTo<int?>();           // null
```

### 4.2 对象深拷贝

```csharp
var user = new User { Name = "张三", Age = 25 };
var copy = user.Clone();  // 深拷贝，修改 copy 不会影响 user
```

### 4.3 对象属性 Trim

```csharp
var user = new User { Name = "  张三  ", Address = "北京  " };
user.ObjToTrim();  // Name = "张三", Address = "北京"
```

### 4.4 对象转字典

```csharp
var user = new User { Name = "张三", Age = 25 };
var dict = user.ToDictionary();
// dict: { "Name": "张三", "Age": 25 }
```

### 4.5 DTO 属性映射（ModifyByDto）

```csharp
var entity = new User { Id = 1, Name = "张三", Age = 25, CreateTime = DateTime.Now };
var dto = new { Name = "李四", Age = 30 };

entity.ModifyByDto(dto);
// entity.Name = "李四"
// entity.Age = 30
// entity.CreateTime 不变
```

### 4.6 类型判断

```csharp
obj.IsNumeric();   // 是否数字类型
obj.IsEnum();     // 是否枚举类型
obj.IsNullOrDBNull();  // 是否 null 或 DBNull
```

## 5. IEnumerableExtensions - 集合扩展

### 5.1 空值判断

```csharp
list.IsNullOrEmpty();      // 是否为 null 或空
list.IsNotNullOrEmpty();   // 是否不为 null 且不为空
```

### 5.2 条件筛选

```csharp
// 条件筛选
var result = list.WhereIf(x => x.Status == 1, isActive);
// 当 isActive=true 时执行筛选，为 false 时返回原集合
```

### 5.3 分页

```csharp
// 内存集合分页
var page = list.GetPage(1, 10);  // 第1页，每页10条
```

### 5.4 批量处理

```csharp
// 将集合分段
foreach (var batch in list.Batch(100))
{
    // 每批处理 100 条
}
```

### 5.5 集合比较

```csharp
// 获取差异
var (added, removed) = newList.GetDiff(oldList);
// added: 新增的
// removed: 删除的

// 判断是否包含
listA.IsContains(listB);  // listA 是否包含 listB 的所有元素
```

### 5.6 树形结构

```csharp
// 转为树形结构
var tree = list.ToTree(
    (a, b) => b.ParentId == 0,  // 根节点条件
    (a, b) => a.Id == b.ParentId,  // 父子关系
    (parent, children) => parent.Children = children.ToList()  // 添加子节点
);
```

### 5.7 转换为 DataTable

```csharp
var dt = list.ToDataTable();
```

### 5.8 其他方法

```csharp
// 遍历执行
list.ForEach(x => Console.WriteLine(x));

// 随机选择
var random = list.SelectRandom();

// 集合拼接
var str = list.ToStringSeparated(",");  // "a,b,c"
```

## 6. ListExtensions - 列表扩展

### 6.1 添加集合

```csharp
list.Add(item1, item2, item3);
list.AddRange(otherList);
```

### 6.2 移除元素

```csharp
list.Remove(x => x.Status == 0);  // 移除符合条件的元素
```

### 6.3 集合比较

```csharp
// 集合比较
list1.ListComparator(list2);  // 默认要求顺序一致
list1.ListComparator(list2, byOrder: false);  // 不要求顺序
```

## 7. ArrayExtensions - 数组扩展

```csharp
var arr = new[] { 1, 2, 3, 4, 5 };

// 添加数组
var newArr = arr.AddRange(new[] { 6, 7 });

// 移除元素
var filtered = arr.Remove(x => x > 3);  // {1, 2, 3}
```

## 8. DictionaryExtensions - 字典扩展

### 8.1 获取或添加

```csharp
dict.GetOrAdd(key, value);  // 键不存在时添加
dict.GetOrAdd(key, () => ComputeValue());  // 延迟计算
dict.GetOrDefault(key, defaultValue);  // 键不存在时返回默认值
```

### 8.2 字典转实体

```csharp
var dic = new Dictionary<string, object>
{
    { "Name", "张三" },
    { "Age", 25 }
};
var user = dic.ToModel<User>();
```

## 9. LinqExtensions - LINQ 扩展

### 9.1 批量排序

```csharp
// 多字段排序，字段前加 "-" 表示降序
var result = list.OrderByBatch("Name,-Age,CreateTime");
// 等同于: OrderBy(Name).ThenByDescending(Age).ThenBy(CreateTime)
```

### 9.2 单字段排序

```csharp
list.OrderBy("Name");           // 正序
list.OrderByDescending("Name");  // 倒序
list.ThenBy("Age");             // 继续正序
list.ThenByDescending("Age");    // 继续倒序
```

## 10. IQueryableExtensions - 查询扩展

```csharp
// 条件查询
query.And(x => x.Status == 1);
query.And(true, x => x.Name.Contains("张"));
```

## 11. ExpressionExtensions - 表达式扩展

```csharp
// 组合表达式
Expression<Func<User, bool>> exp1 = x => x.Status == 1;
Expression<Func<User, bool>> exp2 = x => x.Age > 18;

var combined = exp1.CusAnd(exp2);  // x => x.Status == 1 && x.Age > 18
var combined2 = exp1.CusOr(exp2);  // x => x.Status == 1 || x.Age > 18

// 条件组合
exp1.CusAnd(true, exp2);  // 条件为 true 时才组合
exp1.CusOr(false, exp2);   // 条件为 false 时不组合

// 取反
exp1.CusNot();  // x => !(x.Status == 1)
```

## 12. TypeExtensions - 类型扩展

```csharp
// 类型判断
typeof(string).IsSimpleType();      // true
typeof(User).IsNullable();            // false
typeof(int?).IsNullable();           // true
typeof(int[]).IsArrayOf<int>();     // true
typeof(List<string>).IsGenericList(); // true

// 获取类型代码
typeof(int).GetTypeCode();  // TypeCode.Int32

// 获取默认值
typeof(int).GetDefault();  // 0
```

## 13. UriExtensions - URI 扩展

```csharp
var uri = new Uri("https://example.com/path");

// 解析查询参数
foreach (var param in uri.ParseQueryString())
{
    Console.WriteLine($"{param.Key}: {param.Value}");
}

// 添加查询参数
var newUri = uri.AddParametersToQueryString("page", "1");
var newUri2 = uri.AddParametersToQueryString(new Dictionary<string, string>
{
    { "page", "1" },
    { "size", "10" }
});
```

## 14. EnumExtensions - 枚举扩展

```csharp
public enum Status { Active = 1, Inactive = 2 }

var status = Status.Active;

// 获取描述
status.ToDescription();  // 如果有 DescriptionAttribute 返回描述，否则返回枚举名

// 转为下拉列表
var list = status.ToKeyValueList<Status>();
// [(1, "Active"), (2, "Inactive")]

// Flags 枚举判断
[Flags]
public enum Permissions { Read = 1, Write = 2, Delete = 4 }

var perms = Permissions.Read | Permissions.Write;
perms.Contains(Permissions.Read);     // true
perms.Contains(Permissions.Delete);  // false
perms.ContainsAny(Permissions.Write); // true
```
