# 扩展方法

JBaseLibrary 提供了丰富的扩展方法，覆盖字符串、日期、集合、对象、类型、LINQ、JSON、字典、任务、文件、Excel 等常用场景。所有扩展方法位于 `JBaseLibrary.Extensions` 命名空间。

## 1. StringExtensions - 字符串扩展

### 1.1 空值判断

```csharp
string str = null;

// 判断是否为空
str.IsNullOrEmpty();      // true
str.IsNotNullOrEmpty();   // false

// 判断是否为空或仅包含空白
str.IsNullOrWhiteSpace();      // true
str.IsNotNullOrWhiteSpace();  // false
```

### 1.2 字符串截取

```csharp
// 从左边截取
"HelloWorld".Left(5);             // "Hello"
"HelloWorld".Left(5, "...");      // "Hello..."

// 从右边截取
"HelloWorld".Right(5);            // "World"
```

> `Left`/`Right` 都会校验长度，若 `len > str.Length` 会抛 `ArgumentException`。

### 1.3 正则匹配

```csharp
// 是否匹配正则
"abc123".IsMatch(@"\d+");                          // true
"abc123".IsMatch(@"^[a-z]+$");                     // false

// 忽略大小写
"ABC".IsMatch("abc", RegexOptions.IgnoreCase);     // true
```

### 1.4 字符串转枚举

```csharp
// 转枚举（区分大小写）
"Active".ToEnum<Status>();                  // Status.Active

// 忽略大小写
"active".ToEnum<Status>(ignoreCase: true);  // Status.Active
```

### 1.5 字符串分割

```csharp
// 字符串数组（去前后空格 + 去空项）
"a, b, c".SplitAndTrim(',');                // ["a", "b", "c"]
"a;b;c".SplitAndTrim(';');                  // ["a", "b", "c"]

// 指定多个分隔符（char 或 string 重载）
"a,b;c|d".SplitAndTrim(',', ';', '|');      // ["a", "b", "c", "d"]
"a,b;c".SplitAndTrim(",", ";");             // ["a", "b", "c"]

// 转换为指定类型集合
"1,2,3".SplitAndTrim<int>(',');             // [1, 2, 3]
```

### 1.6 文件名/路径验证

```csharp
"file.txt".IsValidFileName();      // true
"file<.txt".IsValidFileName();     // false - 包含非法字符
"C:\\folder".IsValidPathName();    // true
```

### 1.7 字符串转换

```csharp
// 日期格式转换
"20240101".ToFormatDateString("yyyyMMdd", "yyyy-MM-dd");  // "2024-01-01"

// 字符串转布尔值（true|yes|ok|1|是 不区分大小写都返回 true）
"true".ToBool();    // true
"yes".ToBool();     // true
"1".ToBool();       // true
"否".ToBool();      // false

// 阿拉伯数字转中文数字（字符级替换 0-9 → 零-九）
"123".ToChineseNumber();  // "一二三"
```

### 1.8 重复与首字母大小写

```csharp
// 重复字符串（count<=1 直接返回原串）
"ab".Repeat(3);             // "ababab"

// 首字母大小写
"hello".FirstUpperCase();   // "Hello"
"Hello".FirstLowerCase();   // "hello"
```

### 1.9 字符串格式化

```csharp
// String.Format 简化
"Hello, {0}".Format("World");              // "Hello, World"

// Render 模板渲染（按属性名替换占位符，参数忽略大小写）
"Hello, {name}".Render(new { name = "World" });  // "Hello, World"
"Hi {Name}, age={age}".Render(new { name = "张三", age = 18 });  // "Hi 张三, age=18"
```

### 1.10 字符串结束判断

```csharp
// 是否以指定字符串结尾（Ordinal 比较）
"file.txt".EndsWith(".txt");                // true
"file.TXT".EndsWith(".txt");                // false

// 忽略大小写
"file.TXT".EndsWith(".txt", ignoreCase: true);  // true
```

### 1.11 JSON 判断

```csharp
// 仅判断首尾是否为 {} 或 []
"{ \"name\": \"test\" }".IsJson();    // true
"[1, 2, 3]".IsJson();                  // true
"not json".IsJson();                   // false
```

## 2. DateTimeExtensions - 日期扩展

### 2.1 日期判断

```csharp
var date = new DateTime(2024, 4, 15);

// 日期范围判断
date.IsBetween(startDate, endDate);                     // 只比较日期部分
date.IsBetween(startDate, endDate, compareTime: true); // 同时比较时间

// 周末/工作日
date.IsWeekend();         // true（周六/周日）
date.IsLeapYear();        // false
date.IsLastDayOfTheMonth();   // false
```

### 2.2 日期差异

```csharp
var start = new DateTime(2024, 1, 1);
var end = new DateTime(2024, 4, 15);

start.DiffDays(end);       // 105
start.DiffHours(end);      // 2520
start.DiffMinutes(end);    // 151200
start.DiffSeconds(end);    // 9072000
start.DiffMonths(end);     // 3（不足一月不算）

// 月、天差（元组）
var (month, day) = start.DiffMonthAndDay(end);  // (3, 14)
```

### 2.3 日期格式

```csharp
var date = DateTime.Now;

date.ToCommonString();        // "2024-04-15 10:30:45"
date.ToCommonDateString();    // "2024-04-15"
date.ToCommonTimeString();    // "10:30:45"
date.ToCommonStampString();   // "2024-04-15 10:30:45.123"

// 中文格式
date.Week();                  // "星期一"
date.DateToUpper();           // "二〇二四年四月十五日"

// 自定义格式（ToCommonDateString 支持 format 参数）
date.ToCommonDateString("yyyy年MM月dd日");  // "2024年04月15日"
```

### 2.4 时间戳转换

```csharp
// DateTime -> 时间戳
date.ToUnixTimeSeconds();      // 10 位时间戳
date.ToUnixTimeMilliseconds(); // 13 位时间戳

// 时间戳 -> DateTime
1713153600.FromUnixTimeSeconds();         // DateTime
1713153600000.FromUnixTimeMilliseconds(); // DateTime

// 通用转换（自动识别 10/13 位）
new DateTime(1970,1,1).AddSeconds(ts).ToLocalTime();
// 或者使用 long 扩展
1745328000L.ConvertToDateTime();
```

### 2.5 年龄计算

```csharp
var birthday = new DateTime(2000, 4, 15);
int age = birthday.Age();  // 25（当前日期为 2026 年）
```

### 2.6 DateTime / DateTimeOffset 互转

```csharp
DateTimeOffset offset = DateTime.Now.ConvertToDateTimeOffset();
DateTime dt = offset.ConvertToDateTime();  // 转换回本地 DateTime
```

## 3. NumericExtensions - 数值扩展

### 3.1 金额转换（元 ↔ 万元）

```csharp
// 元 -> 万元
10000m.YuanToWY();      // 1m
10000m.YuanToWY(2);     // 1.00m（保留2位小数）
100m.YuanToWY(2);       // 0.01m

// 万元 -> 元
1m.WYuanToY();          // 10000m
1.5m.WYuanToY();        // 15000m
1.234m.WYuanToY(2);     // 12340m

// 可空类型
((decimal?)10000m).YuanToWY();   // 1m
```

### 3.2 小数处理

```csharp
// 去除尾随零
123.4500m.TrimZero();     // 123.45
0.1000m.TrimZero();       // 0.1
123.0000m.TrimZero();     // 123
0m.TrimZero();            // 0

// 设置小数位数（截取，不四舍五入）
123.456789m.SetDigits(2); // 123.45

// 四舍五入（MidpointRounding.AwayFromZero）
123.456789m.RoundTo(2);   // 123.46
```

### 3.3 百分比

```csharp
// 小数转百分比
0.9535.ToPercentage();        // "95.35%"
0.9535.ToPercentage(1);      // "95.4%"

// 可空类型（null 显示 "-"）
((decimal?)0.9535).ToPercentage();  // "95.35%"
((decimal?)null).ToPercentage();    // "-"

// 两个数相除转百分比
int passed = 85, total = 100;
passed.ToPercentage(total);         // "85.00%"
85L.ToPercentage(100L);             // "85.00%"
```

### 3.4 数字转中文

```csharp
// 数字转中文格式（口语化）
123.NumberToUpper();       // "一百二十三"
12345.NumberToUpper();     // "一万二千三百四十五"
1234.56m.NumberToUpper();  // "一千二百三十四点五六"

// 金额转中文大写（财务大写）
165.7m.MoneyToUpper();     // "壹佰陆拾伍点柒"
1234.56m.MoneyToUpper();   // "壹仟贰佰叁拾肆点伍陆"

// 月/日转大写
4.MonthToUpper();          // "四"
12.MonthToUpper();         // "十二"
15.DayToUpper();           // "十五"

// 数字按位转大写（10 -> 一〇）
10.NumToUpper();            // "一〇"
123.NumToUpper();           // "一二三"
```

### 3.5 时间格式化

```csharp
// 秒转时间格式（输入必须 ≥ 0）
3661.FormatSeconds();  // "1小时1分1秒"
60.FormatSeconds();    // "1分0秒"
3600.FormatSeconds();  // "1小时0分0秒"
```

## 4. ObjectExtensions - 对象扩展

### 4.1 类型转换（ObjTo）

高性能、强类型转换，底层使用预热字典 + 表达式树编译缓存。

```csharp
// 基础类型转换
"123".ObjTo<int>();              // 123
"true".ObjTo<bool>();            // true
"2024-01-01".ObjTo<DateTime>();
123.ObjTo<string>();             // "123"

// 失败处理（默认返回 default；useDefault=false 时抛异常）
"abc".ObjTo<int>();              // 0（默认）
"abc".ObjTo<int>(useDefault: false);  // 抛 InvalidCastException

// 自定义默认值
"abc".ObjTo<int>(defaultValue: 99);  // 99

// 枚举转换
"Active".ObjTo<Status>();        // Status.Active（自动识别大小写）
123.ObjTo<Status>();             // Status.Active（按 int 值转换）

// 可空类型
"123".ObjTo<int?>();             // 123
((object)null).ObjTo<int?>();    // null
DBNull.Value.ObjTo<int?>();      // null

// 重载版本（直接指定目标类型）
((object)"123").ObjTo(typeof(int));   // 123
((object)DateTime.Now).ObjTo(typeof(DateTimeOffset));
```

### 4.2 对象深拷贝（基于 JSON）

```csharp
var user = new User { Name = "张三", Age = 25 };
var copy = user.Clone();  // 深拷贝（基于 Newtonsoft.Json）
```

### 4.3 对象属性 Trim

```csharp
var user = new User { Name = "  张三  ", Address = "北京  " };
user.ObjToTrim();  // Name="张三", Address="北京"
// 仅处理可写的 string 类型属性
```

### 4.4 对象转字典

```csharp
var user = new User { Name = "张三", Age = 25 };
var dict = user.ToDictionary();              // {"Name": "张三", "Age": 25}

// 重载（控制是否包含私有属性、是否小写 key）
var dict2 = user.ToDictionary(inherit: true, includePrivate: false, keyIsLower: false);
```

### 4.5 DTO 属性映射（ModifyByDto）

`ModifyByDto` 基于同名属性进行映射（`entity.ModifyByDto(dto)` 会修改 `entity` 的属性值）。底层使用表达式树编译 + 缓存。

```csharp
var entity = new User { Id = 1, Name = "张三", Age = 25, CreateTime = DateTime.Now };
var dto = new { Name = "李四", Age = 30 };

entity.ModifyByDto(dto);
// entity.Name = "李四"
// entity.Age = 30
// entity.CreateTime 不变
// entity.Id 不变
```

行为说明：

- `dto` 为 `null` 直接返回 `entity`；
- `entity` 与 `dto` 类型相同，直接返回 `dto`（不修改）；
- 属性值相等时不改变；
- 集合类型直接覆盖；
- 引用类型递归修改。

### 4.6 类型判断

```csharp
obj.IsNumeric();         // 是否数字类型
obj.IsEnum();            // 是否枚举类型
obj.IsNullOrDBNull();    // 是否 null 或 DBNull
```

## 5. JsonExtensions - JSON 扩展

基于 Newtonsoft.Json，默认日期格式 `yyyy-MM-dd HH:mm:ss`，忽略循环引用，开启 `Indent` 格式化。

### 5.1 序列化

```csharp
// 默认格式
var json = user.ToJson();
// {"Name":"张三","Age":25}

// 自定义日期格式
var json2 = user.ToJson("yyyy/MM/dd");

// 自定义 JsonSerializerSettings
var settings = new JsonSerializerSettings { ... };
var json3 = user.ToJson(settings);
```

### 5.2 反序列化

```csharp
// 反序列化为 object
object obj = json.ToObject();

// 反序列化为指定类型
var user = json.ToObject<User>();

// 反序列化为 List<T>
var list = jsonStr.ToList<User>();

// 反序列化为 DataTable
var dt = jsonStr.ToTable();

// 反序列化为 Newtonsoft 的 JObject（自动去除 &nbsp;）
var jobj = jsonStr.ToJObject();
```

## 6. IEnumerableExtensions - 集合扩展

### 6.5 集合比较

## 12. ExpressionExtensions - 表达式扩展

支持 1~5 个泛型参数的重载（`T1`、`T1,T2`...`T1,T2,T3,T4,T5`），每个参数都提供 And / Or / Not 三种方法。

```csharp
Expression<Func<User, bool>> exp1 = x => x.Status == 1;
Expression<Func<User, bool>> exp2 = x => x.Age > 18;

// AND 拼接
var combined = exp1.CusAnd(exp2);       // x => x.Status == 1 && x.Age > 18

// 条件 AND
var combined2 = exp1.CusAnd(true, exp2);   // 等同上面
var combined3 = exp1.CusAnd(false, exp2);  // 等同 exp1

// OR 拼接
var combined4 = exp1.CusOr(exp2);        // x => x.Status == 1 || x.Age > 18

// 取反
var reversed = exp1.CusNot();            // x => !(x.Status == 1)
```

## 13. TypeExtensions - 类型扩展

### 13.1 属性获取

```csharp
if (typeof(User).TryGetInstanceProperty("Name", out var prop)) { ... }

typeof(User).GetPropertiesWithAttribute<DisplayNameAttribute>();
typeof(User).GetAttributeToPropertyMapping<DisplayNameAttribute>();  // 特性->属性 字典

typeof(User).TryGetAttributes<DisplayNameAttribute>(out var attrs);
```

### 13.2 泛型信息

```csharp
if (typeof(Dictionary<string, object>).TryGetGenericArguments(out Type[] args))

    // args = [typeof(string), typeof(object)]
}
```

### 13.3 类型判断


## 22. TreeExtensions - 树形结构扩展

> ⚠️ 本节与 [IEnumerableExtensions.ToTree](#68-转换为树形结构) 都能构建树，但本节的 API 更专业、功能更丰富（支持 `FilterTree` 树过滤、`RecurseTree` 深度遍历、`ToFlat` 树扁平化）。要求 `T` 实现 `ITreeStruct<T>` 或显式提供 `Children` 属性表达式。

### 22.1 TreeNode\<T\> - 通用树节点

```csharp
public sealed class TreeNode<T>
{
    public T Data { get; }                      // 节点数据
    public TreeNode<T>[] Children { get; }      // 子节点数组
    public TreeNode(T data, TreeNode<T>[] children);
}
```

### 22.2 ITreeStruct\<T\> - 树结构接口

```csharp
public interface ITreeStruct<T>
{
    T Self { get; set; }              // 当前节点
    T Parent { get; set; }            // 父节点
    ICollection<T> Children { get; set; }   // 子节点集合
}
```

### 22.3 ToTree - 转换为 TreeNode\<T\>

基于 Id / ParentId 关系构建树。返回 `TreeNode<T>[]`：

```csharp
public class Category
{
    public int Id { get; set; }
    public int ParentId { get; set; }
    public string Name { get; set; }
}

var categories = new List<Category>
{
    new Category { Id = 1, ParentId = 0, Name = "根1" },
    new Category { Id = 2, ParentId = 1, Name = "子1" },
    new Category { Id = 3, ParentId = 1, Name = "子2" }
};

// 重载 1：使用 rootId 标识根节点（默认 TId 的默认值）
TreeNode<Category>[] tree = categories.ToTree(
    c => c.Id, c => c.ParentId,
    rootId: 0);

// 重载 2：使用 isRoot 谓词
TreeNode<Category>[] tree2 = categories.ToTree(
    c => c.Id, c => c.ParentId,
    isRoot: c => c.ParentId == 0);
```

### 22.4 FetchToTree - 转换为 List\<T\>

**直接修改 `T` 上的 `Children` 属性**（要求 `T` 实现 `ITreeStruct<T>` 或显式提供 `childrenSelectorExpression`）：

```csharp
// 重载 1：要求 T 实现 ITreeStruct<T>
public class Menu : ITreeStruct<Menu>
{
    public int Id { get; set; }
    public int ParentId { get; set; }
    public string Name { get; set; }
    public Menu Self { get; set; }
    public Menu Parent { get; set; }
    public ICollection<Menu> Children { get; set; }
}

List<Menu> menuTree = menus.FetchToTree(
    m => m.Id, m => m.ParentId,
    isRoot: m => m.ParentId == 0,
    sortSelector: m => m.OrderIndex,
    orderAsc: true);

// 重载 2：使用表达式指定 Children 属性
List<Category> categoryTree = categories.FetchToTree(
    c => c.Id, c => c.ParentId,
    childrenSelectorExpression: c => c.SubCategories,   // 显式提供 children 属性
    isRoot: c => c.ParentId == 0,
    sortSelector: c => c.Sort);
```

> 与 `ToTree` 的区别：`FetchToTree` 会**直接修改** `T` 的 `Children` 属性，返回 `List<T>`（不是包装的 `TreeNode<T>`），可与 ORM 实体直接配合。

### 22.5 ToFlat - 树扁平化

把树形结构展开为平铺列表（深度优先）：

```csharp
public static List<T> ToFlat<T>(this IEnumerable<T> srcArr,
                                Expression<Func<T, IEnumerable<T>>> childrenSelectorExpression,
                                TreeToFlatAction treeToFlatAction = TreeToFlatAction.None)
```

`TreeToFlatAction` 控制子节点引用如何处理：

| 值 | 行为 |
|----|------|
| `None` | 保留子节点引用 |
| `SetEmpty` | 子节点设为空集合（`Clear()`） |
| `SetNull` | 子节点设为 `null` |
| `SetEmptyCollection` | 子节点设为新的 `T[0]`（数组形式） |

```csharp
// 平铺（保留子节点）
List<Category> flat = tree.ToFlat(c => c.SubCategories);

// 平铺并清空子节点
List<Category> flatEmpty = tree.ToFlat(c => c.SubCategories, TreeToFlatAction.SetEmpty);

// 平铺并置空子节点
List<Category> flatNull = tree.ToFlat(c => c.SubCategories, TreeToFlatAction.SetNull);
```

### 22.6 FilterTree - 树过滤

```csharp
public static List<T> FilterTree<T>(this IList<T> tree,
                                    Func<T, IList<T>> childrenSelector,
                                    Predicate<T> filterExpression,
                                    bool withAllChildren = false,
                                    bool withAllParents = true)
```

> ⚠️ **会直接修改原集合**（`tree.RemoveAt` / `tree.AddRange`）。

参数说明：

| 参数 | 说明 |
|------|------|
| `tree` | 树根节点集合（会被修改） |
| `childrenSelector` | 获取子节点集合 |
| `filterExpression` | 单节点过滤条件 |
| `withAllChildren` | 命中的节点是否连带其**所有**子节点一并输出 |
| `withAllParents` | 命中的节点是否输出其**所有**父节点链（默认 true） |

```csharp
// 过滤"包含管理"的菜单（保留所有父节点，不连带子节点）
var result = menus.FilterTree(
    m => m.Children,
    node => node.Name.Contains("管理"),
    withAllChildren: false,
    withAllParents: true);
```

### 22.7 RecurseTree - 递归遍历

```csharp
public static List<T> RecurseTree<T>(this ICollection<T> tree,
                                     Func<T, IEnumerable<T>> childrenSelector,
                                     Action<RecurseTreeContext<T>> action)
```

深度优先遍历整棵树，对每个节点执行 `action`：

```csharp
menus.RecurseTree(
    m => m.Children,
    ctx => Console.WriteLine($"{new string(' ', ctx.Level * 2)}{ctx.Current.Name} (叶子: {ctx.IsLeaf})"));
```

`RecurseTreeContext<T>` 字段：

| 字段 | 类型 | 说明 |
|------|------|------|
| `Current` | `T` | 当前节点 |
| `IsLeaf` | `bool` | 是否叶子节点 |
| `Parent` | `RecurseTreeContext<T>` | 父级上下文 |
| `Level` | `int` | 当前深度（从 0 开始） |
| `Index` | `int` | 当前节点在同级中的索引 |
| `IsFirst` / `IsLast` | `bool` | 是否同级的首/末 |
| `Path` | `string` | 路径字符串（如 `0-1-2`） |
| `BreakRquested` | `bool` | 设为 true 可**中断**整棵树的遍历 |

### 22.8 TreeExtensions 方法汇总

| 方法 | 说明 | 返回 |
|------|------|------|
| `ToTree(idSelector, parentIdSelector, rootId)` | 转 TreeNode 树（按 rootId） | `TreeNode<T>[]` |
| `ToTree(idSelector, parentIdSelector, isRoot)` | 转 TreeNode 树（按谓词） | `TreeNode<T>[]` |
| `FetchToTree(idSelector, parentIdSelector, ...)` | 转 List 树（修改 T.Children） | `List<T>` |
| `ToFlat(childrenSelectorExpression, action?)` | 树扁平化 | `List<T>` |
| `FilterTree(childrenSelector, predicate, ...)` | 树过滤 | `List<T>` |
| `RecurseTree(childrenSelector, action)` | 树遍历 | `List<T>` |

### 22.9 选择建议

| 场景 | 推荐 API |
|------|----------|
| 临时构建树（不想污染原数据） | `ToTree` → `TreeNode<T>[]` |
| ORM 实体 + 已有 `Children` 字段 | `FetchToTree` |
| 按条件筛选菜单/分类 | `FilterTree` |
| 遍历整棵树（深度/兄弟索引） | `RecurseTree` |
| 序列化/传输前压平 | `ToFlat` + `SetNull` |
