# 快速开始

本文档将帮助您快速上手使用 JBaseLibrary 类库。

## 1. 安装 NuGet 包

通过命令行安装：

```bash
dotnet add package JBaseLibrary
```

或通过 Package Manager Console：

```powershell
Install-Package JBaseLibrary
```

## 2. 引入命名空间

根据使用的功能，引入相应的命名空间：

```csharp
// 核心工具类（Ensure、Equatable、Base64UrlSafe）
using JBaseLibrary;

// 扩展方法（字符串、日期、对象、集合、JSON 等）
using JBaseLibrary.Extensions;

// 加密模块
using JBaseLibrary.Encrypt;

// 帮助类（文件、Excel、二维码、JSON、日期、压缩、缓存、搜索 等）
using JBaseLibrary.Helpers;

// 验证模块（ValidateContext、Ensure 已在 JBaseLibrary）
using JBaseLibrary.Validate;

// 拼音模块
using JBaseLibrary.NPinyin;

// 对象反射访问器
using JBaseLibrary.Accessors;

// 对象差异比较
using JBaseLibrary.EasyComparers;

// 特性
using JBaseLibrary.Attributes;

// 枚举（OperationType 等）
using JBaseLibrary.Enums;
```

## 3. 快速示例

### 3.1 字符串处理

```csharp
using JBaseLibrary.Extensions;

// 判断是否为空
string name = null;
bool isEmpty = name.IsNullOrEmpty();  // true

// 字符串截取
"HelloWorld".Left(5);   // "Hello"
"HelloWorld".Right(5);  // "World"

// 字符串分割并去空格
var parts = "a, b, c".SplitAndTrim(',');  // ["a", "b", "c"]

// 字符串格式化（类似 String.Format）
"Hello, {name}".Render(new { name = "World" });  // "Hello, World"

// 首字母大写
"hello".FirstUpperCase();  // "Hello"
```

### 3.2 对象转换

```csharp
using JBaseLibrary.Extensions;

// 对象转 JSON
var user = new User { Name = "张三", Age = 25 };
var json = user.ToJson();

// JSON 反序列化
var user2 = json.ToObject<User>();

// 深拷贝
var copy = user.Clone();

// 高性能类型转换
var num = "123".ObjTo<int>();  // 123
var flag = "true".ObjTo<bool>();  // true

// 对象属性映射（用 DTO 修改 entity）
entity.ModifyByDto(updateDto);

// 对象转字典
var dict = user.ToDictionary();

// 对象 -> 另一个类型（新建）
var dto = user.Mapper<UserDto>();

// 集合 -> 集合
var dtos = users.Mapper<List<User>, List<UserDto>>();
```

### 3.3 加密操作

```csharp
using JBaseLibrary.Encrypt;

// MD5 加密（32位大写十六进制）
var md5 = MD5Encrypt.MD5("password");

// SHA256 加密（Base64UrlSafe 编码）
var sha256 = SHA256.SHA256Hash("password");

// AES 加解密
var encrypted = AESEncrypt.Encrypt("Hello", "Key12345678901234");
var decrypted = AESEncrypt.Decrypt(encrypted, "Key12345678901234");

// Base64UrlSafe（JWT 常用）
var urlSafe = Base64UrlSafe.Encode(data);
var original = Base64UrlSafe.Decode(urlSafe);
```

### 3.4 日期处理

```csharp
using JBaseLibrary.Extensions;

var now = DateTime.Now;

// 日期判断
bool isWeekend = now.IsWeekend();
bool isLeapYear = now.IsLeapYear();

// 日期差异
int days = now.DiffDays(endDate);

// 格式化输出
string dateStr = now.ToCommonString();      // "2026-04-23 10:30:00"
string dateOnly = now.ToCommonDateString();  // "2026-04-23"

// 中文格式
string week = now.Week();           // "星期三"
string chinese = now.DateToUpper(); // "二〇二六年四月二十三日"

// 时间戳
long ts = now.ToUnixTimeSeconds();  // 10位时间戳
DateTime? dt = ts.FromUnixTimeSeconds();
```

### 3.5 数值处理

```csharp
using JBaseLibrary.Extensions;

// 金额转换
decimal yuan = 1m.WYuanToY();     // 1万 -> 10000元
decimal wan = 10000m.YuanToWY();   // 10000元 -> 1万元

// 小数处理
decimal v = 123.456789m.TrimZero();   // 去除尾随零
decimal v2 = 123.456789m.SetDigits(2); // 截取：123.45
decimal v3 = 123.456789m.RoundTo(2);   // 四舍五入：123.46

// 百分比
string pct = 0.9535.ToPercentage();  // "95.35%"

// 数字转中文大写
string chinese = 12345.NumberToUpper();  // "一万二千三百四十五"
string money = 165.7m.MoneyToUpper();    // "壹佰陆拾伍点柒"
```

### 3.6 参数断言

```csharp
using JBaseLibrary;

// 基本断言
Ensure.That(isValid, "验证失败");
Ensure.NotNull(user, nameof(user));
Ensure.NotNullOrEmpty(list, nameof(list));
Ensure.NotNullOrWhiteSpace(name, nameof(name));
Ensure.Equal(expected, actual);
Ensure.NotEqual(a, b);

// 文件/目录检查
Ensure.Exists(directoryInfo);
Ensure.Exists(fileInfo);
```

### 3.7 链式验证器

```csharp
using JBaseLibrary.Validate;

var context = new ValidateContext<string>("hello");

// 链式验证
context.MustNotNullOrEmptyOrWhiteSpace()
       .MustLengthInRange(1, 100);

if (context.IsValid)
{
    Console.WriteLine("验证通过");
}
else
{
    foreach (var error in context.GetErrorMessages())
    {
        Console.WriteLine(error);
    }
}
```

完整示例（包括嵌套模型 + 实战 DTO）请参考 [验证模块详解](6-验证模块)。

### 3.8 集合操作

```csharp
using JBaseLibrary.Extensions;

// 条件筛选
var activeUsers = users.WhereIf(u => u.Status == 1, hasFilter);

// 分页
var page = users.GetPage(1, 10);

// 批量处理
foreach (var batch in users.Batch(100))
{
    // 每批处理 100 条
}

// 随机选择
var randomUser = users.SelectRandom();

// 集合比较
var (added, removed) = newList.GetDiff(oldList);

// ListComparator
bool eq = list1.ListComparator(list2);
bool eqIgnoreOrder = list1.ListComparator(list2, byOrder: false);
```

### 3.9 树形结构

```csharp
using JBaseLibrary.Extensions;

// 转换为树形结构
var tree = categories.ToTree(
    (a, b) => b.ParentId == 0,                  // 根节点条件
    (parent, child) => parent.Id == child.ParentId,  // 父子关系
    (parent, children) => parent.Children = children.ToList()  // 添加子节点
);

// 或使用 FetchToTree（要求 T 实现 ITreeStruct<T>）
var tree2 = categories.FetchToTree(
    t => t.Id, t => t.ParentId,
    isRoot: t => t.ParentId == 0,
    sortSelector: t => t.Sort);

// 树扁平化
var flat = tree.ToFlat(t => t.Children);

// 树过滤
var filtered = tree.FilterTree(
    t => t.Children,
    node => node.Name.Contains("管理"),
    withAllChildren: false,
    withAllParents: true);
```

### 3.10 Excel 操作

```csharp
using JBaseLibrary.Helpers;

// 导出 Excel
var headers = new Dictionary<string, string>
{
    { "姓名", "Name" },
    { "年龄", "Age" }
};
var bytes = ExcelHelper.ExportExcel("学生信息", headers, students);

// 读取 Excel
var students = ExcelHelper.ReadExcel<Student>("path.xlsx", 0, 1);
```

### 3.11 二维码生成

```csharp
using JBaseLibrary.Helpers;

// 生成字节数组
var bytes = QrCodeHelper.GenerateQrCodeBytes("https://example.com");

// 生成 Base64（用于 HTML 显示）
var base64 = QrCodeHelper.GenerateQrCodeBase64("https://example.com");
// <img src="data:image/png;base64,@base64" />

// 保存到文件
QrCodeHelper.GenerateQrCodeToFile("https://example.com", "qrcode.png");
```

### 3.12 文件与压缩

```csharp
using JBaseLibrary.Helpers;

// 读 / 写文件
FileHelper.WriteFile("C:\\test.txt", "Hello");
string content = FileHelper.FileRead("C:\\test.txt");

// 压缩
ZipHelper.ZipFile("C:\\out.zip", "C:\\file1.txt", "C:\\file2.db");
ZipHelper.UnZipFile("C:\\out.zip", "C:\\extract");
```

### 3.13 对象差异比较

```csharp
using JBaseLibrary.EasyComparers;

bool isEqual = EasyComparer.Instance.Compare(
    oldEntity, newEntity,
    inherit: true,
    includePrivate: false,
    out var variances);

foreach (var (prop, variance) in variances)
{
    if (variance.Varies)
    {
        Console.WriteLine($"{prop.Name}: {variance.LeftValue} -> {variance.RightValue}");
    }
}
```

### 3.14 顺序 GUID（COMB GUID）

```csharp
using JBaseLibrary.Helpers;

// SQL Server 推荐 AtEnd
GuidHelper.SequentialGuidType = SequentialGuidType.AtEnd;
Guid id = GuidHelper.Next();
```

### 3.15 拼音转换

```csharp
using JBaseLibrary.NPinyin;

// 首字母
PinyinHelper.GetInitials("中国");   // "ZG"

// 全拼
PinyinHelper.GetPinyin("中国");     // "zhong guo "

// 根据拼音找汉字
PinyinHelper.GetChineseText("ai");  // "哎爱..."
```
