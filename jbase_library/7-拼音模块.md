# 拼音模块

JBaseLibrary 提供了汉字转拼音的工具，支持获取拼音首字母、全拼，以及根据拼音查找汉字等功能。

## 1. PinyinHelper - 拼音转换

位于 `JBaseLibrary.NPinyin` 命名空间，提供汉字与拼音之间的转换功能。

### 1.1 获取拼音首字母

```csharp
using JBaseLibrary.NPinyin;

// 获取字符串的首字母
string initials = PinyinHelper.GetInitials("中国");
Console.WriteLine(initials);  // 输出: "ZG"

// 获取字符串的拼音首字母前缀（仅返回第一个字符的首字母）
string prefix = PinyinHelper.GetInitialsPrefix("中国");
Console.WriteLine(prefix);  // 输出: "Z"

// 处理混合字符串
string mixed = PinyinHelper.GetInitials("Hello中国");
Console.WriteLine(mixed);  // 输出: "HelloZG"

// 特殊字符处理
string empty = PinyinHelper.GetInitials("");
Console.WriteLine(empty);  // 输出: ""
```

### 1.2 获取全拼

```csharp
using JBaseLibrary.NPinyin;

// 获取字符串的全拼
string pinyin = PinyinHelper.GetPinyin("中国");
Console.WriteLine(pinyin);  // 输出: "zhong guo "

// 每个汉字之间用空格分隔
string name = PinyinHelper.GetPinyin("张三");
Console.WriteLine(name);  // 输出: "zhang san "

// 特殊字符原样返回
string withNumber = PinyinHelper.GetPinyin("张3");
Console.WriteLine(withNumber);  // 输出: "zhang 3 "
```

### 1.3 根据拼音查找汉字

```csharp
using JBaseLibrary.NPinyin;

// 根据拼音获取所有同音汉字
string chars = PinyinHelper.GetChineseText("ai");
Console.WriteLine(chars);  // 输出: "哎爱..." 等所有拼音为 "ai" 的汉字

// 多音字测试
string duoYin = PinyinHelper.GetChineseText("chang");
Console.WriteLine(duoYin);  // 输出: 所有拼音为 "chang" 的汉字（包含"常、长、场"等）
```

### 1.4 单字符处理

```csharp
using JBaseLibrary.NPinyin;

// 获取单个汉字的拼音
string py = PinyinHelper.GetPinyin('张');
Console.WriteLine(py);  // 输出: "zhang"

// 获取单个汉字的首字母（传入单字符字符串）
string initial = PinyinHelper.GetInitials("张");
Console.WriteLine(initial);  // 输出: "Z"

// 非汉字字符原样返回
string original = PinyinHelper.GetPinyin('A');
Console.WriteLine(original);  // 输出: "A"
```

### 1.5 编码支持

支持不同编码的文本转换：

```csharp
using JBaseLibrary.NPinyin;
using System.Text;

// UTF-8 编码（默认）
string utf8 = PinyinHelper.GetInitials("中国");  // "ZG"

// 指定编码
string gbk = PinyinHelper.GetInitials("中国", Encoding.GetEncoding("GB2312"));

// 获取全拼（指定编码）
string pinyinGbk = PinyinHelper.GetPinyin("中国", Encoding.GetEncoding("GB2312"));
```

### 1.6 编码转换

提供编码转换辅助方法：

```csharp
using JBaseLibrary.NPinyin;
using System.Text;

// 编码转换
string converted = PinyinHelper.ConvertEncoding(
    "中国",
    Encoding.GetEncoding("GB2312"),  // 源编码
    Encoding.UTF8                     // 目标编码
);
```

## 2. PyCode - 拼音编码数据（内部使用）

位于 `JBaseLibrary.NPinyin` 命名空间（内部类），包含汉字与拼音的映射数据。

> **注意**：`PyCode` 和 `PyHash` 是内部类，仅供 `PinyinHelper` 内部使用，不对外部直接暴露。

### 2.1 数据结构

`PyCode` 类包含拼音编码的静态数据，格式为：

```
拼音:汉字1汉字2汉字3...
```

例如：`ai:哎爱埃挨..."

### 2.2 数据来源

数据存储在 `PyCode.Codes` 静态字符串数组中，包含常用汉字的拼音映射。

## 3. PyHash - 拼音哈希索引（内部使用）

位于 `JBaseLibrary.NPinyin` 命名空间（内部类），用于快速查找汉字的拼音。

> **注意**：`PyHash` 是内部类，仅供 `PinyinHelper` 内部使用，不对外部直接暴露。

### 3.1 索引原理

使用哈希表加速汉字到拼音的查找，通过取模运算快速定位汉字所在区间。

### 3.2 内部实现

`PyHash.hashes` 是二维数组，包含汉字哈希值到拼音编码数组的映射。

## 4. 使用示例

### 4.1 姓名排序（拼音首字母）

```csharp
using JBaseLibrary.NPinyin;

var names = new[] { "张三", "李四", "王五", "赵六" };

// 按拼音首字母排序
var sorted = names.OrderBy(n => PinyinHelper.GetInitials(n));
foreach (var name in sorted)
{
    Console.WriteLine($"{name}: {PinyinHelper.GetInitials(name)}");
}

// 输出:
// 李四: LS
// 王五: WW
// 张三: ZS
// 赵六: ZL
```

### 4.2 搜索关键字（拼音匹配）

```csharp
using JBaseLibrary.NPinyin;

var keywords = new[] { "中国", "中华", "中文", "中心", "China" };

// 根据拼音筛选包含 "zhong" 的关键词
var search = PinyinHelper.GetPinyin("中");
var results = keywords.Where(k => 
    k.Contains("中") || 
    PinyinHelper.GetPinyin(k).Contains(search));
// 输出: 中国, 中华, 中文, 中心
```

### 4.3 生成拼音首字母索引

```csharp
using JBaseLibrary.NPinyin;
using System.Collections.Generic;

var items = new[]
{
    new { Id = 1, Name = "中国银行" },
    new { Id = 2, Name = "中国石油" },
    new { Id = 3, Name = "招商银行" }
};

// 生成首字母索引
var index = items.ToDictionary(
    item => PinyinHelper.GetInitials(item.Name),
    item => item
);

// 按首字母查询
var zgyh = index.FirstOrDefault(x => x.Key.StartsWith("Z"));
// 返回: { "ZGZH", { Id = 1, Name = "中国银行" } }
```

### 4.4 姓名转拼音

```csharp
using JBaseLibrary.NPinyin;

public string ConvertNameToPinyin(string name)
{
    // 姓名的全拼
    var pinyin = PinyinHelper.GetPinyin(name);
    
    // 姓名的首字母
    var initials = PinyinHelper.GetInitials(name);
    
    return $"{pinyin} ({initials})";
}

Console.WriteLine(ConvertNameToPinyin("张三"));
// 输出: "zhang san  (ZS)"

Console.WriteLine(ConvertNameToPinyin("李小龙"));
// 输出: "li xiao long  (LXL)"
```

### 4.5 批量转换

```csharp
using JBaseLibrary.NPinyin;

var cities = new[] { "北京", "上海", "广州", "深圳", "杭州" };

var cityPinyinMap = cities.ToDictionary(
    city => city,
    city => new
    {
        Pinyin = PinyinHelper.GetPinyin(city),
        Initials = PinyinHelper.GetInitials(city)
    }
);

// 输出结果
foreach (var kvp in cityPinyinMap)
{
    Console.WriteLine($"{kvp.Key}: {kvp.Value.Pinyin} ({kvp.Value.Initials})");
}

// 输出:
// 北京: bei jing  (BJ)
// 上海: shang hai  (SH)
// 广州: guang zhou  (GZ)
// 深圳: shen zhen  (SZ)
// 杭州: hang zhou  (HZ)
```

### 4.6 拼音纠错（常见多音字）

```csharp
using JBaseLibrary.NPinyin;

// 常见多音字列表
var polyphoneWords = new Dictionary<char, string[]>
{
    { '曾', new[] { "zeng", "ceng" } },
    { '行', new[] { "xing", "hang" } },
    { '长', new[] { "zhang", "chang" } },
    { '得', new[] { "de", "de", "děi" } }
};

// 获取多音字的所有拼音
foreach (var kvp in polyphoneWords)
{
    var chars = PinyinHelper.GetChineseText(kvp.Value[0]);
    Console.WriteLine($"'{kvp.Key}' 的拼音 '{kvp.Value[0]}' 对应汉字: {chars}");
}
```

## 5. 方法汇总

### PinyinHelper 方法

| 方法 | 参数 | 返回值 | 说明 |
|------|------|--------|------|
| `GetInitials(text)` | 字符串 | string | 获取拼音首字母 |
| `GetInitialsPrefix(text)` | 字符串 | string | 获取首个字符的首字母 |
| `GetInitials(text, encoding)` | 字符串, 编码 | string | 按指定编码获取首字母 |
| `GetPinyin(text)` | 字符串 | string | 获取全拼（空格分隔） |
| `GetPinyin(text, encoding)` | 字符串, 编码 | string | 按指定编码获取全拼 |
| `GetPinyin(ch)` | 字符 | string | 获取单个字符的拼音 |
| `GetPinyin(ch, encoding)` | 字符, 编码 | string | 按指定编码获取单个字符拼音 |
| `GetChineseText(pinyin)` | 拼音 | string | 根据拼音获取同音汉字 |
| `GetChineseText(pinyin, encoding)` | 拼音, 编码 | string | 按指定编码获取同音汉字 |
| `ConvertEncoding(text, src, dst)` | 文本, 源编码, 目标编码 | string | 编码转换 |

## 6. 注意事项

### 6.1 多音字处理

汉字存在大量多音字，`PinyinHelper` 默认返回常用读音。如需处理多音字，需要自行实现选择逻辑：

```csharp
// 常见多音字需要特殊处理
public string GetCorrectPinyin(string text)
{
    // 简单处理：按常用读音
    return PinyinHelper.GetPinyin(text);
}

// 进阶处理：根据上下文选择读音
public string GetCorrectPinyinWithContext(string text)
{
    // 行 (hang/xing)
    if (text.Contains("银行") || text.Contains("行业"))
    {
        return text.Replace("行", "hang");
    }
    
    return PinyinHelper.GetPinyin(text);
}
```

### 6.2 特殊字符

- 英文字母保持原样
- 数字保持原样
- 标点符号保持原样
- 空格处理为分隔符

### 6.3 编码问题

当处理非 UTF-8 编码的文本时，需要显式指定编码：

```csharp
// GB2312 编码
string gbkPinyin = PinyinHelper.GetPinyin(text, Encoding.GetEncoding("GB2312"));
```

## 7. 与 TreeExtensions 的结合

拼音模块可以与树形结构扩展结合，实现按拼音排序的树形菜单：

```csharp
using JBaseLibrary.NPinyin;
using JBaseLibrary.Extensions;

var menus = GetAllMenus();  // 获取所有菜单

// 构建树形结构并按拼音排序
var tree = menus
    .OrderBy(m => PinyinHelper.GetInitials(m.Name))  // 按拼音首字母排序
    .ToList()
    .FetchToTree(m => m.Id, m => m.ParentId, m => m.Children);
```
