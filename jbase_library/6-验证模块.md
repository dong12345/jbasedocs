# 验证模块

JBaseLibrary 提供了完整的参数验证框架，包含参数断言（`Ensure`）、链式验证器（`ValidateContext`）、通用格式校验（`ValidateHelper`）以及数据注解特性（`NotEmptyAttribute`、`EnumCheckAttribute`）。

## 1. Ensure - 参数断言

位于 `JBaseLibrary` 命名空间，用于在方法入口处进行参数校验，校验失败抛出异常。

### 1.1 That - 确保条件为真

```csharp
public static void That(bool condition, string message = "给定条件为false")
public static void That<TException>(bool condition, string message = "给定条件为false") where TException : Exception
```

当 `condition` 为 `false` 时抛出 `ArgumentException`（或指定的异常类型）。

```csharp
Ensure.That(isValid, "参数验证失败");
Ensure.That<ArgumentNullException>(value != null, "值不能为空");
```

### 1.2 Not - 确保条件为假

```csharp
public static void Not(bool condition, string message = "给定条件为true")
public static void Not<TException>(bool condition, string message = "给定条件为true") where TException : Exception
```

当 `condition` 为 `true` 时抛出 `ArgumentException`（或指定的异常类型）。

```csharp
Ensure.Not(string.IsNullOrEmpty(name), "名称不能为空");
```

### 1.3 NotNull - 确保对象不为空

```csharp
public static void NotNull<T>(T value, string argName) where T : class
```

当 `value` 为 `null` 时抛出 `ArgumentNullException`，异常信息包含参数名。

```csharp
public void ProcessUser(User user)
{
    Ensure.NotNull(user, nameof(user));
    // 后续处理...
}
```

### 1.4 Equal / NotEqual - 确保值相等/不相等

```csharp
public static void Equal<T>(T left, T right, string message = "值必须相等")
public static void NotEqual<T>(T left, T right, string message = "值不能相等")
```

当 `left` 和 `right` 不相等（Equal）或相等（NotEqual）时抛出 `ArgumentException`。

```csharp
Ensure.Equal(expected, actual, "值不匹配");
Ensure.NotEqual(status, 0, "状态不能为0");
```

### 1.5 NotNullOrEmpty - 确保集合不为空

```csharp
public static void NotNullOrEmpty<T>(ICollection<T> collection, string message = "Collection must not be null or empty.")
```

当集合为 `null` 或空时抛出 `ArgumentException`。

```csharp
public void ProcessItems(List<Item> items)
{
    Ensure.NotNullOrEmpty(items, "项目列表不能为空");
    // 后续处理...
}
```

### 1.6 NotNullOrWhiteSpace - 确保字符串不为空

```csharp
public static void NotNullOrWhiteSpace(string value, string message = "String must not be null, empty or whitespace.")
```

当字符串为 `null`、空或仅包含空白时抛出 `ArgumentException`。

```csharp
public void ProcessName(string name)
{
    Ensure.NotNullOrWhiteSpace(name, "名称不能为空");
    // 后续处理...
}
```

### 1.7 Exists - 确保文件/目录存在

```csharp
public static void Exists(DirectoryInfo directoryInfo)   // 抛 DirectoryNotFoundException
public static void Exists(FileInfo fileInfo)               // 抛 FileNotFoundException
```

当文件或目录不存在时抛出相应异常。

```csharp
public void ReadConfig(FileInfo configFile)
{
    Ensure.Exists(configFile);
    // 读取配置...
}
```

### 1.8 Ensure 方法汇总

| 方法 | 说明 | 异常类型 |
|------|------|----------|
| `That(condition, msg)` | 确保条件为真 | ArgumentException |
| `That<TException>` | 确保条件为真 | 自定义异常 |
| `Not(condition, msg)` | 确保条件为假 | ArgumentException |
| `Not<TException>` | 确保条件为假 | 自定义异常 |
| `NotNull(value, name)` | 确保对象不为空 | ArgumentNullException |
| `Equal(left, right, msg)` | 确保值相等 | ArgumentException |
| `NotEqual(left, right, msg)` | 确保值不相等 | ArgumentException |
| `NotNullOrEmpty(collection, msg)` | 确保集合不为空 | ArgumentException |
| `NotNullOrWhiteSpace(str, msg)` | 确保字符串不为空 | ArgumentException |
| `Exists(DirectoryInfo)` | 确保目录存在 | DirectoryNotFoundException |
| `Exists(FileInfo)` | 确保文件存在 | FileNotFoundException |

## 2. ValidateContext - 链式验证器

位于 `JBaseLibrary.Validate` 命名空间，提供链式调用的参数验证功能，且**支持嵌套对象的属性级验证**（通过 `RuleFor`）。

### 2.1 ValidateContext 抽象基类

```csharp
public abstract class ValidateContext
{
    internal List<(string path, string error)> ErrorMessage;
    internal List<ValidateContext> Children;
    internal ValidateContext Parent { get; set; }

    /// <summary>验证属性名称（用于错误消息显示）</summary>
    public string ModelName { get; protected set; }

    /// <summary>当前上下文和所有子上下文是否验证通过</summary>
    public bool IsValid { get; }

    /// <summary>获取当前上下文及所有子级的错误消息集合</summary>
    public IReadOnlyList<string> GetErrorMessages();
}
```

### 2.2 ValidateContext\<T\> - 泛型验证上下文

```csharp
public class ValidateContext<T> : ValidateContext
{
    /// <summary>要验证的值</summary>
    public T Model { get; }

    /// <summary>构造函数</summary>
    /// <param name="model">要验证的值</param>
    /// <param name="modelName">属性名称（用于错误消息显示），默认为 "Model"</param>
    public ValidateContext(T model, string modelName = "Model");
}
```

### 2.3 基本用法

```csharp
using JBaseLibrary.Validate;

// 创建验证上下文
var context = new ValidateContext<int>(100);

// 链式调用验证
context.MustGreaterThan(50)
       .MustLessThan(200)
       .MustNotNull();

// 检查验证结果
if (context.IsValid)
{
    // 验证通过
    var value = context.Model;
}
else
{
    // 验证失败，获取错误信息
    foreach (var error in context.GetErrorMessages())
    {
        Console.WriteLine(error);
    }
}
```

### 2.4 RuleFor - 属性级验证（嵌套模型）

`ValidateContext<T>` 通过 `RuleFor` 表达式树实现对模型属性的验证，这是验证模块最核心的能力：

```csharp
/// <summary>
/// 为对象的某个属性创建子级验证上下文
/// </summary>
/// <typeparam name="TProp">验证的类型</typeparam>
/// <param name="prop">类型的属性（如 x => x.Name）</param>
public ValidateContext<TProp> RuleFor<TProp>(Expression<Func<T, TProp>> prop);
```

`RuleFor` 会自动读取属性上的 `ValidateDisplayNameAttribute` 或 `DisplayNameAttribute`，作为错误消息中显示的字段名（即 `ModelName`）。

#### 使用示例

```csharp
public class User
{
    [DisplayName("用户名")]
    public string Name { get; set; }

    public int Age { get; set; }
}

var ctx = new ValidateContext<User>(new User { Name = "", Age = 200 });
ctx.RuleFor(x => x.Name).MustNotNullOrEmptyOrWhiteSpace("不能为空");
ctx.RuleFor(x => x.Age).MustLessThan(150, "年龄不能超过150");

// ctx.GetErrorMessages():
//   ["'用户名'不能为空", "'Age'年龄不能超过150"]
```

### 2.5 WithDisplayName - 自定义显示名称

```csharp
public ValidateContext<T> WithDisplayName(string name);
```

为当前验证上下文设置显示名称（覆盖属性名 / 特性名）。常用于在父级上下文中为子级模型起业务名称：

```csharp
var ctx = new ValidateContext<User>(user);
ctx.WithDisplayName("当前用户")
   .RuleFor(x => x.Name).MustNotNullOrEmptyOrWhiteSpace();
// 错误消息: "'当前用户.Name'不能为空"
```

### 2.6 IfFailThenExit - 失败立即抛出异常

```csharp
public ValidateContext<T> IfFailThenExit();
```

如果当前上下文（含子级）存在任何错误，立即将所有错误用 `\r\n` 拼接抛出 `ValidationException`，不再继续执行。常用于"前置必填"场景：

```csharp
ctx.RuleFor(x => x.Id).MustNotNull("Id不能为空").IfFailThenExit();
// 若 Id 验证失败，下面的代码不会再执行
ctx.RuleFor(x => x.Name).MustNotNullOrEmptyOrWhiteSpace();
```

### 2.7 验证方法一览

所有验证方法都支持自定义错误消息，第二个参数 `errorMessage` 可选，不传时使用自动生成的默认消息（包含属性名）。

#### 通用验证（`ValidateExtensions`，位于 `JBaseLibrary.Validate`）

| 方法 | 说明 | 支持类型 |
|------|------|----------|
| `MustNotNull(msg?)` | 值不能为 null | 全部 |
| `MustBeNull(msg?)` | 值必须为 null | 全部 |
| `MustEqualTo(value, msg?)` | 必须等于指定值 | 全部（同时有 `T?` 可空版本） |
| `MustNotEqualTo(value, msg?)` | 不能等于指定值 | 全部（同时有 `T?` 可空版本） |
| `MustGreaterThan(value, msg?)` | 必须大于指定值 | IComparable（含 `T?` 重载） |
| `MustGreaterThanOrEqualTo(value, msg?)` | 必须大于等于指定值 | IComparable（含 `T?` 重载） |
| `MustLessThan(value, msg?)` | 必须小于指定值 | IComparable（含 `T?` 重载） |
| `MustLessThanOrEqualTo(value, msg?)` | 必须小于等于指定值 | IComparable（含 `T?` 重载） |

### 2.8 验证方法示例

#### MustNotNull - 不能为空

```csharp
var context = new ValidateContext<string>("hello");
context.MustNotNull();  // 通过

var context2 = new ValidateContext<string>(null);
context2.MustNotNull();
// context2.IsValid == false
// context2.GetErrorMessages(): ["'Model'不能为空"]
```

#### MustBeNull - 必须为空

```csharp
var context = new ValidateContext<string>(null);
context.MustBeNull();  // 通过

var context2 = new ValidateContext<string>("hello");
context2.MustBeNull();
// context2.IsValid == false
// context2.GetErrorMessages(): ["'Model'必须为空"]
```

#### MustEqualTo - 必须相等

```csharp
var context = new ValidateContext<int>(100);
context.MustEqualTo(100);  // 通过

var context2 = new ValidateContext<int>(100);
context2.MustEqualTo(200);
// context2.IsValid == false
// context2.GetErrorMessages(): ["'Model'必须等于'200'"]
```

#### MustNotEqualTo - 不能相等

```csharp
var context = new ValidateContext<int>(100);
context.MustNotEqualTo(200);  // 通过

var context2 = new ValidateContext<int>(100);
context2.MustNotEqualTo(100);
// context2.IsValid == false
// context2.GetErrorMessages(): ["'Model'不能等于'100'"]
```

#### MustGreaterThan - 必须大于

```csharp
var context = new ValidateContext<int>(50);
context.MustGreaterThan(0);  // 通过

var context2 = new ValidateContext<int>(0);
context2.MustGreaterThan(0);
// context2.IsValid == false
// context2.GetErrorMessages(): ["'Model'必须大于'0'"]
```

#### MustGreaterThanOrEqualTo - 必须大于等于

```csharp
var context = new ValidateContext<int>(0);
context.MustGreaterThanOrEqualTo(0);  // 通过

var context2 = new ValidateContext<int>(-1);
context2.MustGreaterThanOrEqualTo(0);
// context2.IsValid == false
// context2.GetErrorMessages(): ["'Model'必须大于等于'0'"]
```

#### MustLessThan - 必须小于

```csharp
var context = new ValidateContext<int>(50);
context.MustLessThan(100);  // 通过

var context2 = new ValidateContext<int>(100);
context2.MustLessThan(100);
// context2.IsValid == false
// context2.GetErrorMessages(): ["'Model'必须小于'100'"]
```

#### MustLessThanOrEqualTo - 必须小于等于

```csharp
var context = new ValidateContext<int>(100);
context.MustLessThanOrEqualTo(100);  // 通过

var context2 = new ValidateContext<int>(101);
context2.MustLessThanOrEqualTo(100);
// context2.IsValid == false
// context2.GetErrorMessages(): ["'Model'必须小于等于'100'"]
```

### 2.9 自定义错误消息

所有验证方法都支持自定义错误消息（`errorMessage` 参数），覆盖默认消息：

```csharp
var context = new ValidateContext<int>(0);
context.MustGreaterThan(0, "年龄必须大于0");
context.MustLessThan(150, "年龄不能超过150");
// context.GetErrorMessages(): ["年龄必须大于0"]
```

### 2.10 可空类型支持

验证器完全支持可空类型（`T?`）。`ValidateExtensions` 中针对数值比较有专门的可空类型重载：

```csharp
int? value = 100;
var context = new ValidateContext<int?>(value);
context.MustGreaterThan(50);  // 通过

int? nullValue = null;
var context2 = new ValidateContext<int?>(nullValue);
// 当值为 null 时，相关比较操作会失败（视为不通过）
```

## 3. ValidateNumberExtensions - 数字验证扩展

位于 `JBaseLibrary.Validate` 命名空间，针对数值类型（int、short、long、float、double、decimal，含可空版本）提供 `MustGreaterThanZero`、`MustGreaterThanOrEuqalToZero` 等便捷扩展。

### 3.1 MustGreaterThanZero - 必须大于 0

支持 `int?`/`int`/`short?`/`short`/`long?`/`long`/`float?`/`float`/`double?`/`double`/`decimal?`/`decimal` 全套重载：

```csharp
var ctx = new ValidateContext<int>(-1);
ctx.MustGreaterThanZero("数量必须大于0");
// ctx.GetErrorMessages(): ["数量必须大于0"]
```

### 3.2 MustGreaterThanOrEuqalToZero - 必须大于等于 0

支持 `int?`/`int`/`short?`/`short`：

```csharp
var ctx = new ValidateContext<int>(-1);
ctx.MustGreaterThanOrEuqalToZero();
// ctx.GetErrorMessages(): ["'Model'必须大于等于0"]
```

> **注意**：方法名 `EuqalTo` 是源代码中的拼写（保持向后兼容），调用时按此名引用。

## 4. ValidateStringExtensions - 字符串验证扩展

位于 `JBaseLibrary.Validate` 命名空间，提供针对字符串的验证扩展方法。

### 4.1 基本验证

```csharp
var context = new ValidateContext<string>("hello");

// 非空白验证
context.MustNotNullOrEmptyOrWhiteSpace("字符串不能为空");

// 长度范围验证（min 和 max 可任一为 null 表示不限制）
context.MustLengthInRange(3, 10, "长度必须在3-10之间");

// 编码后字节长度验证（如中文按 UTF-8 占多字节）
context.MustByteLengthInRange(Encoding.UTF8, 1, 50, "编码后长度必须在1-50之间");

// 必须包含子串
context.MustContais("@", "必须包含@");

// 不能包含子串
context.MustNotContais("admin", "不能包含admin");

// 正则验证
context.MustMatchRegex(@"^[a-z]+$", "只能包含小写字母");

// 邮箱验证
context.MustEmailAddress("邮箱格式不正确");

// 手机号验证
context.MustCellPhone("手机号格式不正确");

// 身份证验证
context.MustIdCard("身份证格式不正确");
```

### 4.2 自动处理（链式副作用）

下面的方法不是验证，而是对值做自动处理后继续链式调用：

```csharp
// 去除首尾空格
var ctx = new ValidateContext<string>("  hello  ");
ctx.TrimValue();
// ctx.Model == "hello"

// 转大写
ctx.ToUpperValue();

// 转小写
ctx.ToLowerValue();
```

### 4.3 方法汇总

| 方法 | 说明 |
|------|------|
| `MustBeNull(msg?)` | 必须为 null |
| `MustBeNullOrEmptyOrWhiteSpace(msg?)` | 必须为空或仅空白 |
| `MustNotNullOrEmptyOrWhiteSpace(msg?)` | 不能为空或仅空白 |
| `MustLengthInRange(min?, max?, msg?)` | 长度范围 |
| `MustByteLengthInRange(encoding, min?, max?, msg?)` | 编码后字节长度范围 |
| `MustContais(value, msg?)` | 必须包含子串 |
| `MustNotContais(value, msg?)` | 不能包含子串 |
| `MustMatchRegex(pattern, msg?)` | 正则匹配 |
| `MustEmailAddress(msg?)` | 邮箱格式 |
| `MustIdCard(msg?)` | 身份证格式 |
| `MustCellPhone(msg?)` | 手机号格式 |
| `TrimValue()` | 去除首尾空白 |
| `ToUpperValue()` | 转大写 |
| `ToLowerValue()` | 转小写 |

## 5. ValidateListExtensions - 集合验证扩展

位于 `JBaseLibrary.Validate` 命名空间，提供针对集合的验证扩展方法。重载覆盖 `IList<T>`、`List<T>`、`IEnumerable<T>`、`ICollection<T>` 四种类型。

### 5.1 基本验证

```csharp
var context = new ValidateContext<List<string>>(new List<string> { "a", "b", "c" });

// 非空验证
context.MustNotNullOrEmpty("列表不能为空");

// 为空验证
var emptyContext = new ValidateContext<List<string>>(new List<string>());
emptyContext.MustBeNullOrEmpty("列表必须为空");
```

### 5.2 RuleForEach - 集合元素级验证

```csharp
/// <summary>
/// 循环验证集合中每个元素
/// </summary>
/// <param name="validater">针对每个元素的验证委托</param>
public static ValidateContext<...> RuleForEach<T>(this ValidateContext<...> ctx, Action<ValidateContext<T>> validater);
```

`RuleForEach` 对集合中每一项创建子级 `ValidateContext<T>`，元素验证失败时错误路径会自动包含下标，如 `[0]`、`[1]`：

```csharp
var itemCtx = new ValidateContext<List<int>>(new List<int> { 1, 2, 3 });
itemCtx.RuleForEach(item => item.MustGreaterThan(0, "每个元素必须大于0"));

// 假设有 [1, -2, 3]：
// itemCtx.GetErrorMessages(): ["'[1]'每个元素必须大于0"]
```

### 5.3 方法汇总

| 方法 | 说明 |
|------|------|
| `MustNotNullOrEmpty(msg?)` | 不能为空（4 种集合重载） |
| `MustBeNullOrEmpty(msg?)` | 必须为空（4 种集合重载） |
| `RuleForEach(validator)` | 循环验证集合中每个元素 |

## 6. ValidationException - 验证异常

位于 `JBaseLibrary.Validate` 命名空间，表示验证失败的异常。仅接收单一的错误消息字符串：

```csharp
public class ValidationException : Exception
{
    public ValidationException(string message) : base(message);
}

// 使用
throw new ValidationException("验证失败");
```

### 6.1 ValidateContext.IfFailThenExit()

`ValidateContext<T>.IfFailThenExit()` 是抛出 `ValidationException` 的标准入口：内部把所有错误用 `\r\n` 拼接后抛出。

## 7. ValidateDisplayNameAttribute - 自定义显示名

位于 `JBaseLibrary.Validate` 命名空间，标注在模型属性上，可在 `RuleFor` 的错误消息中作为字段名使用（优先级高于 `DisplayNameAttribute`）：

```csharp
public class User
{
    [ValidateDisplayName("用户名")]
    public string Name { get; set; }

    [DisplayName("邮箱")]   // 也可被识别，但优先级低于 ValidateDisplayNameAttribute
    public string Email { get; set; }
}
```

## 8. ValidateHelper - 通用格式校验

位于 `JBaseLibrary.Helpers` 命名空间，提供一组**返回 `bool` 的通用格式判断方法**，与上面"链式验证器"互补——常用于不需要错误聚合的简单场景。

### 8.1 邮箱验证

```csharp
ValidateHelper.IsEmail("user@example.com");                      // true
ValidateHelper.IsEmail("user@example.com", isRestrict: true);    // true（严格模式，RFC 5322）

// 严格模式正则
@"^(?("")("".+?""@)|(([0-9a-zA-Z]((\.(?!\.))|[-!#\$%&'\*\+/=\?\^`\{\}\|~\w])*)(?<=[0-9a-zA-Z])@))(?(\[)(\[(\d{1,3}\.){3}\d{1,3}\])|(([0-9a-zA-Z][-\w]*[0-9a-zA-Z]\.)+[a-zA-Z]{2,6}))$"

// 普通模式正则
@"^[\w-]+(\.[\w-]+)*@[\w-]+(\.[\w-]+)+$"
```

### 8.2 手机号验证

```csharp
ValidateHelper.IsMobileNumber("13800138000");  // true（11 位，以 1 开头）
```

### 8.3 身份证号验证

支持 15 位和 18 位身份证号（含末位 X），会校验省份码、生日、最后一位校验位：

```csharp
ValidateHelper.IsIdCard("11010519491231002X");  // true
ValidateHelper.IsIdCard("110105194912310026");  // true
ValidateHelper.IsIdCard("110105491231002");    // false（已不再签发 15 位）
```

### 8.4 URL / IP / Mac / 银行卡 / 日期

```csharp
ValidateHelper.IsUrl("https://example.com");      // true
ValidateHelper.IsIpAddress("192.168.1.1");       // true
ValidateHelper.IsMac("00-1B-44-11-3A-B7");       // true（也支持无分隔符 12 位大写）
ValidateHelper.IsBandCard("6222021234567890123"); // true（16 位或 19 位数字）

// 指定格式解析日期
ValidateHelper.IsDate("20240101", "yyyyMMdd");    // true
ValidateHelper.IsDate("20240101", "yyyyMMdd", null, DateTimeStyles.None);
```

### 8.5 SQL 注入防护判断

```csharp
ValidateHelper.IsSafeString("select * from users");  // false（包含 `*`、空格等）
ValidateHelper.IsSafeString("hello world");          // false（包含空格）
ValidateHelper.IsSafeString("helloworld");          // true
```

> 该方法会检查 `[-|;|,|\/|\(|\)|\[|\]|\}|\{|%|@|\*|!|\']` 这些危险字符，实际项目中建议使用参数化查询，而非依赖此判断。

### 8.6 中文相关

```csharp
ValidateHelper.IsChinese("中国");        // true
ValidateHelper.IsContainsChinese("中国abc");  // true（包含中文）
```

### 8.7 数字判断

```csharp
ValidateHelper.IsInteger("-123");           // true
ValidateHelper.IsPositiveInteger("123");    // true（大于 0 的整数）
ValidateHelper.IsContainsNumber("abc123");  // true（包含数字）
```

### 8.8 长度范围（一个中文按 2 个字符计）

```csharp
ValidateHelper.IsConformRange("张三", 1, 10);  // true（"张三" 计为 4 个字符）
```

### 8.9 Base64 编码判断

```csharp
ValidateHelper.IsBase64String("SGVsbG8=");  // true
```

## 9. 实战案例

### 9.1 用户修改密码请求（典型业务场景）

下面是项目中最常见的 DTO + 验证组合，使用 `ValidateContext.RuleFor` 链式校验，配合 `JBase.Common.Helper.ValidateModelHelper.ValidThrow` 在 Service 层一键调用：

#### 9.1.1 定义 DTO

```csharp
using System.ComponentModel.DataAnnotations;
using JBaseLibrary.Validate;

public class UserUpdatePwdReq
{
    /// <summary>
    /// 旧密码
    /// </summary>
    [Required(ErrorMessage = "旧密码不能为空")]
    public string OldPassword { get; set; }

    /// <summary>
    /// 新密码
    /// </summary>
    [Required(ErrorMessage = "新密码不能为空")]
    [StringLength(20, MinimumLength = 5, ErrorMessage = "密码长度必须在5-20个字符之间")]
    public string NewPassword { get; set; }

    /// <summary>
    /// 确认新密码
    /// </summary>
    [Required(ErrorMessage = "确认新密码不能为空")]
    [StringLength(20, MinimumLength = 5, ErrorMessage = "密码长度必须在5-20个字符之间")]
    public string ConfirmNewPassword { get; set; }

    /// <summary>
    /// 校验逻辑：两次新密码必须一致
    /// </summary>
    public static void Valid(ValidateContext<UserUpdatePwdReq> ctx)
    {
        ctx.RuleFor(x => x.NewPassword)
           .MustEqualTo(ctx.Model.ConfirmNewPassword, "确认新密码必须和新密码相同");
    }
}
```

> **注意**：`MustEqualTo(ctx.Model.ConfirmNewPassword, ...)` 中的 `ctx.Model` 是外层 `ValidateContext<UserUpdatePwdReq>` 的值，因此可以访问到任何已校验字段，用于做"字段间一致性"校验。

#### 9.1.2 Service 层调用

`ValidateModelHelper.ValidThrow` 是项目中最常用的入口（在 `JBase.Common.Helper` 命名空间下，封装在 `JBase.Common` 项目中），它会执行验证委托并在失败时抛出 `ValidationException`：

```csharp
using JBase.Common.Helper;

public class UserService
{
    public void UpdatePassword(int userId, UserUpdatePwdReq req)
    {
        // 一行调用完成 DTO 验证 + 异常抛出
        ValidateModelHelper.ValidThrow(req, UserUpdatePwdReq.Valid);

        // ... 执行业务逻辑（修改密码、记录日志等）
    }
}
```

#### 9.1.3 运行效果

```csharp
// 调用
var req = new UserUpdatePwdReq
{
    OldPassword = "123456",
    NewPassword = "abc12",
    ConfirmNewPassword = "abc99"   // 与新密码不一致
};
ValidateModelHelper.ValidThrow(req, UserUpdatePwdReq.Valid);

// 抛出异常：JBaseLibrary.Validate.ValidationException
// Message = "确认新密码必须和新密码相同"
```

#### 9.1.4 三种返回方式

`ValidateModelHelper` 提供三种不同的返回方式，可按业务选择：

| 方法 | 返回 | 异常 | 典型用途 |
|------|------|------|----------|
| `ValidErrorMessage(dto, func)` | 错误消息字符串（多条用 `\r\n` 拼接） | 无 | 日志、消息聚合 |
| `ValidResult(dto, func, code)` | `ResponseOutput`（Ok / NotOk） | 无 | Web Controller 返回统一响应 |
| `ValidThrow(dto, func, code)` | void | `ValidationException` | Service / Worker 内部使用 |

```csharp
// 仅获取错误消息（不抛异常）
string msg = ValidateModelHelper.ValidErrorMessage(req, UserUpdatePwdReq.Valid);

// 返回统一响应对象
var response = ValidateModelHelper.ValidResult(req, UserUpdatePwdReq.Valid, errorCode: 400);
// response.Success == false, response.Message == "确认新密码必须和新密码相同"

// 抛异常
ValidateModelHelper.ValidThrow(req, UserUpdatePwdReq.Valid);
```

### 9.2 嵌套模型验证

支持对子对象的属性逐级验证（`RuleFor` 嵌套 `RuleFor`）：

```csharp
public class OrderReq
{
    public UserReq User { get; set; }
    public List<OrderItemReq> Items { get; set; }
}

public class UserReq
{
    [ValidateDisplayName("收货人姓名")]
    public string Name { get; set; }

    [ValidateDisplayName("收货人手机")]
    public string Phone { get; set; }
}

public class OrderItemReq
{
    [ValidateDisplayName("商品名称")]
    public string ProductName { get; set; }

    [ValidateDisplayName("购买数量")]
    public int Quantity { get; set; }
}

public static void Valid(ValidateContext<OrderReq> ctx)
{
    // 嵌套验证子对象
    ctx.RuleFor(x => x.User)
       .MustNotNull("收货人信息不能为空")
       .RuleFor(x => x.Name)
       .MustNotNullOrEmptyOrWhiteSpace("姓名不能为空");

    ctx.RuleFor(x => x.User.Phone)
       .MustCellPhone("手机号格式不正确");

    // 集合元素级验证（每个元素都按 RuleFor 校验）
    ctx.RuleFor(x => x.Items)
       .MustNotNullOrEmpty("订单项不能为空")
       .RuleForEach(item => item
           .RuleFor(x => x.ProductName).MustNotNullOrEmptyOrWhiteSpace()
           .RuleFor(x => x.Quantity).MustGreaterThanZero("数量必须大于0"));
}
```

### 9.3 在领域模型中使用

```csharp
public class User
{
    public string Name { get; set; }
    public int Age { get; set; }
    public string Email { get; set; }

    public void Validate()
    {
        var ctx = new ValidateContext<User>(this).WithDisplayName("用户信息");

        ctx.RuleFor(x => x.Name).MustNotNullOrEmptyOrWhiteSpace("姓名不能为空")
                                .MustLengthInRange(null, 50, "姓名不能超过50个字符");
        ctx.RuleFor(x => x.Age).MustGreaterThan(0, "年龄必须大于0")
                               .MustLessThan(150, "年龄不能超过150");
        ctx.RuleFor(x => x.Email).MustEmailAddress("邮箱格式不正确");

        if (!ctx.IsValid)
        {
            throw new ValidationException(
                string.Join("; ", ctx.GetErrorMessages()));
        }
    }
}
```

### 9.4 在 Service 层中使用

```csharp
public class OrderService
{
    public void CreateOrder(OrderDto dto)
    {
        // 验证订单数据
        var ctx = new ValidateContext<OrderDto>(dto).WithDisplayName("订单");
        ctx.RuleFor(x => x.TotalAmount).MustGreaterThan(0, "订单金额必须大于0");

        if (!ctx.IsValid)
        {
            throw new ValidationException(
                string.Join("; ", ctx.GetErrorMessages()));
        }

        // 继续业务逻辑...
    }
}
```

## 10. 最佳实践

1. **DTO 与 Valid 静态方法同文件**：将验证方法作为 DTO 的静态方法（参见 9.1），便于一处维护、多处调用。
2. **优先使用 `RuleFor` + `MustXxx`**：相比手动 `new ValidateContext<T>`，`RuleFor` 自动从特性读取属性名，错误消息更友好。
3. **`IfFailThenExit` 用于前置必填**：如 `Id`、`UserId` 等字段应先校验，失败立即抛异常，避免后续空引用。
4. **可空类型用 `T?` 重载**：对 `int?`、`decimal?` 等可空数值，使用可空类型专用的重载，避免空值比较出错。
5. **Service 层用 `ValidThrow`**：配合 `JBase.Common.Helper.ValidateModelHelper.ValidThrow` 一行完成"验证 + 抛异常"。
6. **Controller 层用 `ValidResult`**：配合 `JBase.Common.Helper.ValidateModelHelper.ValidResult` 直接返回 `ResponseOutput` 统一响应。

## 11. 方法汇总

### 11.1 ValidateContext 基础验证（`ValidateExtensions`）

| 方法 | 说明 | 支持类型 |
|------|------|----------|
| `MustNotNull(msg?)` | 值不能为 null | 全部 |
| `MustBeNull(msg?)` | 值必须为 null | 全部 |
| `MustEqualTo(value, msg?)` | 必须等于指定值 | 全部（含 `T?` 重载） |
| `MustNotEqualTo(value, msg?)` | 不能等于指定值 | 全部（含 `T?` 重载） |
| `MustGreaterThan(value, msg?)` | 必须大于指定值 | IComparable（含 `T?` 重载） |
| `MustGreaterThanOrEqualTo(value, msg?)` | 必须大于等于指定值 | IComparable（含 `T?` 重载） |
| `MustLessThan(value, msg?)` | 必须小于指定值 | IComparable（含 `T?` 重载） |
| `MustLessThanOrEqualTo(value, msg?)` | 必须小于等于指定值 | IComparable（含 `T?` 重载） |

### 11.2 ValidateContext 上下文操作

| 方法 | 说明 |
|------|------|
| `RuleFor<TProp>(prop)` | 进入属性级验证（自动识别 `[ValidateDisplayName]`、`[DisplayName]`） |
| `WithDisplayName(name)` | 设置当前上下文的显示名称 |
| `IfFailThenExit()` | 失败时把全部错误用 `\r\n` 拼接抛 `ValidationException` |

### 11.3 数字验证扩展（`ValidateNumberExtensions`）

| 方法 | 说明 | 支持类型 |
|------|------|----------|
| `MustGreaterThanZero(msg?)` | 必须大于 0 | int/long/short/float/double/decimal（含可空） |
| `MustGreaterThanOrEuqalToZero(msg?)` | 必须大于等于 0 | int/short（含可空） |

### 11.4 字符串验证扩展（`ValidateStringExtensions`）

| 方法 | 说明 |
|------|------|
| `MustBeNull(msg?)` | 必须为 null |

| `MustNotNullOrEmptyOrWhiteSpace(msg?)` | 不能为空或仅空白 |
| `MustLengthInRange(min?, max?, msg?)` | 长度范围 |
| `MustByteLengthInRange(encoding, min?, max?, msg?)` | 编码后字节长度范围 |
| `MustContais(value, msg?)` | 必须包含子串 |
| `MustNotContais(value, msg?)` | 不能包含子串 |

| `MustEmailAddress(msg?)` | 邮箱格式 |
| `MustIdCard(msg?)` | 身份证格式 |
| `MustCellPhone(msg?)` | 手机号格式 |
| `TrimValue()` | 去除首尾空白 |
