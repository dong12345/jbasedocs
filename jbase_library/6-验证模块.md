# 验证模块

JBaseLibrary 提供了参数验证框架，包括参数断言（Ensure）和链式验证器（ValidateContext）。

## 1. ValidateContext - 链式验证器

位于 `JBaseLibrary.Validate` 命名空间，提供链式调用的参数验证功能。

### 1.1 基本用法

```csharp
using JBaseLibrary.Validate;

// 创建验证上下文
var context = new ValidateContext<int>(100);

// 链式调用验证
context.MustGreaterThan(50)
       .MustLessThan(200)
       .MustNotNull();

// 检查验证结果
if (context.IsValid)
{
    // 验证通过
    var value = context.Model;
}
else
{
    // 验证失败，获取错误信息
    foreach (var error in context.GetErrorMessages())
    {
        Console.WriteLine(error);
    }
}
```

### 1.2 验证方法一览

| 方法 | 说明 | 示例 |
|------|------|------|
| `MustNotNull` | 值不能为 null | `ctx.MustNotNull()` |
| `MustBeNull` | 值必须为 null | `ctx.MustBeNull()` |
| `MustEqualTo(value)` | 值必须等于指定值 | `ctx.MustEqualTo(100)` |
| `MustNotEqualTo(value)` | 值不能等于指定值 | `ctx.MustNotEqualTo(0)` |
| `MustGreaterThan(value)` | 值必须大于指定值 | `ctx.MustGreaterThan(0)` |
| `MustGreaterThanOrEqualTo(value)` | 值必须大于等于指定值 | `ctx.MustGreaterThanOrEqualTo(0)` |
| `MustLessThan(value)` | 值必须小于指定值 | `ctx.MustLessThan(100)` |
| `MustLessThanOrEqualTo(value)` | 值必须小于等于指定值 | `ctx.MustLessThanOrEqualTo(100)` |

### 1.3 验证规则

#### MustNotNull - 不能为空

```csharp
var context = new ValidateContext<string>("hello");
context.MustNotNull();  // 通过

var context2 = new ValidateContext<string>(null);
context2.MustNotNull();
// context2.IsValid == false
// context2.GetErrorMessages(): ["'Model'不能为空"]
```

#### MustBeNull - 必须为空

```csharp
var context = new ValidateContext<string>(null);
context.MustBeNull();  // 通过

var context2 = new ValidateContext<string>("hello");
context2.MustBeNull();
// context2.IsValid == false
// context2.GetErrorMessages(): ["'Model'必须为空"]
```

#### MustEqualTo - 必须相等

```csharp
var context = new ValidateContext<int>(100);
context.MustEqualTo(100);  // 通过

var context2 = new ValidateContext<int>(100);
context2.MustEqualTo(200);
// context2.IsValid == false
// context2.GetErrorMessages(): ["'Model'必须等于'200'"]
```

#### MustNotEqualTo - 不能相等

```csharp
var context = new ValidateContext<int>(100);
context.MustNotEqualTo(200);  // 通过

var context2 = new ValidateContext<int>(100);
context2.MustNotEqualTo(100);
// context2.IsValid == false
// context2.GetErrorMessages(): ["'Model'不能等于'100'"]
```

#### MustGreaterThan - 必须大于

```csharp
var context = new ValidateContext<int>(50);
context.MustGreaterThan(0);  // 通过

var context2 = new ValidateContext<int>(0);
context2.MustGreaterThan(0);
// context2.IsValid == false
// context2.GetErrorMessages(): ["'Model'必须大于'0'"]
```

#### MustGreaterThanOrEqualTo - 必须大于等于

```csharp
var context = new ValidateContext<int>(0);
context.MustGreaterThanOrEqualTo(0);  // 通过

var context2 = new ValidateContext<int>(-1);
context2.MustGreaterThanOrEqualTo(0);
// context2.IsValid == false
// context2.GetErrorMessages(): ["'Model'必须大于等于'0'"]
```

#### MustLessThan - 必须小于

```csharp
var context = new ValidateContext<int>(50);
context.MustLessThan(100);  // 通过

var context2 = new ValidateContext<int>(100);
context2.MustLessThan(100);
// context2.IsValid == false
// context2.GetErrorMessages(): ["'Model'必须小于'100'"]
```

#### MustLessThanOrEqualTo - 必须小于等于

```csharp
var context = new ValidateContext<int>(100);
context.MustLessThanOrEqualTo(100);  // 通过

var context2 = new ValidateContext<int>(101);
context2.MustLessThanOrEqualTo(100);
// context.IsValid == false
// context.GetErrorMessages(): ["'Model'必须小于等于'100'"]
```

### 1.4 自定义错误消息

所有验证方法都支持自定义错误消息：

```csharp
var context = new ValidateContext<int>(0);
context.MustGreaterThan(0, "年龄必须大于0");
context.MustLessThan(150, "年龄不能超过150");
// context.IsValid == false
// context.GetErrorMessages(): ["年龄必须大于0"]
```

### 1.5 可空类型支持

验证器完全支持可空类型：

```csharp
int? value = 100;
var context = new ValidateContext<int?>(value);
context.MustGreaterThan(50);  // 通过

int? nullValue = null;
var context2 = new ValidateContext<int?>(nullValue);
// 当值为 null 时，相关比较操作会失败
```

### 1.6 完整示例

```csharp
public class UserValidator
{
    public bool Validate(User user, out List<string> errors)
    {
        var context = new ValidateContext<int>(user.Age);

        context.MustGreaterThan(0, "年龄必须大于0")
               .MustLessThan(150, "年龄不能超过150");

        var nameContext = new ValidateContext<string>(user.Name);
        nameContext.MustNotNull("用户名不能为空");

        var emailContext = new ValidateContext<string>(user.Email);
        emailContext.MustNotNull("邮箱不能为空");

        // 收集所有错误消息
        errors = new List<string>();
        errors.AddRange(context.GetErrorMessages());
        errors.AddRange(nameContext.GetErrorMessages());
        errors.AddRange(emailContext.GetErrorMessages());

        return errors.Count == 0;
    }
}
```

## 2. ValidateNumberExtensions - 数字验证扩展

位于 `JBaseLibrary.Validate` 命名空间，提供针对数字类型的验证扩展方法。

### 2.1 基本验证

```csharp
var context = new ValidateContext<int>(150);

// 大于0验证
context.MustGreaterThan(0);

// 小于0验证
context.MustLessThan(0);

// 等于0验证
context.MustEqualTo(0);

// 不等于0验证
context.MustNotEqualTo(0);

// 范围验证（使用链式调用）
var rangeCtx = new ValidateContext<int>(150);
rangeCtx.MustGreaterThanOrEqualTo(0)
       .MustLessThanOrEqualTo(100);
```

## 3. ValidateStringExtensions - 字符串验证扩展

位于 `JBaseLibrary.Validate` 命名空间，提供针对字符串的验证扩展方法。

### 3.1 基本验证

```csharp
var context = new ValidateContext<string>("hello");

// 非空白验证
context.MustNotNullOrEmptyOrWhiteSpace("字符串不能为空");

// 长度范围验证
context.MustLengthInRange(3, 10, "长度必须在3-10之间");

// 邮箱验证
context.MustEmailAddress("邮箱格式不正确");

// 手机号验证
context.MustCellPhone("手机号格式不正确");

// 身份证验证
context.MustIdCard("身份证格式不正确");

// 正则验证
context.MustMatchRegex(@"^[a-z]+$", "格式不正确");
```

## 4. ValidateListExtensions - 集合验证扩展

位于 `JBaseLibrary.Validate` 命名空间，提供针对集合的验证扩展方法。

### 4.1 基本验证

```csharp
var context = new ValidateContext<List<string>>(new List<string> { "a", "b", "c" });

// 非空验证
context.MustNotNullOrEmpty("列表不能为空");

// 为空验证
var emptyContext = new ValidateContext<List<string>>(new List<string>());
emptyContext.MustBeNullOrEmpty("列表必须为空");

// 循环验证集合中每个元素
var itemCtx = new ValidateContext<List<int>>(new List<int> { 1, 2, 3 });
itemCtx.RuleForEach(item => item.MustGreaterThan(0, "每个元素必须大于0"));
```

## 5. ValidationException - 验证异常

位于 `JBaseLibrary.Validate` 命名空间，表示验证失败的异常。

### 5.1 基本用法

```csharp
throw new ValidationException("验证失败");
```

`ValidationException` 继承自 `Exception`，仅接收单一的错误消息字符串。

## 6. 最佳实践

### 6.1 在领域模型中使用

```csharp
public class User
{
    public string Name { get; set; }
    public int Age { get; set; }
    public string Email { get; set; }

    public void Validate()
    {
        var errors = new List<string>();

        // 验证姓名
        var nameCtx = new ValidateContext<string>(Name);
        nameCtx.MustNotNullOrEmptyOrWhiteSpace("姓名不能为空");
        nameCtx.MustLengthInRange(null, 50, "姓名不能超过50个字符");
        errors.AddRange(nameCtx.GetErrorMessages());

        // 验证年龄
        var ageCtx = new ValidateContext<int>(Age);
        ageCtx.MustGreaterThan(0, "年龄必须大于0");
        ageCtx.MustLessThan(150, "年龄不能超过150");
        errors.AddRange(ageCtx.GetErrorMessages());

        if (errors.Any())
        {
            throw new ValidationException(string.Join("; ", errors));
        }
    }
}
```

### 6.2 在服务层中使用

```csharp
public class OrderService
{
    public void CreateOrder(OrderDto dto)
    {
        // 验证订单数据
        var orderCtx = new ValidateContext<decimal>(dto.TotalAmount);
        orderCtx.MustGreaterThan(0, "订单金额必须大于0");

        if (!orderCtx.IsValid)
        {
            throw new ValidationException(
                string.Join("; ", orderCtx.GetErrorMessages()));
        }

        // 继续业务逻辑...
    }
}
```

### 6.3 验证与异常处理

```csharp
public class UserService
{
    public void Register(UserDto dto)
    {
        var errors = ValidateUser(dto);
        if (errors.Any())
        {
            throw new ValidationException(string.Join("; ", errors));
        }

        // 注册逻辑...
    }

    private List<string> ValidateUser(UserDto dto)
    {
        var errors = new List<string>();

        var nameCtx = new ValidateContext<string>(dto.Name);
        nameCtx.MustNotNullOrEmptyOrWhiteSpace();
        errors.AddRange(nameCtx.GetErrorMessages());

        var ageCtx = new ValidateContext<int>(dto.Age);
        ageCtx.MustGreaterThan(0);
        ageCtx.MustLessThan(150);
        errors.AddRange(ageCtx.GetErrorMessages());

        return errors;
    }
}
```

## 7. 方法汇总

### ValidateContext 验证方法

| 方法 | 说明 | 支持类型 |
|------|------|----------|
| `MustNotNull(msg?)` | 值不能为 null | 全部 |
| `MustBeNull(msg?)` | 值必须为 null | 全部 |
| `MustEqualTo(value, msg?)` | 必须等于指定值 | 全部 |
| `MustNotEqualTo(value, msg?)` | 不能等于指定值 | 全部 |
| `MustGreaterThan(value, msg?)` | 必须大于指定值 | IComparable |
| `MustGreaterThanOrEqualTo(value, msg?)` | 必须大于等于指定值 | IComparable |
| `MustLessThan(value, msg?)` | 必须小于指定值 | IComparable |
| `MustLessThanOrEqualTo(value, msg?)` | 必须小于等于指定值 | IComparable |

### 数字验证扩展

> 数字验证实际上使用的是 `ValidateContext` 的基础验证方法（见上方表格），而非独立的扩展方法。

### 字符串验证扩展

| 方法 | 说明 |
|------|------|
| `MustNotNullOrEmptyOrWhiteSpace(msg?)` | 不能为空或仅包含空白 |
| `MustLengthInRange(min?, max?, msg?)` | 长度范围 |
| `MustEmailAddress(msg?)` | 邮箱格式 |
| `MustCellPhone(msg?)` | 手机号格式 |
| `MustIdCard(msg?)` | 身份证格式 |
| `MustMatchRegex(pattern, msg?)` | 正则匹配 |
| `TrimValue()` | 自动 Trim 值 |
| `ToUpperValue()` | 自动转大写 |
| `ToLowerValue()` | 自动转小写 |

### 集合验证扩展

| 方法 | 说明 |
|------|------|
| `MustNotNullOrEmpty(msg?)` | 不能为空 |
| `MustBeNullOrEmpty(msg?)` | 必须为空 |
| `RuleForEach(validator)` | 循环验证集合中每个元素 |
