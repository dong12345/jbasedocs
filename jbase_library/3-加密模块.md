# 加密模块

JBaseLibrary 提供了完整的加密解密工具集，包括 MD5、SHA256、AES、DES 等常用加密算法，以及支持 URL 安全的 Base64 编解码。

## 1. MD5 加密

位于 `JBaseLibrary.Encrypt` 命名空间，提供 MD5 哈希计算功能。

### 1.1 MD5 字符串加密

```csharp
public static string MD5(string source)
```

对字符串进行 MD5 加密，返回 32 位大写十六进制字符串。

```csharp
// 示例
string source = "password";
string hash = MD5Encrypt.MD5(source);

// 输出: "5F4DCC3B5AA765D61D8327DEB882CF99"
```

### 1.2 MD5 流加密

```csharp
public static string MD5(Stream stream)
```

对流数据进行 MD5 加密，自动将流指针调整到起始位置。

```csharp
// 示例
using var stream = File.OpenRead("document.pdf");
string hash = MD5Encrypt.MD5(stream);
```

### 1.3 MD5 文件加密

```csharp
public static string MD5File(string absPath)
```

对文件进行 MD5 加密。

```csharp
// 示例
string hash = MD5Encrypt.MD5File("C:\\data\\file.txt");
```

### 1.4 注意事项

> **注意**：MD5 是哈希算法，不是加密算法，无法解密。适用于：
> - 文件完整性校验
> - 密码存储（建议搭配盐值使用）
> - 数字签名

## 2. SHA256 加密

位于 `JBaseLibrary.Encrypt` 命名空间，提供 SHA256 哈希计算功能。

### 2.1 SHA256 字符串加密

```csharp
public static string SHA256Hash(string source)
```

对字符串进行 SHA256 加密，返回 Base64UrlSafe 编码结果。

```csharp
// 示例
string source = "password";
string hash = SHA256.SHA256Hash(source);
// 返回 Base64UrlSafe 编码的哈希值
```

> **注意**：文档中描述的"32位大写"是错误的描述，SHA256 实际返回的是 Base64UrlSafe 编码格式的字符串。

### 2.2 SHA256 流加密

```csharp
public static string SHA256Hash(Stream stream)
```

对流数据进行 SHA256 加密。

### 2.3 SHA256 文件加密

```csharp
public static string SHA256HashFile(string absPath)
```

对文件进行 SHA256 加密。

## 3. AES 加解密

位于 `JBaseLibrary.Encrypt` 命名空间，提供 AES 对称加密解密功能。

### 3.1 AES 加密字符串

```csharp
public static string Encrypt(string encryptString, string encryptKey)
```

| 参数 | 说明 | 要求 |
|------|------|------|
| encryptString | 待加密字符串 | UTF-8 编码 |
| encryptKey | 加密密钥 | 最长 32 位 |

返回十六进制字符串。

```csharp
// 示例
string encrypted = AESEncrypt.Encrypt("Hello World", "Key12345678901234");
Console.WriteLine(encrypted);
// 输出: "1A2B3C4D..."（十六进制字符串）
```

### 3.2 AES 解密字符串

```csharp
public static string Decrypt(string decryptString, string decryptKey)
```

| 参数 | 说明 | 要求 |
|------|------|------|
| decryptString | 待解密字符串 | 十六进制字符串 |
| decryptKey | 解密密钥 | 必须与加密密钥相同 |

```csharp
// 示例
string decrypted = AESEncrypt.Decrypt(encrypted, "Key12345678901234");
Console.WriteLine(decrypted);
// 输出: "Hello World"
```

### 3.3 AES 加密流

```csharp
public static string Encrypt(Stream stream, string encryptKey, string tmpfiledir = null)
```

将流加密后保存为临时文件，返回临时文件路径。

| 参数 | 说明 | 要求 |
|------|------|------|
| stream | 待加密流 | 自动调整指针到起始位置 |
| encryptKey | 加密密钥 | 最长 32 位 |
| tmpfiledir | 临时目录 | 默认使用系统临时目录 |

```csharp
// 示例
using var input = File.OpenRead("document.pdf");
string tempPath = AESEncrypt.Encrypt(input, "Key12345678901234");
// 返回: "C:\\Users\\xxx\\AppData\\Local\\Temp\\DotNetCommon.EncrptTemp\\20260423_a1b2c3d4-xxxx-xxxx-xxxx-xxxxxxxxxxxx"
```

### 3.4 AES 解密流

```csharp
public static string Decrypt(Stream stream, string decryptKey, string tmpfiledir = null)
```

将流解密后保存为临时文件，返回临时文件路径。

### 3.5 密钥处理规则

内部将密钥处理为 32 字节（256 位），密钥格式：

```
key: "Key123" -> 补齐为 32 字节 -> "Key123                          "
iv:  取前 16 字节
```

```csharp
// 密钥处理示例
string key = "Key123";  // 6 字符
// 补齐为 32 字节
// 前 16 字节作为 Key
// 前 16 字节作为 IV
```

### 3.6 加密模式

使用 RijndaelManaged（AES 的前身），填充模式为 PKCS7：

```csharp
using var rijndaelProvider = new RijndaelManaged
{
    Key = key,      // 256 位
    IV = iv,        // 128 位
    Padding = PaddingMode.PKCS7
};
```

### 3.7 使用示例

```csharp
// 完整示例
public class AesDemo
{
    public void Demo()
    {
        string original = "敏感数据";
        string key = "MySecretKey123456789012345678";

        // 加密
        string encrypted = AESEncrypt.Encrypt(original, key);
        Console.WriteLine($"加密: {encrypted}");

        // 解密
        string decrypted = AESEncrypt.Decrypt(encrypted, key);
        Console.WriteLine($"解密: {decrypted}");

        // 结果验证
        Debug.Assert(original == decrypted);
    }
}
```

## 4. DES 加解密

位于 `JBaseLibrary.Encrypt` 命名空间，提供 DES 对称加密解密功能。

> **注意**：DES 已被认为不够安全，建议使用 AES 替代。

### 4.1 DES 加密字符串

```csharp
public static string Encrypt(string encryptString, string encryptKey = "Key123Ace#321Key")
```

| 参数 | 说明 | 要求 |
|------|------|------|
| encryptString | 待加密字符串 | UTF-8 编码 |
| encryptKey | 加密密钥 | 默认值 16 位 |

返回十六进制字符串。

```csharp
// 示例
string encrypted = DESEncrypt.Encrypt("Hello World");
Console.WriteLine(encrypted);
// 输出: "1A2B3C4D..."（十六进制字符串）
```

### 4.2 DES 解密字符串

```csharp
public static string Decrypt(string decryptString, string decryptKey = "Key123Ace#321Key")
```

| 参数 | 说明 | 要求 |
|------|------|--------------|
| decryptString | 待解密字符串 | 十六进制字符串 |
| decryptKey | 解密密钥 | 必须与加密密钥相同 |

```csharp
// 示例
string decrypted = DESEncrypt.Decrypt(encrypted);
Console.WriteLine(decrypted);
// 输出: "Hello World"
```

### 4.3 密钥处理规则

DES 密钥要求 8 字节，内部通过 MD5 将密钥处理为 8 字节：

```csharp
// 密钥处理示例
string key = "Key123Ace#321Key";  // 16 字符
// 1. MD5 加密: MD5("Key123Ace#321Key") = "4F3A2B1C..."
// 2. 取前 8 字符: "4F3A2B1C"
// 3. RGBKey 和 RGBIV 都使用这 8 字节
```

### 4.4 使用示例

```csharp
// 完整示例
public class DesDemo
{
    public void Demo()
    {
        string original = "敏感数据";
        string key = "MySecretKey";

        // 加密
        string encrypted = DESEncrypt.Encrypt(original, key);
        Console.WriteLine($"加密: {encrypted}");

        // 解密
        string decrypted = DESEncrypt.Decrypt(encrypted, key);
        Console.WriteLine($"解密: {decrypted}");

        // 结果验证
        Debug.Assert(original == decrypted);
    }
}
```

## 5. 加密模块汇总

| 类 | 方法 | 输入 | 输出 | 说明 |
|----|------|------|------|------|
| **MD5Encrypt** | `MD5(string)` | 字符串 | 32位大写十六进制 | 哈希，不可逆 |
| | `MD5(Stream)` | 流 | 32位大写十六进制 | 哈希，不可逆 |
| | `MD5File(string)` | 文件路径 | 32位大写十六进制 | 哈希，不可逆 |
| **SHA256** | `SHA256Hash(string)` | 字符串 | Base64UrlSafe | 哈希，不可逆 |
| | `SHA256Hash(Stream)` | 流 | Base64UrlSafe | 哈希，不可逆 |
| | `SHA256HashFile(string)` | 文件路径 | Base64UrlSafe | 哈希，不可逆 |
| **AESEncrypt** | `Encrypt(string, key)` | 字符串 | 十六进制字符串 | 对称加密 |
| | `Decrypt(string, key)` | 十六进制字符串 | 字符串 | 对称解密 |
| | `Encrypt(Stream, key)` | 流 | 临时文件路径 | 流加密 |
| | `Decrypt(Stream, key)` | 流 | 临时文件路径 | 流解密 |
| **DESEncrypt** | `Encrypt(string, key)` | 字符串 | 十六进制字符串 | 对称加密（已过时） |
| | `Decrypt(string, key)` | 十六进制字符串 | 字符串 | 对称解密（已过时） |

## 6. 安全建议

1. **密码存储**：使用 SHA256 + 盐值，而非 MD5
2. **敏感数据加密**：优先使用 AES-256
3. **密钥管理**：密钥不要硬编码在代码中，使用配置或密钥管理服务
4. **DES 已过时**：新项目不要使用 DES
