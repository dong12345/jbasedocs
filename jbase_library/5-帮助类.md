# 帮助类

JBaseLibrary 提供了多个实用帮助类，包括文件操作、Excel 导入导出、二维码生成、JSON 处理、日期处理、拼音转换、压缩、图片压缩、哈希、缓存、验证、搜索、树形结构等。

## 1. FileHelper - 文件操作

位于 `JBaseLibrary.Helpers` 命名空间，提供文件读写、复制、移动、删除等操作。该类实现了 `IDisposable`（无实际资源释放）。

### 1.1 读文件

```csharp
// 同步读文件
string content = FileHelper.FileRead("C:\\test.txt");
string contentWithEncoding = FileHelper.FileRead("C:\\test.txt", Encoding.UTF8);

// 异步读文件
string content = await FileHelper.FileReadAsync("C:\\test.txt");
string content2 = await FileHelper.FileReadAsync("C:\\test.txt", Encoding.UTF8);
```

### 1.2 写文件

```csharp
// 同步写文件
FileHelper.WriteFile("C:\\test.txt", "Hello World");
FileHelper.WriteFile("C:\\test.txt", "Hello", Encoding.UTF8);

// 异步写文件
await FileHelper.WriteFileAsync("C:\\test.txt", "Hello World");
await FileHelper.WriteFileAsync("C:\\test.txt", "Hello", Encoding.UTF8);
```

### 1.3 追加内容

```csharp
FileHelper.FileAdd("C:\\log.txt", "New log entry\r\n");
```

### 1.4 文件操作

```csharp
// 拷贝文件（目标已存在则覆盖）
FileHelper.FileCopy("C:\\source.txt", "C:\\backup.txt");

// 删除文件
FileHelper.FileDel("C:\\temp.txt");

// 删除包含特定名称的文件
FileHelper.FileDel("C:\\temp", "old");  // 删除 temp 目录下路径含 "old" 的所有文件

// 移动文件
FileHelper.FileMove("C:\\old.txt", "C:\\new.txt");

// 取文件后缀名（含 .）
FileHelper.GetPostfixStr("test.png");  // ".png"
```

### 1.5 目录操作

```csharp
// 在指定目录下创建子目录
FileHelper.FolderCreate("C:\\base", "subfolder");

// 递归删除目录
FileHelper.FolderDelete("C:\\temp");

// 复制目录及其内容
FileHelper.CopyDir("C:\\source", "C:\\target");
```

### 1.6 流 / 字符串 / 字节互转

```csharp
using var stream = File.OpenRead("C:\\test.txt");

// 流转字节数组
byte[] bytes = FileHelper.ToBytes(stream);
byte[] bytesAsync = await FileHelper.ToBytesAsync(stream);

// 流转字符串（支持自定义编码和是否释放流）
string content = FileHelper.ToString(stream, Encoding.UTF8);
string contentAsync = await FileHelper.ToStringAsync(stream);

// 复制流后转字符串
string contentCopy = await FileHelper.CopyToStringAsync(stream);

// 字符串转字节数组
byte[] bytes = FileHelper.ToBytes("Hello");
byte[] bytes = FileHelper.ToBytes("你好", Encoding.UTF8);

// 读取文件到字节数组
byte[] fileBytes = FileHelper.Read("C:\\image.png");
```

### 1.7 FileHelper 方法汇总

| 方法 | 说明 |
|------|------|
| `GetPostfixStr(filename)` | 取文件后缀名（含点） |
| `FileRead(path)` / `FileRead(path, encoding)` | 同步读取文件内容 |
| `FileReadAsync(path)` / `FileReadAsync(path, encoding)` | 异步读取文件内容 |
| `WriteFile(path, content)` / `WriteFile(path, content, encoding)` | 同步写入文件 |
| `WriteFileAsync(path, content)` / `WriteFileAsync(path, content, encoding)` | 异步写入文件 |
| `FileAdd(path, content)` | 追加内容到文件 |
| `FileCopy(source, target)` | 复制文件（覆盖目标） |
| `FileDel(path)` | 删除文件 |
| `FileDel(path, fileName)` | 删除目录下路径含 `fileName` 的文件 |
| `FileMove(source, target)` | 移动文件 |
| `FolderCreate(parent, child)` | 在 parent 下创建子目录 |

## 2. ExcelHelper - Excel 操作

位于 `JBaseLibrary.Helpers` 命名空间，提供 Excel 的导入导出功能。基于 NPOI 实现，支持 `.xls`/`.xlsx`。

### 2.1 导出 Excel（固定列）

```csharp
var headers = new Dictionary<string, string>
{
    { "姓名", "Name" },
    { "年龄", "Age" },
    { "邮箱", "Email" }
};

var students = new List<Student>
{
    new Student { Name = "张三", Age = 25, Email = "zhang@example.com" },
    new Student { Name = "李四", Age = 30, Email = "li@example.com" }
};

// 导出为 xlsx 格式（默认）
byte[] bytes = ExcelHelper.ExportExcel("学生信息", headers, students);

// 导出为 xls 格式
byte[] bytesXls = ExcelHelper.ExportExcel("学生信息", headers, students, isXlsx: false);

// 不显示首行大标题
byte[] bytesNoTitle = ExcelHelper.ExportExcel("学生信息", headers, students, isShowTitle: false);

// 自定义标题背景色（RGB）
byte[] bytesCustom = ExcelHelper.ExportExcel(
    "学生信息",
    headers,
    students,
    isXlsx: true,
    isShowTitle: true,
    titleRGB: new byte[] { 26, 140, 155 });
```

### 2.2 导出 Excel（动态列）

支持动态列的 Excel 导出，适用于评分表等场景。

```csharp
// 定义数据模型
public class ScoreRecord
{
    public string Name { get; set; }
    public string School { get; set; }
    public decimal TotalScore { get; set; }
    public List<ExpertScore> ExpertScores { get; set; }
}

public class ExpertScore
{
    public string ExpertName { get; set; }
    public decimal Score { get; set; }
}

// 配置固定列
var fixedHeaders = new Dictionary<string, string>
{
    { "姓名", nameof(ScoreRecord.Name) },
    { "学校", nameof(ScoreRecord.School) },
    { "总分", nameof(ScoreRecord.TotalScore) }
};

// 配置动态列
var dynamicColumnConfig = new DynamicColumnConfig
{
    PropertyName = nameof(ScoreRecord.ExpertScores),  // 数据属性名
    HeaderTitle = "评分详情",                         // 动态列标题
    LabelProperty = nameof(ExpertScore.ExpertName),  // 标签属性名
    ValueProperty = nameof(ExpertScore.Score)        // 值属性名
};

var data = new List<ScoreRecord>
{
    new ScoreRecord
    {
        Name = "赵华",
        School = "信阳师范大学",
        TotalScore = 95,
        ExpertScores = new List<ExpertScore>
        {
            new ExpertScore { ExpertName = "专家1", Score = 90 },
            new ExpertScore { ExpertName = "专家2", Score = 98 },
            new ExpertScore { ExpertName = "专家3", Score = 97 }
        }
    }
};

var bytes = ExcelHelper.ExportExcelWithDynamicColumns(
    "成绩表",
    fixedHeaders,
    dynamicColumnConfig,
    data,
    isXlsx: true,
    isShowTitle: true);
```

生成的 Excel 结构：

| 姓名 | 学校 | 总分 | 评分详情 |
|------|------|------|----------|
| 赵华 | 信阳师范大学 | 95 | 专家1:90分 |
|  |  |  | 专家2:98分 |
|  |  |  | 专家3:97分 |

### 2.3 DynamicColumnConfig 配置说明

```csharp
public class DynamicColumnConfig
{
    /// <summary>动态列数据属性名（对应数据源中的属性名）</summary>
    public string PropertyName { get; set; }

    /// <summary>动态列标题（如"评分详情"）</summary>
    public string HeaderTitle { get; set; }

    /// <summary>标签属性名（如"专家1"中的标签部分）</summary>
    public string LabelProperty { get; set; }

    /// <summary>值属性名（如"50分"中的值部分）</summary>
    public string ValueProperty { get; set; }
}
```

### 2.4 读取 Excel

```csharp
// 从 IFormFile 读取（Web 项目）
var students = ExcelHelper.ReadExcel<Student>(formFile, 0, 1);
// 参数说明：headRowNum = 0（第1行是表头），contentRowNum = 1（从第2行开始读取内容）

// 从文件路径读取
var students = ExcelHelper.ReadExcel<Student>("C:\\students.xlsx", 0, 1);

// 匹配 DescriptionAttribute 读取
var students = ExcelHelper.ReadExcelWithDescription<Student>(formFile, 0, 1);

// 返回原始 DataSet
DataSet ds = ExcelHelper.ReadExcel(formFile, 0, 1);
DataSet ds2 = ExcelHelper.ReadExcel("C:\\students.xlsx", 0, 1);
```

### 2.5 ExcelHelper 方法汇总

| 方法 | 说明 |
|------|------|
| `ExportExcel(name, headers, list, isXlsx?, isShowTitle?, titleRGB?)` | 导出 Excel（固定列） |
| `ExportExcelWithDynamicColumns(name, fixedHeaders, dynamicColumnConfig, list, isXlsx?, isShowTitle?)` | 导出 Excel（支持动态列） |
| `ReadExcel<T>(path, headRowNum, contentRowNum)` | 从路径读取 Excel |
| `ReadExcel<T>(formFile, headRowNum, contentRowNum)` | 从 IFormFile 读取 Excel |
| `ReadExcelWithDescription<T>(path, headRowNum, contentRowNum)` | 读取并匹配 Description |
| `ReadExcelWithDescription<T>(formFile, headRowNum, contentRowNum)` | 同上，IFormFile 重载 |
| `ReadExcel(formFile, headRowNum, contentRowNum)` / `ReadExcel(path, ...)` | 返回原始 DataSet |
| `SetBackgroundColor(style, r, g, b)` | 设置单元格背景色 |

## 3. QrCodeHelper - 二维码生成

位于 `JBaseLibrary.Helpers` 命名空间，基于 SkiaSharp 实现跨平台二维码生成（无 GDI 依赖）。依赖 QRCoder 库生成二维码数据。

### 3.1 生成二维码字节数组

```csharp
// 基本用法
byte[] bytes = QrCodeHelper.GenerateQrCodeBytes("https://example.com");

// 自定义参数
byte[] bytes = QrCodeHelper.GenerateQrCodeBytes(
    url: "https://example.com",
    pixelsPerModule: 10,            // 每个模块的像素大小
    frontColor: SKColors.Black,     // 前景色
    backColor: SKColors.White       // 背景色
);
```

### 3.2 生成 Base64 字符串

```csharp
// 用于 HTML 显示（不含 data:image/png;base64, 前缀，需自行拼接）
string base64 = QrCodeHelper.GenerateQrCodeBase64("https://example.com");

// 前端使用
// <img src="data:image/png;base64,@base64" />
```

### 3.3 保存到文件

```csharp
QrCodeHelper.GenerateQrCodeToFile(
    url: "https://example.com",
    filePath: "C:\\qrcode.png",
    pixelsPerModule: 5);
```

### 3.4 生成二维码流

```csharp
Stream stream = QrCodeHelper.GenerateQrCodeStream("https://example.com");
// 可用于返回 FileStreamResult
```

### 3.5 参数说明

| 参数 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `url` | string | 必填 | 二维码内容 |
| `pixelsPerModule` | int | 5 | 每个模块的像素大小，值越大二维码越大 |
| `frontColor` | SKColor? | Black | 二维码前景色 |
| `backColor` | SKColor? | White | 二维码背景色 |

### 3.6 辅助方法

```csharp
// 解析颜色字符串
var color = QrCodeHelper.ParseColor("#FF0000");   // 红色
var color2 = QrCodeHelper.ParseColor("FF0000");    // 红色（不带#）
var color3 = QrCodeHelper.ParseColor("80FF0000"); // 带透明度的红色（ARGB）
```

## 4. JsonHelper - JSON 处理

位于 `JBaseLibrary.Helpers` 命名空间，封装 Newtonsoft.Json 的常用操作（最简接口）。


## 6. GuidHelper - 顺序 GUID 生成

位于 `JBaseLibrary.Helpers` 命名空间，基于时间戳 + 加密安全随机数生成**严格递增的 GUID**（COMB GUID 实现），适配各数据库的最优排序规则，符合 RFC 4122 标准。

### 6.1 SequentialGuidType 枚举

```csharp
public enum SequentialGuidType
{
    /// <summary>用于 MySql 和 PostgreSql（字符串格式连续有序）</summary>
    AsString,

    /// <summary>用于 Oracle（字节数组格式连续有序）</summary>
    AsBinary,

    /// <summary>用于 SqlServer（GUID 第4部分连续有序）</summary>
    AtEnd
}
```

可通过 `GuidHelper.SequentialGuidType` 静态属性设置默认类型。

### 6.2 生成顺序 GUID

```csharp
// 默认生成（AsString）
Guid guid = GuidHelper.Next();

// 指定类型
Guid sqlServerGuid = GuidHelper.Next(SequentialGuidType.AtEnd);
Guid mysqlGuid = GuidHelper.Next(SequentialGuidType.AsString);
Guid oracleGuid = GuidHelper.Next(SequentialGuidType.AsBinary);

// 修改默认类型（影响后续 Next() 调用）
GuidHelper.SequentialGuidType = SequentialGuidType.AtEnd;
Guid next = GuidHelper.Next();
```

### 6.3 应用场景

| 数据库 | 推荐类型 |
|--------|----------|
| SQL Server | `AtEnd` |
| MySQL | `AsString` |
| PostgreSQL | `AsString` |
| Oracle | `AsBinary` |

> 顺序 GUID 在 B+Tree 索引（如聚集索引）场景下能避免随机 GUID 导致的频繁页分裂，**显著提升写入性能**。

## 7. HashHelper - 哈希处理

位于 `JBaseLibrary.Helpers` 命名空间，提供组合哈希码计算辅助方法（参数顺序会影响结果）。

### 7.1 计算哈希码

```csharp
// 计算单个对象的哈希码
int hash1 = HashHelper.GetHashCode(user);

// 计算两个对象的组合哈希码
int hash2 = HashHelper.GetHashCode(name, age);

// 计算多个对象的组合哈希码（最多支持 13 个参数的重载）
int hash3 = HashHelper.GetHashCode(id, name, age, email);

// 使用参数数组计算多个对象的组合哈希码
int hash4 = HashHelper.GetHashCode(items);
```

> 实现原理：使用经典算法 `hash = hash * PrimeNumber(486187739) + element.GetHashCode()`，`DefaultHashValue = 31`。

### 7.2 适用场景

- 实体 `GetHashCode` 重写
- 缓存键生成
- 数据签名、指纹

## 8. TreeHelper - 树形结构

位于 `JBaseLibrary.Helpers` 命名空间，提供反射式树形结构构建辅助方法（无需在数据模型上定义 `Children` 属性）。

### 8.1 获取树形数据

```csharp
public class Category
{
    public int Id { get; set; }
    public int ParentId { get; set; }
    public string Name { get; set; }
    public int Sort { get; set; }
}

var allCategories = GetAllCategories();  // 所有分类数据

var tree = TreeHelper.GetTreeStructureList(
    allCategories,
    "0",           // 父级 key 值（根节点的父级值）
    "Id",          // key 字段名
    "ParentId",    // 父级 key 字段名
    "Name",        // name 字段名
    "Sort"         // sort 字段名（可为空）
);
```

### 8.2 TreeModel 结构

```csharp
/// <summary>树形节点模型</summary>
public class TreeModel
{
    public string Key { set; get; }             // 关键词
    public string ParentKey { set; get; }       // 父级关键词
    public string Name { set; get; }             // 名称
    public int Sort { get; set; }               // 排序
    public List<TreeModel> Child { set; get; }   // 子集
}
```

> 与 `TreeHelper` 对应的"硬类型"树操作见 [扩展方法 - TreeExtensions](4-扩展方法) 中 `ToTree` / `FetchToTree`。

## 9. VerifyCodeHelper - 验证码生成

位于 `JBaseLibrary.Helpers` 命名空间，基于 SkiaSharp 实现跨平台验证码生成。

### 9.1 生成验证码图片（byte[]）

```csharp
// 生成验证码图片，返回 byte[]
byte[] imageBytes = VerifyCodeHelper.Draw(out string code, 4);
// code 输出: 随机4位验证码，如 "X7kB"
Console.WriteLine(code);

// 指定长度
byte[] imageBytes6 = VerifyCodeHelper.Draw(out string code6, 6);
```

### 9.2 生成验证码 Base64 字符串

```csharp
// 返回 Base64 字符串，可直接用于前端展示（不含 data:image/png;base64, 前缀）
string base64 = VerifyCodeHelper.GetBase64String(out string code, 4);
// 前端使用: <img src="data:image/png;base64,@base64" />
```

### 9.3 生成验证码（元组形式）

```csharp
// 同时返回验证码和图片 Base64
var (code, imgBase64) = VerifyCodeHelper.New(4);
Console.WriteLine(code);      // "A3fK"
Console.WriteLine(imgBase64); // "iVBORw0KGgoAAAANSUhEUgAA..."
```

### 9.4 生成纯数字验证码（不绘图）

```csharp
// 生成纯数字验证码（不生成图片）
string code = VerifyCodeHelper.GenerateCode(4, isOnlyNumber: true);
// 输出: "3847"

// 生成数字+字母验证码
string code = VerifyCodeHelper.GenerateCode(4, isOnlyNumber: false);
// 输出: "K5X9"
```

### 9.5 生成随机字符串（不绘图）

```csharp
// 生成数字+字母随机字符串（去除了易混淆字符 0/O/1/l/I）
string random = VerifyCodeHelper.GenerateRandom(4);
// 输出: "X7kB"（从 2,3,4,5,6,8,9,a,b,d,e,f,h,k,m,n,r,x,y,A,B,C,D,E,F,G,H,J,K,L,M,N,P,R,S,T,W,X,Y 中随机选取）

// 指定长度
string random6 = VerifyCodeHelper.GenerateRandom(6);
```

### 9.6 VerifyCodeHelper 方法汇总

| 方法 | 说明 |
|------|------|
| `Draw(out code, length)` | 生成验证码图片，返回 byte[] |
| `GetBase64String(out code, length)` | 生成验证码 Base64 字符串 |
| `New(length)` | 生成验证码，返回 `(code, imgBase64)` 元组 |

| `GenerateCode(codeCount, isOnlyNumber)` | 生成纯数字或混合验证码（不绘图） |

## 10. ZipHelper - 压缩与解压缩

位于 `JBaseLibrary.Helpers` 命名空间，基于 ICSharpCode.SharpZipLib 实现。

### 10.1 压缩文件

```csharp
// 压缩文件列表（保留原文件名）
ZipHelper.ZipFile("C:\\test.zip", "C:\\test.txt", "D:\\data.db");

// 压缩文件列表（自定义压缩包内的文件名）
ZipHelper.ZipFile("C:\\test.zip",
    ("C:\\test.txt", "test.txt"),
    ("D:\\data.db", "db\\data.db"));

// 递归压缩整个文件夹（包含文件夹本身）
ZipHelper.ZipFolder("C:\\backup.zip", "C:\\myFolder", "D:\\anotherFolder");

// 压缩文件夹内容（不包含最外层文件夹本身）
ZipHelper.ZipFolderContent("C:\\content.zip", "C:\\myFolder");
```

### 10.2 解压缩文件

```csharp
// 解压到指定文件夹（自动创建）
ZipHelper.UnZipFile("C:\\test.zip", "C:\\outputDir");
```

### 10.3 ZipHelper 方法汇总

| 方法 | 说明 |
|------|------|
| `ZipFile(dest, params fileAbsPaths)` | 压缩多个文件（保留原文件名） |
| `ZipFile(dest, params (path, name)[])` | 压缩多个文件（自定义包内名） |
| `ZipFolder(dest, params folderPaths)` | 递归压缩文件夹（含文件夹本身） |
| `ZipFolderContent(dest, folderPath)` | 压缩文件夹内容（不含文件夹本身） |
| `UnZipFile(srcZipFile, destDir)` | 解压 ZIP 到指定目录 |

## 11. ImageCompressionHelper - 图片压缩与缩略图

位于 `JBaseLibrary.Helpers` 命名空间，基于 SixLabors.ImageSharp 实现跨平台图片处理（不依赖 GDI）。

### 11.1 主要方法

```csharp
// 压缩图片流
long savedBytes = await ImageCompressionHelper.CompressImageAsync(
    inputStream,
    outputStream,
    options);

// 压缩 IFormFile，保存到指定路径
var result = await ImageCompressionHelper.CompressImageAsync(file, "C:\\out.jpg", options);

// 压缩 IFormFile，返回 byte[]
byte[] compressed = await ImageCompressionHelper.CompressImageAsync(file, options);

// 压缩文件
long savedBytes = await ImageCompressionHelper.CompressImageFileAsync("in.jpg", "out.jpg", options);

// 压缩字节数组
byte[] compressed = await ImageCompressionHelper.CompressImageBytesAsync(inputBytes, options);

// 检测是否为支持的图片格式
bool ok = ImageCompressionHelper.IsSupportedImageFormat(stream);
bool ok = ImageCompressionHelper.IsSupportedImageFormat(bytes);
bool ok = ImageCompressionHelper.IsSupportedImageFormat(file);

// 生成缩略图（同样有 Stream / IFormFile / 文件路径 / 字节数组 多个重载）
await ImageCompressionHelper.GenerateThumbnailAsync(inputStream, outputStream, options);
```

### 11.2 CompressionOptions / ThumbnailOptions

通过 `CompressionOptions` / `ThumbnailOptions` 设置压缩质量、目标尺寸、输出格式等参数。

## 12. ValidateHelper - 通用格式校验

位于 `JBaseLibrary.Helpers` 命名空间，提供一组返回 `bool` 的通用格式判断方法。常用于不需要错误聚合的简单场景。

### 12.1 邮箱 / 手机号 / 身份证

```csharp
ValidateHelper.IsEmail("user@example.com");                    // true
ValidateHelper.IsEmail("user@example.com", isRestrict: true);  // true（严格 RFC 5322 模式）

ValidateHelper.IsMobileNumber("13800138000");                  // true

ValidateHelper.IsIdCard("11010519491231002X");                 // true
ValidateHelper.IsIdCard("110105194912310026");                 // true
```

### 12.2 URL / IP / Mac / 银行卡 / Base64

```csharp
ValidateHelper.IsUrl("https://example.com");
ValidateHelper.IsIpAddress("192.168.1.1");
ValidateHelper.IsMac("00-1B-44-11-3A-B7");       // 也支持无分隔符 12 位大写
ValidateHelper.IsBandCard("6222021234567890123"); // 16 位或 19 位数字
ValidateHelper.IsBase64String("SGVsbG8=");
```

### 12.3 日期

```csharp
ValidateHelper.IsDate("20240101", "yyyyMMdd");
ValidateHelper.IsDate("20240101", "yyyyMMdd", null, DateTimeStyles.None);
```

### 12.4 中文 / 数字 / 长度

```csharp
ValidateHelper.IsChinese("中国");
ValidateHelper.IsContainsChinese("中国abc");
ValidateHelper.IsInteger("-123");
ValidateHelper.IsPositiveInteger("123");
ValidateHelper.IsContainsNumber("abc123");

// 一个中文按 2 个字符计
ValidateHelper.IsConformRange("张三", 1, 10);  // true（"张三" 计为 4）
```

### 12.5 SQL 注入防护判断

```csharp
ValidateHelper.IsSafeString("helloworld");   // true
ValidateHelper.IsSafeString("select * from"); // false（包含 `*`、空格等危险字符）
```

> 实际项目中建议使用参数化查询，而非依赖此判断。

## 13. SearchHelper - 动态查询

位于 `JBaseLibrary.Helpers` 命名空间，基于 `SearchAttribute` + `OperationType` 实现动态查询条件拼接。

### 13.1 定义搜索 DTO

```csharp
using JBaseLibrary.Attributes;
using JBaseLibrary.Enums;

public class UserSearch
{
    [Search("Name", OperationType.Like)]
    public string NameLike { get; set; }

    [Search("Age", OperationType.GreaterThanOrEqual)]
    public int? MinAge { get; set; }

    [Search("Status", OperationType.Equal)]
    public int? Status { get; set; }
}
```

### 13.2 在 Service 中使用

```csharp
// 直接搜索（IQueryable.Where）
var query = dbContext.Users.Search(searchDto);

// 仅生成 Expression（可继续拼接）
Expression<Func<User, bool>> exp = SearchHelper.GenerateExpressionCondition<User, UserSearch>(searchDto);
var query2 = dbContext.Users.Where(exp).OrderBy("CreateTime");
```

### 13.3 支持的操作符（OperationType）

| 值 | 含义 | SQL |
|----|------|-----|
| `None` | 不参与查询 | - |
| `Equal` | 相等 | `=` |
| `Like` | 包含（string.Contains） | `LIKE` |
| `GreaterThan` | 大于 | `>` |
| `LessThan` | 小于 | `<` |
| `GreaterThanOrEqual` | 大于等于 | `>=` |
| `LessThanOrEqual` | 小于等于 | `<=` |

> 仅当搜索值不为 `null` 且不为空字符串时才参与条件拼接。

## 14. CacheExpirationHelper - 缓存过期时间（防雪崩）

位于 `JBaseLibrary.Helpers` 命名空间，用于生成带随机偏移的缓存过期时间，避免大量缓存同时过期（缓存雪崩）。

```csharp
// 24 小时缓存，±10% 随机偏移
TimeSpan base24h = TimeSpan.FromHours(24);
int expirationSeconds = CacheExpirationHelper.GetRandomExpirationSeconds(base24h);
// 结果可能是 77760 ~ 95040 秒之间的随机值（21.6 ~ 26.4 小时）
```

> 仅支持正数（`TotalSeconds > 0`），异常时抛 `ArgumentException`。
