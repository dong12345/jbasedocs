# 帮助类

JBaseLibrary 提供了多个实用帮助类，包括文件操作、Excel 导入导出、二维码生成、JSON 处理、日期处理、拼音转换等。

## 1. FileHelper - 文件操作

位于 `JBaseLibrary.Helpers` 命名空间，提供文件读写、复制、移动、删除等操作。

### 1.1 读文件

```csharp
// 同步读文件
string content = FileHelper.FileRead("C:\\test.txt");
string contentWithEncoding = FileHelper.FileRead("C:\\test.txt", Encoding.UTF8);

// 异步读文件
string content = await FileHelper.FileReadAsync("C:\\test.txt");
```

### 1.2 写文件

```csharp
// 同步写文件
FileHelper.WriteFile("C:\\test.txt", "Hello World");
FileHelper.WriteFile("C:\\test.txt", "Hello", Encoding.UTF8);

// 异步写文件
await FileHelper.WriteFileAsync("C:\\test.txt", "Hello World");
```

### 1.3 追加内容

```csharp
FileHelper.FileAdd("C:\\log.txt", "New log entry\r\n");
```

### 1.4 文件操作

```csharp
// 拷贝文件
FileHelper.FileCopy("C:\\source.txt", "C:\\backup.txt");

// 删除文件
FileHelper.FileDel("C:\\temp.txt");

// 删除包含特定名称的文件
FileHelper.FileDel("C:\\temp", "old");  // 删除 temp 目录下包含 "old" 的文件

// 移动文件
FileHelper.FileMove("C:\\old.txt", "C:\\new.txt");
```

### 1.5 目录操作

```csharp
// 创建目录
FileHelper.FolderCreate("C:\\base", "subfolder");  // 在 base 下创建 subfolder

// 删除目录（递归删除）
FileHelper.FolderDelete("C:\\temp");  // 删除整个目录及其内容

// 复制目录
FileHelper.CopyDir("C:\\source", "C:\\target");
```

### 1.6 流操作

```csharp
using var stream = File.OpenRead("C:\\test.txt");

// 流转字节数组
byte[] bytes = FileHelper.ToBytes(stream);
byte[] bytesAsync = await FileHelper.ToBytesAsync(stream);

// 流转字符串
string content = FileHelper.ToString(stream);
string contentAsync = await FileHelper.ToStringAsync(stream);

// 字符串转字节数组
byte[] bytes = FileHelper.ToBytes("Hello");
byte[] bytes = FileHelper.ToBytes("你好", Encoding.UTF8);

// 读取文件到字节数组
byte[] fileBytes = FileHelper.Read("C:\\image.png");
```

### 1.7 FileHelper 方法汇总

| 方法 | 说明 |
|------|------|
| `FileRead(path)` | 同步读取文件内容 |
| `FileReadAsync(path)` | 异步读取文件内容 |
| `WriteFile(path, content)` | 同步写入文件 |
| `WriteFileAsync(path, content)` | 异步写入文件 |
| `FileAdd(path, content)` | 追加内容到文件 |
| `FileCopy(source, target)` | 复制文件 |
| `FileDel(path)` | 删除文件 |
| `FileMove(source, target)` | 移动文件 |
| `FolderCreate(parent, child)` | 创建子目录 |
| `FolderDelete(path)` | 递归删除目录 |
| `CopyDir(src, target)` | 复制整个目录 |
| `ToBytes(stream)` | 流转字节数组 |
| `ToString(stream)` | 流转字符串 |
| `Read(path)` | 读取文件到字节数组 |

## 2. ExcelHelper - Excel 操作

位于 `JBaseLibrary.Helpers` 命名空间，提供 Excel 的导入导出功能。

### 2.1 导出 Excel

```csharp
var headers = new Dictionary<string, string>
{
    { "姓名", "Name" },
    { "年龄", "Age" },
    { "邮箱", "Email" }
};

var students = new List<Student>
{
    new Student { Name = "张三", Age = 25, Email = "zhang@example.com" },
    new Student { Name = "李四", Age = 30, Email = "li@example.com" }
};

// 导出为 byte[]
byte[] bytes = ExcelHelper.ExportExcel("学生信息", headers, students);

// 导出为 xlsx 格式（默认）
byte[] bytes = ExcelHelper.ExportExcel("学生信息", headers, students);

// 导出为 xls 格式
byte[] bytes = ExcelHelper.ExportExcel("学生信息", headers, students, isXlsx: false);

// 导出为 xlsx 格式（显式指定）
byte[] bytes = ExcelHelper.ExportExcel("学生信息", headers, students, isXlsx: true);

// 不显示标题
byte[] bytes = ExcelHelper.ExportExcel("学生信息", headers, students, isXlsx: true, isShowTitle: false);

// 自定义标题背景色
byte[] bytes = ExcelHelper.ExportExcel("学生信息", headers, students, isXlsx: true, isShowTitle: true, new byte[] { 26, 140, 155 });
```

### 2.2 导出 Excel（动态列）

支持动态列的 Excel 导出，适用于评分表等场景。

```csharp
// 定义数据模型
public class ScoreRecord
{
    public string Name { get; set; }
    public string School { get; set; }
    public decimal TotalScore { get; set; }
    public List<ExpertScore> ExpertScores { get; set; }
}

public class ExpertScore
{
    public string ExpertName { get; set; }
    public decimal Score { get; set; }
}

// 配置固定列
var fixedHeaders = new Dictionary<string, string>
{
    { "姓名", nameof(ScoreRecord.Name) },
    { "学校", nameof(ScoreRecord.School) },
    { "总分", nameof(ScoreRecord.TotalScore) }
};

// 配置动态列
var dynamicColumnConfig = new DynamicColumnConfig
{
    PropertyName = nameof(ScoreRecord.ExpertScores),  // 数据属性名
    HeaderTitle = "评分详情",                         // 动态列标题
    LabelProperty = nameof(ExpertScore.ExpertName), // 标签属性名
    ValueProperty = nameof(ExpertScore.Score)       // 值属性名
};

var data = new List<ScoreRecord>
{
    new ScoreRecord
    {
        Name = "赵华",
        School = "信阳师范大学",
        TotalScore = 95,
        ExpertScores = new List<ExpertScore>
        {
            new ExpertScore { ExpertName = "专家1", Score = 90 },
            new ExpertScore { ExpertName = "专家2", Score = 98 },
            new ExpertScore { ExpertName = "专家3", Score = 97 }
        }
    }
};

var bytes = ExcelHelper.ExportExcelWithDynamicColumns(
    "成绩表",
    fixedHeaders,
    dynamicColumnConfig,
    data,
    isXlsx: true,  // 默认为 xlsx 格式
    isShowTitle: true
);
```

生成的 Excel 结构：

| 姓名 | 学校 | 总分 | 评分详情 |
|------|------|------|----------|
| 赵华 | 信阳师范大学 | 95 | 专家1:90分 |
| | | | 专家2:98分 |
| | | | 专家3:97分 |

### 2.3 DynamicColumnConfig 配置说明

```csharp
public class DynamicColumnConfig
{
    /// <summary>
    /// 动态列数据属性名（对应数据源中的属性名）
    /// </summary>
    public string PropertyName { get; set; }

    /// <summary>
    /// 动态列标题（如"评分详情"）
    /// </summary>
    public string HeaderTitle { get; set; }

    /// <summary>
    /// 标签属性名（如"专家1"中的标签部分）
    /// </summary>
    public string LabelProperty { get; set; }

    /// <summary>
    /// 值属性名（如"50分"中的值部分）
    /// </summary>
    public string ValueProperty { get; set; }
}
```

### 2.4 读取 Excel

```csharp
// 从 IFormFile 读取（Web 项目）
var students = ExcelHelper.ReadExcel<Student>(formFile, 0, 1);
// 参数说明：headRowNum = 0（第1行是表头），contentRowNum = 1（从第2行开始读取内容）

// 从文件路径读取
var students = ExcelHelper.ReadExcel<Student>("C:\\students.xlsx", 0, 1);

// 匹配 DescriptionAttribute 读取
var students = ExcelHelper.ReadExcelWithDescription<Student>(formFile, 0, 1);
```

### 2.5 ExcelHelper 方法汇总

| 方法 | 说明 |
|------|------|
| `ExportExcel(name, headers, list)` | 导出 Excel（固定列） |
| `ExportExcelWithDynamicColumns(name, fixedHeaders, dynamicColumnConfig, list)` | 导出 Excel（支持动态列） |
| `ReadExcel<T>(path, headRowNum, contentRowNum)` | 从路径读取 Excel |
| `ReadExcel<T>(formFile, headRowNum, contentRowNum)` | 从 IFormFile 读取 Excel |
| `ReadExcelWithDescription<T>(path, headRowNum, contentRowNum)` | 读取并匹配 Description |

## 3. QrCodeHelper - 二维码生成

位于 `JBaseLibrary.Helpers` 命名空间，基于 SkiaSharp 实现跨平台二维码生成。

### 3.1 生成二维码字节数组

```csharp
// 基本用法
byte[] bytes = QrCodeHelper.GenerateQrCodeBytes("https://example.com");

// 自定义参数
byte[] bytes = QrCodeHelper.GenerateQrCodeBytes(
    url: "https://example.com",
    pixelsPerModule: 10,  // 每个模块的像素大小
    frontColor: SKColors.Black,  // 前景色
    backColor: SKColors.White     // 背景色
);
```

### 3.2 生成 Base64 字符串

```csharp
// 用于 HTML 显示
string base64 = QrCodeHelper.GenerateQrCodeBase64("https://example.com");
// 输出: "data:image/png;base64,..." 格式需要自己拼接

// 前端使用
// <img src="data:image/png;base64,@base64" />
```

### 3.3 保存到文件

```csharp
QrCodeHelper.GenerateQrCodeToFile(
    url: "https://example.com",
    filePath: "C:\\qrcode.png",
    pixelsPerModule: 5
);
```

### 3.4 生成二维码流

```csharp
Stream stream = QrCodeHelper.GenerateQrCodeStream("https://example.com");
// 可用于返回 FileStreamResult
```

### 3.5 参数说明

| 参数 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| url | string | 必填 | 二维码内容 |
| pixelsPerModule | int | 5 | 每个模块的像素大小，值越大二维码越大 |
| frontColor | SKColor? | Black | 二维码前景色 |
| backColor | SKColor? | White | 二维码背景色 |

### 3.6 辅助方法

```csharp
// 解析颜色字符串
var color = QrCodeHelper.ParseColor("#FF0000");  // 红色
var color2 = QrCodeHelper.ParseColor("FF0000");   // 红色（不带#）
var color3 = QrCodeHelper.ParseColor("FF000080"); // 带透明度的红色
```

## 5. DateTimeHelper - 日期处理

位于 `JBaseLibrary.Helpers` 命名空间，提供日期相关的辅助方法。

### 5.1 日期解析

```csharp
// 按指定格式解析日期
DateTime date = DateTimeHelper.ParseExact("20240101", "yyyyMMdd");
```

### 5.2 日期拼接

```csharp
// 拼接 Date 和 TimeSpan
var date = DateTime.Now.Date;
var time = new TimeSpan(10, 30, 0);
DateTime result = DateTimeHelper.ConcatDateAndTime(date, time);
// result = 2024-04-15 10:30:00
```

### 5.3 周判断

```csharp
// 判断是否本周
bool isThisWeek = DateTimeHelper.IsThisWeek(targetDate);

// 计算星期几（1-7，1代表星期一）
int weekday = DateTimeHelper.GetWeekDay(2024, 4, 15);  // 1
int weekday2 = DateTimeHelper.CaculateWeekDay(new DateTime(2024, 4, 15));  // 1
```

### 5.4 本周日期范围

```csharp
// 计算本周起始日期（星期一）
DateTime monday = DateTimeHelper.CalculateFirstDateOfWeek(DateTime.Now);

// 计算本周结束日期（星期日）
DateTime sunday = DateTimeHelper.CalculateLastDateOfWeek(DateTime.Now);
```

### 5.5 日期差异

```csharp
var start = new DateTime(2024, 1, 1);
var end = new DateTime(2024, 4, 15);

double milliseconds = DateTimeHelper.DiffMilliseconds(start, end);
double seconds = DateTimeHelper.DiffSeconds(start, end);
double minutes = DateTimeHelper.DiffMinutes(start, end);
double hours = DateTimeHelper.DiffHours(start, end);
int days = DateTimeHelper.DiffDays(start, end);
```

### 5.6 集合日期操作

```csharp
var dates = new List<DateTime?> { DateTime.Now, null, DateTime.Now.AddDays(-1) };

// 获取最小时间
DateTime? min = DateTimeHelper.GetMinTime(dates);

// 获取最大时间
DateTime? max = DateTimeHelper.GetMaxTime(dates);
```

## 8. TreeHelper - 树形结构

位于 `JBaseLibrary.Helpers` 命名空间，提供树形结构构建辅助方法。

### 8.1 获取树形数据

```csharp
var allCategories = GetAllCategories();  // 所有分类数据

var tree = TreeHelper.GetTreeStructureList(
    allCategories,
    "0",           // 父级 key 值（根节点的父级值）
    "Id",          // key 字段名
    "ParentId",    // 父级 key 字段名
    "Name",        // name 字段名
    "Sort"         // sort 字段名（可为空）
);

// 返回 TreeModel 列表
public class TreeModel
{
    public string Key { get; set; }        // 关键词
    public string ParentKey { get; set; }  // 父级关键词
    public string Name { get; set; }        // 名称
    public int Sort { get; set; }          // 排序
    public List<TreeModel> Child { get; set; }  // 子集
}
```

### 8.2 TreeModel 结构

```csharp
// 树形节点模型
public class TreeModel
{
    /// <summary>关键词</summary>
    public string Key { set; get; }

    /// <summary>父级关键词</summary>
    public string ParentKey { set; get; }

    /// <summary>名称</summary>
    public string Name { set; get; }

    /// <summary>排序</summary>
    public int Sort { get; set; }

    /// <summary>子集</summary>
    public List<TreeModel> Child { set; get; }
}
```

## 9. VerifyCodeHelper - 验证码生成

位于 `JBaseLibrary.Helpers` 命名空间，基于 SkiaSharp 实现跨平台验证码生成。

### 9.1 生成验证码图片（byte[]）

```csharp
// 生成验证码图片，返回 byte[]
byte[] imageBytes = VerifyCodeHelper.Draw(out string code, 4);
Console.WriteLine(code);  // 输出: 随机4位验证码，如 "X7kB"

// 指定长度
byte[] imageBytes = VerifyCodeHelper.Draw(out string code, 6);
Console.WriteLine(code);  // 输出: 6位验证码
```

### 9.2 生成验证码 Base64 字符串

```csharp
// 返回 Base64 字符串，可直接用于前端展示
string base64 = VerifyCodeHelper.GetBase64String(out string code, 4);
Console.WriteLine(code);  // 输出: 随机验证码
// 前端使用: <img src="data:image/png;base64,@base64" />
```

### 9.3 生成验证码（元组形式）

```csharp
// 同时返回验证码和图片 Base64
var (code, imgBase64) = VerifyCodeHelper.New(4);
Console.WriteLine(code);      // 输出: "A3fK"
Console.WriteLine(imgBase64);  // 输出: "iVBORw0KGgoAAAANSUhEUgAA..."
```

### 9.4 生成随机字符串

```csharp
// 生成随机字符串（数字+字母，去除了易混淆字符）
string random = VerifyCodeHelper.GenerateRandom(4);
// 输出: "X7kB"（从 2,3,4,5,6,8,9,a,b,d,e,f,h,k,m,n,r,x,y,A,B,C,D,E,F,G,H,J,K,L,M,N,P,R,S,T,W,X,Y 中随机选取）

// 指定长度
string random = VerifyCodeHelper.GenerateRandom(6);
```

### 9.5 生成纯数字验证码

```csharp
// 生成纯数字验证码
string code = VerifyCodeHelper.GenerateCode(4, isOnlyNumber: true);
// 输出: "3847"

// 生成数字+字母验证码
string code = VerifyCodeHelper.GenerateCode(4, isOnlyNumber: false);
// 输出: "K5X9"
```

### 9.6 VerifyCodeHelper 方法汇总

| 方法 | 说明 |
|------|------|
| `Draw(out code, length)` | 生成验证码图片，返回 byte[] |
| `GetBase64String(out code, length)` | 生成验证码 Base64 字符串 |
| `New(length)` | 生成验证码，返回 (code, imgBase64) 元组 |
| `GenerateRandom(length)` | 生成随机字符串 |
| `GenerateCode(codeCount, isOnlyNumber)` | 生成纯数字或混合验证码 |
