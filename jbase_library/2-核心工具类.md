# 核心工具类

本文档详细介绍 JBaseLibrary 中的核心工具类，包括参数断言、泛型相等基类、Base64 编码工具、特性、对象反射访问器、对象比较器、对象映射器等。

## 1. Ensure - 参数断言

位于 `JBaseLibrary` 命名空间，用于在方法入口处进行参数校验。

### 1.1 That - 确保条件为真

```csharp
public static void That(bool condition, string message = "给定条件为false")
public static void That<TException>(bool condition, string message = "给定条件为false") where TException : Exception
```

当 `condition` 为 `false` 时抛出 `ArgumentException`（或指定的异常类型）。

```csharp
Ensure.That(isValid, "参数验证失败");
Ensure.That<ArgumentNullException>(value != null, "值不能为空");
```

### 1.2 Not - 确保条件为假

```csharp
public static void Not(bool condition, string message = "给定条件为true")
public static void Not<TException>(bool condition, string message = "给定条件为true") where TException : Exception
```

当 `condition` 为 `true` 时抛出 `ArgumentException`（或指定的异常类型）。

```csharp
Ensure.Not(string.IsNullOrEmpty(name), "名称不能为空");
```

### 1.3 NotNull - 确保对象不为空

```csharp
public static void NotNull<T>(T value, string argName) where T : class
```

当 `value` 为 `null` 时抛出 `ArgumentNullException`，异常信息包含参数名。

```csharp
public void ProcessUser(User user)
{
    Ensure.NotNull(user, nameof(user));
    // 后续处理...
}
```

### 1.4 Equal - 确保值相等

```csharp
public static void Equal<T>(T left, T right, string message = "值必须相等")
```

当 `left` 和 `right` 不相等时抛出 `ArgumentException`。

```csharp
Ensure.Equal(expected, actual, "值不匹配");
```

### 1.5 NotEqual - 确保值不相等

```csharp
public static void NotEqual<T>(T left, T right, string message = "值不能相等")
```

当 `left` 和 `right` 相等时抛出 `ArgumentException`。

```csharp
Ensure.NotEqual(status, 0, "状态不能为0");
```

### 1.6 NotNullOrEmpty - 确保集合不为空

```csharp
public static void NotNullOrEmpty<T>(ICollection<T> collection, string message = "Collection must not be null or empty.")
```

当集合为 `null` 或空时抛出 `ArgumentException`。

```csharp
public void ProcessItems(List<Item> items)
{
    Ensure.NotNullOrEmpty(items, "项目列表不能为空");
    // 后续处理...
}
```

### 1.7 NotNullOrWhiteSpace - 确保字符串不为空

```csharp
public static void NotNullOrWhiteSpace(string value, string message = "String must not be null, empty or whitespace.")
```

当字符串为 `null`、空或仅包含空白时抛出 `ArgumentException`。

```csharp
public void ProcessName(string name)
{
    Ensure.NotNullOrWhiteSpace(name, "名称不能为空");
    // 后续处理...
}
```

### 1.8 Exists - 确保文件/目录存在

```csharp
public static void Exists(DirectoryInfo directoryInfo)   // 抛 DirectoryNotFoundException
public static void Exists(FileInfo fileInfo)               // 抛 FileNotFoundException
```

当文件或目录不存在时抛出相应异常。

```csharp
public void ReadConfig(FileInfo configFile)
{
    Ensure.Exists(configFile);
    // 读取配置...
}
```

### 1.9 Ensure 方法汇总

| 方法 | 说明 | 异常类型 |
|------|------|----------|
| `That(condition, msg)` | 确保条件为真 | ArgumentException |
| `That<TException>` | 确保条件为真 | 自定义异常 |
| `Not(condition, msg)` | 确保条件为假 | ArgumentException |
| `Not<TException>` | 确保条件为假 | 自定义异常 |
| `NotNull(value, name)` | 确保对象不为空 | ArgumentNullException |
| `Equal(left, right, msg)` | 确保值相等 | ArgumentException |
| `NotEqual(left, right, msg)` | 确保值不相等 | ArgumentException |
| `NotNullOrEmpty(collection, msg)` | 确保集合不为空 | ArgumentException |
| `NotNullOrWhiteSpace(str, msg)` | 确保字符串不为空 | ArgumentException |
| `Exists(DirectoryInfo)` | 确保目录存在 | DirectoryNotFoundException |
| `Exists(FileInfo)` | 确保文件存在 | FileNotFoundException |

## 2. Equatable\<T\> - 泛型相等基类

位于 `JBaseLibrary` 命名空间，简化 `IEquatable<T>` 的实现。

### 2.1 基本用法

继承 `Equatable<T>` 的类只需重写 `GetHashCode()` 方法即可获得完整的相等比较能力。

```csharp
public class Person : Equatable<Person>
{
    public string Name { get; set; }
    public int Age { get; set; }

    public override int GetHashCode()
    {
        return HashCode.Combine(Name, Age);
    }
}
```

### 2.2 自动获得的能力

```csharp
var person1 = new Person { Name = "张三", Age = 25 };
var person2 = new Person { Name = "张三", Age = 25 };

person1.Equals(person2);                        // true
person1 == person2;                              // true
person1 != person2;                              // false
person1.GetHashCode() == person2.GetHashCode();  // true
```

### 2.3 实现原理

- `Equals(T other)` 通过比较哈希码判断相等性；
- `GetHashCode()` 必须由子类实现；
- 支持 `==` 和 `!=` 运算符重载。

### 2.4 最佳实践

```csharp
// 使用 HashCode.Combine（推荐）
public override int GetHashCode()
{
    return HashCode.Combine(Name, Age);
}

// 或手动实现
public override int GetHashCode()
{
    unchecked
    {
        int hashCode = Name?.GetHashCode() ?? 0;
        hashCode = (hashCode * 397) ^ Age;
        return hashCode;
    }
}
```

## 3. Base64UrlSafe - URL 安全 Base64 编解码

位于 `JBaseLibrary` 命名空间，用于 URL 和文件安全的 Base64 编码（JWT 使用的就是这种算法）。

### 3.1 原理说明

标准 Base64 使用字符 `+` 和 `/`，这些字符在 URL 中需要额外编码。Base64UrlSafe 将其替换为 `-` 和 `_`，并去掉末尾的 `=`，使其可以直接用于 URL。

| 标准 Base64 | Base64UrlSafe |
|-------------|---------------|
| `+` | `-` |
| `/` | `_` |
| `=`（填充） | 删除 |

### 3.2 Encode - 编码

```csharp
public static string Encode(byte[] arg)
```

将字节数组编码为 URL 安全的 Base64 字符串。

```csharp
byte[] data = Encoding.UTF8.GetBytes("Hello World");
string encoded = Base64UrlSafe.Encode(data);
// 输出类似: "SGVsbG8gV29ybGQ"
```

### 3.3 Decode - 解码

```csharp
public static byte[] Decode(string arg)
```

将 URL 安全的 Base64 字符串解码为字节数组。

```csharp
string encoded = "SGVsbG8gV29ybGQ";
byte[] decoded = Base64UrlSafe.Decode(encoded);
string text = Encoding.UTF8.GetString(decoded);
// 输出: "Hello World"
```

### 3.4 异常处理

- 当 `arg` 为 `null`/空/空白时，抛 `ArgumentNullException`（由 `Ensure.NotNullOrWhiteSpace` 抛出）；
- 当 `arg` 不是有效的 Base64UrlSafe 编码时，抛 `InvalidDataException`。

```csharp
try
{
    byte[] data = Base64UrlSafe.Decode("无效的!!!字符串");
}
catch (InvalidDataException ex)
{
    Console.WriteLine("解码失败: " + ex.Message);
}
```

### 3.5 与 JWT 的关系

JWT 的 Header 和 Payload 就是 Base64UrlSafe 编码：

```csharp
// Header
var header = new { alg = "HS256", typ = "JWT" };
string headerEncoded = Base64UrlSafe.Encode(Encoding.UTF8.GetBytes(header.ToJson()));

// Payload
var payload = new { sub = "1234567890", name = "张三" };
string payloadEncoded = Base64UrlSafe.Encode(Encoding.UTF8.GetBytes(payload.ToJson()));

// Signature（通常使用 HMAC）
string signature = HMACSHA256(headerEncoded + "." + payloadEncoded, secret);

// 最终 JWT
string jwt = headerEncoded + "." + payloadEncoded + "." + signature;
```

### 3.6 方法汇总

| 方法 | 参数 | 返回值 | 说明 |
|------|------|--------|------|
| `Encode` | `byte[] arg` | `string` | 将字节数组编码为 URL 安全 Base64 |
| `Decode` | `string arg` | `byte[]` | 将 URL 安全 Base64 解码为字节数组 |

## 4. EasyComparer - 对象差异比较器

位于 `JBaseLibrary.EasyComparers` 命名空间，提供**两个同类型对象属性之间差异**的判断能力。

### 4.1 基本用法

```csharp
using JBaseLibrary.EasyComparers;

public class Person
{
    public int Id { get; set; }
    public string Name { get; set; }
}

var person = new Person { Id = 1, Name = "悟空" };
var person2 = new Person { Id = 1, Name = "八戒" };

bool isEqual = EasyComparer.Instance.Compare<Person>(
    person, person2,
    inherit: true,             // 是否比较继承属性
    includePrivate: true,      // 是否比较私有属性
    out var variances);

foreach (var item in variances)
{
    Console.WriteLine($"属性:{item.Key.Name}, 是否有变化:{item.Value.Varies}");
}
// 输出:
// 属性:Id, 是否有变化:False
// 属性:Name, 是否有变化:True
```

### 4.2 Variance - 差异信息

```csharp
public sealed class Variance
{
    public PropertyInfo Property { get; }    // 比较的属性信息
    public object LeftValue { get; }         // 第一个对象的属性值
    public object RightValue { get; }        // 第二个对象的属性值
    public bool Varies { get; }             // 是否发生变化
}
```

集合类型的属性会比较元素内容（顺序敏感，使用 `SequenceEqual`）。

### 4.3 缓存

`EasyComparer` 是单例（`EasyComparer.Instance`），并缓存每个 `(Type, inherit, includePrivate)` 组合的属性 Getter 委托，性能良好。

## 5. Accessor / AccessorBuilder - 反射访问器

位于 `JBaseLibrary.Accessors` 命名空间，是基于表达式树 / IL Emit 编译的**高性能反射读写工具**，常用于 ORM 映射、DTO 转换、动态配置等场景。

### 5.1 Accessor 基类

```csharp
public abstract class Accessor
{
    public IReflect Type { get; }
    public bool IgnoreCase { get; }
    public bool IncludesNonPublic { get; }
    public SortedList<string, PropertyInfo> Properties { get; }
    public SortedList<string, FieldInfo> Fields { get; }

    // 创建 ObjectAccessor
    public static ObjectAccessor Build(object instance, bool ignoreCase = false, bool includeNonPublic = false);
    public static ObjectAccessor Build(Type instanceType, bool ignoreCase = false, bool includeNonPublic = false);

    // 创建 GenericAccessor<T>
    public static GenericAccessor<TInstance> Build<TInstance>(bool ignoreCase = false, bool includeNonPublic = false) where TInstance : class;
}
```

### 5.2 ObjectAccessor - 通过字符串名访问

```csharp
public class Person
{
    public int Id { get; set; }
    public string Name { get; set; }
}

var accessor = Accessor.Build<Person>(ignoreCase: true);
var person = new Person { Id = 1, Name = "普通用户" };

// 读
int id = (int)accessor[person, "Id"];     // 1

// 写（大小写不敏感）
accessor[person, "name"] = "小明";
// person.Name == "小明"
```

### 5.3 GenericAccessor\<T\> - 强类型访问

```csharp
var accessor = Accessor.Build<Person>(ignoreCase: true);
var person = new Person();

accessor[person, "Id"] = 1;     // object 读写
accessor[person, "Name"] = "张三";

// TryGet / TrySet 带类型安全
if (accessor.TryGet<string>(person, "Name", out var name))
{
    Console.WriteLine(name);  // "张三"
}

if (accessor.TrySet(person, "Age", 25))   // 不存在 Age 属性时返回 false
{
    // ...
}
```

### 5.4 AccessorBuilder - 直接编译 Getter/Setter

```csharp
using JBaseLibrary.Accessors;

// 直接构造 Getter / Setter
Func<Person, int> getter = AccessorBuilder.BuildGetter<Person, int>("Id");
Action<Person, int> setter = AccessorBuilder.BuildSetter<Person, int>("Id");

var person = new Person();
setter(person, 100);
int id = getter(person);  // 100

// 字段版本
Func<Person, string> fieldGetter = AccessorBuilder.BuildFieldGetter<Person, string>("_name");
Action<Person, string> fieldSetter = AccessorBuilder.BuildFieldSetter<Person, string>("_name");

// 非泛型版本（属性信息）
var propInfo = typeof(Person).GetProperty("Name");
Func<object, object> objGetter = AccessorBuilder.BuildGetter(propInfo);
Action<object, object> objSetter = AccessorBuilder.BuildSetter(propInfo);

// 实例构造器
Func<Person> creator = AccessorBuilder.BuildInstanceCreator<Person>();
var p = creator();
```

### 5.5 适用场景

- 通用 CRUD 框架（动态读写实体属性）
- 对象映射（替代反射的慢路径）
- 配置中心（动态读取/写入对象）
- 自定义序列化

## 6. MapperExtensions - 对象映射

位于 `JBaseLibrary.Extensions` 命名空间。基于同名属性映射，提供**实体 ↔ DTO** 转换能力。

### 6.1 基本映射（Mapper\<TResult\>）

```csharp
var person = new Person { Id = 1, Name = "张三", Age = 25 };

// 匿名对象也支持
var personDto = person.Mapper<PersonDto>();

// 显式指定源类型
var personDto2 = person.Mapper<Person, PersonDto>();

// 显式指定目标类型（运行时类型）
object personDto3 = person.Mapper(typeof(PersonDto));
object personDto4 = person.Mapper(typeof(Person), typeof(PersonDto));
```

### 6.2 集合映射

```csharp
var persons = new List<Person> { ... };
var dtos = persons.Mapper<List<Person>, List<PersonDto>>();

// 重载：Mapper<TSource, TTarget>(IEnumerable<TSource>)
var dtos2 = persons.Mapper<Person, PersonDto>();
```

### 6.3 参数说明

```csharp
public static TResult Mapper<TResult>(
    this object src,
    bool containsRepeatReference = true,   // 是否处理循环引用
    bool null2Default = true)             // null 是否转换为默认值（否则抛异常）
```

### 6.4 与 ObjectExtensions.ModifyByDto 的区别

| 方法 | 行为 |
|------|------|
| `Mapper<TResult>()` | **新建**目标对象（`new TTarget()`） |
| `ModifyByDto(dto)` | **修改**已有对象（`entity.Name = dto.Name`） |

### 6.5 JMapper（底层）

> `JMapper<TSource, TTarget>` 是 `internal class`，是 `MapperExtensions` 的底层实现，一般无需直接使用。

## 7. Attributes - 特性集

位于 `JBaseLibrary.Attributes` 命名空间，常配合验证、ORM、API 文档生成使用。

### 7.1 NotEmptyAttribute - 集合非空校验

继承自 `ValidationAttribute`，标注在集合属性上，配合 MVC/ASP.NET Core 模型验证使用。

```csharp
public class OrderReq
{
    [NotEmpty(ErrorMessage = "订单项不能为空")]
    public List<OrderItem> Items { get; set; }
}
```

### 7.2 EnumCheckAttribute - 枚举值合规校验

继承自 `ValidationAttribute`，校验属性值是否为合法枚举值。

```csharp
public enum Status { Active = 1, Inactive = 2 }

public class User
{
    [EnumCheck(ErrorMessage = "状态值不合法")]
    public Status Status { get; set; }

    [EnumCheck(ErrorMessage = "状态值不合法")]
    public Status? OptionalStatus { get; set; }   // 也支持可空枚举
}
```

支持 `AttributeTargets.Property | Enum | Field`。

### 7.3 SearchAttribute - 查询条件特性

与 `SearchHelper` 配合，实现动态查询条件拼接。

```csharp
using JBaseLibrary.Attributes;
using JBaseLibrary.Enums;

public class UserSearch
{
    [Search("Name", OperationType.Like)]
    public string NameLike { get; set; }

    [Search("Age", OperationType.GreaterThanOrEqual)]
    public int? MinAge { get; set; }
}
```

### 7.4 NoLogAttribute - 跳过日志记录

标注在 Controller 或 Action 上，可被日志过滤器识别跳过。

```csharp
[NoLog]
public class HealthController : ControllerBase
{
    [NoLog]
    public IActionResult Ping() => Ok();   // 不会被操作日志记录
}
```

### 7.5 ApiDescriptionSettingsAttribute - Swagger 分组

标注在 Controller 或 Action 上，指定接口所属的 Swagger 分组。

```csharp
[ApiDescriptionSettings("系统管理", "用户管理")]
public class UserController : ControllerBase
{
    [ApiDescriptionSettings("系统管理", "用户管理-查询")]
    public IActionResult GetUsers() => Ok();
}
```

支持多个分组（`params string[]`），也支持方法级标注。

### 7.6 MapperArgumentsAttribute - 映射参数

定义在 `JBaseLibrary.Extensions` 命名空间，用于在 `Mapper`/`ModifyByDto` 时传递额外参数（如 DateTime -> string 的格式）。

```csharp
public class Order
{
    [MapperArguments("yyyy-MM-dd HH:mm:ss")]
    public DateTime CreateTime { get; set; }
}
```

## 8. Enums - 枚举集

### 8.1 OperationType - 查询操作类型

位于 `JBaseLibrary.Enums` 命名空间，定义 `SearchAttribute` 中使用的查询操作符。

| 值 | 含义 | SQL |
|----|------|-----|
| `None` | 不参与查询 | - |
| `Equal` | 相等 | `=` |
| `Like` | 包含 | `LIKE` |
| `GreaterThan` | 大于 | `>` |
| `LessThan` | 小于 | `<` |
| `GreaterThanOrEqual` | 大于等于 | `>=` |
| `LessThanOrEqual` | 小于等于 | `<=` |
