# JBase.Common 文档

> ASP.NET Core 通用基础类库，封装企业级 Web 开发常用功能模块

## 简介

JBase.Common 是一个面向 ASP.NET Core 的通用基础类库，旨在提供开箱即用的企业级 Web 应用开发组件。通过引用 JBase.Common，开发者可以快速集成缓存、JWT 认证、定时任务、权限控制、操作日志等常用功能，无需从零实现。

## 特性

- **统一响应格式**：标准化的 API 响应结构
- **双缓存支持**：Redis + Memory 统一接口，灵活切换
- **JWT 认证**：完整的 Token 颁发、验证、自动刷新机制
- **全局异常处理**：统一的异常捕获和标准化错误响应
- **定时任务**：支持 Cron 表达式、间隔执行、分布式锁
- **权限控制**：基于操作码的细粒度权限验证
- **请求防护**：防高频点击、防重复提交
- **操作日志**：特性驱动的自动日志记录
- **HTTP 客户端**：统一的 HTTP 请求封装
- **依赖注入**：自动扫描程序集批量注册服务

## 环境要求

- .NET Standard 2.1
- ASP.NET Core 3.1+ / .NET 5+ / .NET 6+ / .NET 7+ / .NET 8+

## 安装

```bash
dotnet add package JBase.Common
```

或通过 NuGet 管理器搜索 `JBase.Common` 安装。
