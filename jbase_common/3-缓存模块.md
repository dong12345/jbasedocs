# 缓存模块

JBase.Common 提供统一的缓存接口 `ICacheService`，支持 Redis 和 Memory 两种实现，切换只需修改注册代码。

## 接口定义

```csharp
public interface ICacheService
{
    // 删除
    long Del(params string[] key);
    Task<long> DelAsync(params string[] key);
    Task<long> DelByPatternAsync(string pattern);

    // 存在性检查
    bool Exists(string key);
    Task<bool> ExistsAsync(string key);

    // 获取
    string Get(string key);
    T Get<T>(string key);
    Task<string> GetAsync(string key);
    Task<T> GetAsync<T>(string key);

    // 设置
    void Set(string key, object value);
    void Set(string key, object value, TimeSpan expire);
    void Set(string key, object value, int expireSeconds);
    Task SetAsync(string key, object value);
    Task SetAsync(string key, object value, int expireSeconds);
    Task SetAsync(string key, object value, TimeSpan expire);

    // 分布式锁
    bool TryLock(string lockStr, ref ILock lockObj, int timeoutSeconds = 30);

    // 队列操作
    Task<long> EnQueueAsync<T>(string key, params T[] values);
    Task<T> DeQueueAsync<T>(string key);

    // 计数器
    long Decr(string key);
    long Incr(string key);

    // 模式匹配
    IEnumerable<string> GetKeysByPattern(string pattern);
    Task<IEnumerable<string>> GetKeysByPatternAsync(string pattern);
    IEnumerable<string> GetKeysByPatterns(params string[] patterns);
    Task<IEnumerable<string>> GetKeysByPatternsAsync(params string[] patterns);

    // 其他
    Task<Dictionary<string, string>> GetInfoAsync(string section = null);
    Task<long> GetDbSizeAsync();
    Task<long> GetTtlAsync(string key);
    bool SetNX(string key, object value, int expireSeconds);
    bool SetNX(string key, object value, TimeSpan expire);
    Task<bool> SetNXAsync(string key, object value, int expireSeconds);
    Task<bool> SetNXAsync(string key, object value, TimeSpan expire);
}
```

## 注册服务

### AddCache - 自动选择缓存类型

根据配置文件自动选择 Redis 或 Memory 缓存，无需手动判断。

```csharp
// appsettings.json
{
  "Cache": {
    "Type": 1,              // 1=Redis, 2=Memory
    "RedisConnection": "localhost:6379"
  }
}

// 一行代码搞定，自动根据 Type 选择缓存实现
services.AddCache();
```

### CacheConfig 配置项

| 配置项 | 类型 | 说明 |
|--------|------|------|
| `Type` | `CacheType` | 缓存类型：1=Redis, 2=Memory |
| `RedisConnection` | `string` | Redis 连接字符串 |

## 基本使用

### 1. 简单存取

```csharp
public class UserService
{
    private readonly ICacheService _cache;

    public UserService(ICacheService cache)
    {
        _cache = cache;
    }

    public async Task<UserDto> GetUserAsync(int id)
    {
        var cacheKey = $"user:{id}";

        // 先从缓存获取
        var cached = await _cache.GetAsync<UserDto>(cacheKey);
        if (cached != null)
        {
            return cached;
        }

        // 缓存不存在，从数据库获取
        var user = await _dbContext.Users.FindAsync(id);

        // 写入缓存，1小时过期
        await _cache.SetAsync(cacheKey, user, 3600);

        return user;
    }
}
```

### 2. 带过期时间的缓存

```csharp
// 秒为单位
await _cache.SetAsync("key1", "value", 300); // 5分钟后过期

// TimeSpan 方式
await _cache.SetAsync("key2", "value", TimeSpan.FromHours(1)); // 1小时后过期
```

### 3. 删除缓存

```csharp
// 删除单个 key
await _cache.DelAsync("user:1");

// 删除多个 key
await _cache.DelAsync("user:1", "user:2", "user:3");

// 按模式删除（如删除所有用户缓存）
await _cache.DelByPatternAsync("user:*");
```

### 4. 检查是否存在

```csharp
if (await _cache.ExistsAsync("user:1"))
{
    // 缓存存在
}
```

## 分布式锁

### 基本用法

```csharp
public class OrderService
{
    private readonly ICacheService _cache;

    public OrderService(ICacheService cache)
    {
        _cache = cache;
    }

    public async Task CreateOrderAsync(OrderDto dto)
    {
        ILock lockObj = null;
        try
        {
            // 尝试获取锁，30秒超时
            if (!_cache.TryLock($"order:create:{dto.OrderNo}", ref lockObj, 30))
            {
                throw new CommonException("系统繁忙，请稍后重试");
            }

            // 执行业务逻辑
            await ProcessOrderAsync(dto);
        }
        finally
        {
            // 释放锁
            lockObj?.ReleaseLock();
        }
    }
}
```

### 锁的用途

- **防止并发重复操作**：如订单创建、支付等
- **分布式环境下保证原子性**：多实例部署时防止竞争条件
- **任务执行保护**：定时任务防止多节点重复执行

## 队列操作

### 入队

```csharp
// 添加任务到队列
await _cache.EnQueueAsync("task_queue", new TaskDto { Id = 1, Name = "任务1" });
await _cache.EnQueueAsync("task_queue", new TaskDto { Id = 2, Name = "任务2" });
```

### 出队

```csharp
// 从队列取出任务（先进先出）
var task = await _cache.DeQueueAsync<TaskDto>("task_queue");
```

> **注意**：Memory 缓存不支持队列操作，会抛出 `NotImplementedException`。

## 计数器操作

```csharp
// 递增
var newValue = _cache.Incr("page_views"); // 返回新值

// 递减
var newValue = _cache.Decr("stock_count"); // 返回新值
```

## SetNX（仅当 key 不存在时设置）

```csharp
// 仅当 key 不存在时才设置成功
var success = await _cache.SetNXAsync("distributed_lock", 1, 60);

if (success)
{
    // 获取锁成功
}
else
{
    // 锁已被其他客户端持有
}
```

## 模式匹配获取 Key

```csharp
// 获取所有用户相关的 key
var keys = await _cache.GetKeysByPatternAsync("user:*");

// 获取多个模式的 key
var keys = await _cache.GetKeysByPatternsAsync("user:*", "order:*");
```

## 获取缓存信息

```csharp
// 获取 Redis 服务器信息
var info = await _cache.GetInfoAsync("Server");

// 获取数据库键数量
var dbSize = await _cache.GetDbSizeAsync();

// 获取 key 的剩余生存时间
var ttl = await _cache.GetTtlAsync("user:1");
// 返回值：-1=永久，-2=不存在，正数=剩余秒数
```

## 最佳实践

### 1. 缓存 Key 命名规范

```csharp
// 推荐格式：模块:实体:标识符
"user:1"                    // 用户ID为1的用户缓存
"product:list:page_1"      // 产品列表第1页
"order:create:ON20240101"   // 订单号
```

### 2. 缓存策略

```csharp
public class CacheKeys
{
    public const string UserPrefix = "user:";
    public const string OrderPrefix = "order:";
    public const string ProductListPrefix = "product:list:";

    public static string User(int id) => $"{UserPrefix}{id}";
    public static string Order(string orderNo) => $"{OrderPrefix}{orderNo}";
    public static string ProductList(int page) => $"{ProductListPrefix}page_{page}";
}
```

### 3. 缓存穿透防护

```csharp
public async Task<UserDto> GetUserAsync(int id)
{
    var cacheKey = CacheKeys.User(id);

    // 先获取缓存
    var cached = await _cache.GetAsync<UserDto>(cacheKey);
    if (cached != null)
    {
        return cached;
    }

    // 查询数据库
    var user = await _dbContext.Users.FindAsync(id);

    // 即使数据库不存在，也缓存一个空值（短期），防止缓存穿透
    await _cache.SetAsync(cacheKey, user ?? new UserDto { Id = id, IsNull = true }, 60);

    return user;
}
```

### 4. 缓存雪崩防护

```csharp
// 使用随机过期时间，避免大量 key 同时过期
var random = new Random();
var expireSeconds = 3600 + random.Next(300); // 1小时 + 0~5分钟随机

await _cache.SetAsync(cacheKey, data, expireSeconds);
```

## Redis vs Memory 对比

| 功能 | Redis | Memory |
|------|-------|--------|
| 分布式支持 | 支持，多实例共享 | 不支持，仅本机 |
| 持久化 | 可配置 | 不支持，重启丢失 |
| 队列操作 | 支持 | 不支持 |
| 计数器 | 支持 | 不支持 |
| 过期时间 | 支持 | 支持 |
| 内存限制 | 服务器配置 | 应用内存 |
| 性能 | 网络延迟 | 内存访问，最快 |

## 异常处理

所有操作都进行了异常捕获，不会因为 Redis 连接失败导致应用崩溃：

```csharp
// 如果 Redis 不可用，操作会返回默认值而不抛出异常
var value = _cache.Get<string>("key"); // 失败返回 null
_cache.Set("key", value);               // 失败静默忽略
```
