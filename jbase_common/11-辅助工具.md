# 辅助工具

本文档介绍 `JBase.Common.Helper` 命名空间下的常用工具类，包括 `TraceIdHelper`、`HttpClientHelper`、`EmailHelper`、`ThrowHelper`、`ValidateModelHelper` 等。

## TraceIdHelper

`TraceIdHelper` 用于在任何地方（包括业务代码、静态方法、Service 中）获取当前 HTTP 请求的 TraceId。

`TraceIdMiddleware` 会拦截每个请求，从请求头 `X-Trace-Id`（或自动生成）读取/创建 TraceId，并写入到：
- 当前 `HttpContext.Items["TraceId"]`
- `AsyncLocal<string?>` 中（用于跨异步上下文传递）

`TraceIdHelper` 正是基于这些机制实现追踪。

### API

```csharp
public static class TraceIdHelper
{
    /// <summary>
    /// 获取当前请求的 TraceId。
    /// 优先级：AsyncLocal > HttpContext.Items > TraceIdentifier。
    /// 找不到则返回 string.Empty。
    /// </summary>
    public static string GetTraceId(HttpContext? httpContext = null);

    /// <summary>
    /// 获取当前请求的 TraceId，不存在则自动生成（格式 yyyyMMddHHmmssfff-{8位随机}）。
    /// </summary>
    public static string GetOrCreateTraceId(HttpContext? httpContext = null);
}
```

### 使用示例

```csharp
// 1. 在 Service 业务代码中：直接获取当前请求的 TraceId
public class OrderService
{
    public void CreateOrder()
    {
        var traceId = TraceIdHelper.GetTraceId();
        _logger.LogInformation("下单, TraceId={TraceId}", traceId);
    }
}

// 2. 显式传入 HttpContext（一般不需要）
public void ProcessRequest(HttpContext context)
{
    var traceId = TraceIdHelper.GetTraceId(context);
}

// 3. 没找到 TraceId 时，自动生成新的（用于非 HTTP 场景）
var traceId = TraceIdHelper.GetOrCreateTraceId();
```

### 配置

需要在请求管道中启用 `UseTraceId` 中间件：

```csharp
app.UseTraceId();
```

> 也可以在请求头中传入 `X-Trace-Id: your-id` 来覆盖默认值，便于跨服务调用时统一追踪。

## HttpClientHelper

`HttpClientHelper` 是对 `IHttpClientFactory` 的统一封装，提供 GET / POST / Form / Multipart / UploadFile / DownloadFile 等方法，支持自动编码解析、超时控制、自定义 Header。

### 注册

```csharp
// 1. 注册 IHttpClientFactory
builder.Services.AddHttpClient();

// 2. 注册 HttpClientHelper（HttpClientHelper 实现了 ISingleton，会自动注入）
builder.Services.AddSingleton<HttpClientHelper>();
// 或使用 IOC 扩展
builder.Services.AddJBaseCore();  // AddJBaseCore 内部已注册 HttpClientHelper
```

### HttpResult 统一响应

所有方法都返回 `HttpResult`：

```csharp
public class HttpResult
{
    public bool     Success     { get; set; }   // 是否成功
    public string?  Content     { get; set; }   // 响应内容
    public string?  ErrorMessage{ get; set; }   // 错误信息
    public int?     StatusCode  { get; set; }   // HTTP 状态码
}
```

### GET 请求

```csharp
public class WeatherService
{
    private readonly HttpClientHelper _http;
    public WeatherService(HttpClientHelper http) => _http = http;

    public async Task<string> GetWeatherAsync(string city)
    {
        var result = await _http.GetAsync($"https://api.weather.com/v3/weather?city={city}",
                                          timeoutSeconds: 10);
        if (!result.Success)
        {
            throw new Exception($"获取天气失败：{result.ErrorMessage}");
        }
        return result.Content!;
    }
}
```

### POST 请求

```csharp
// application/json
var result = await _http.PostAsync("https://api.example.com/users",
                                   content: JsonConvert.SerializeObject(user),
                                   contentType: "application/json");

// 自定义 HttpContent
using var content = new StringContent(json, Encoding.UTF8, "application/json");
var result = await _http.PostAsync("https://api.example.com/users", content);

// application/x-www-form-urlencoded
var result = await _http.PostFormAsync("https://api.example.com/login",
                                       new Dictionary<string, string>
                                       {
                                           { "username", "admin" },
                                           { "password", "123456" }
                                       });
```

### multipart/form-data

```csharp
// 1. 完整 MultipartFormDataContent
using var content = new MultipartFormDataContent();
content.Add(new StringContent("value1"), "field1");
content.Add(new ByteArrayContent(fileBytes), "file", "upload.bin");

var result = await _http.PostMultipartAsync("https://api.example.com/upload", content);

// 2. 快速上传文件
var result = await _http.UploadFileAsync("https://api.example.com/upload",
                                         filePath: "C:\\report.pdf",
                                         formFieldName: "file",
                                         formData: new Dictionary<string, string>
                                         {
                                             { "category", "report" }
                                         });
```

### 下载文件

```csharp
var result = await _http.DownloadFileAsync("https://example.com/file.zip",
                                           savePath: "C:\\download\\file.zip");

if (result.Success)
{
    Console.WriteLine($"下载成功，保存到：{result.Content}");
}
```

### 自定义 Header

```csharp
var headers = new Dictionary<string, string>
{
    { "Authorization", "Bearer xxx" },
    { "X-Request-Id", Guid.NewGuid().ToString() }
};

var result = await _http.GetAsync("https://api.example.com/data", headers: headers);
```

### 同步方法

每个异步方法都有对应的同步版本，内部通过 `GetAwaiter().GetResult()` 阻塞：

```csharp
// 不推荐在 ASP.NET Core 中使用同步方法，可能阻塞线程池
var result = _http.Get("https://api.example.com");
var post   = _http.PostForm("https://api.example.com", formData);
```

### 自动编码解析

`HttpClientHelper` 会从响应头 `Content-Type` 中的 `charset` 解析响应内容编码：
- `UTF-8` / `UTF-16` / `UTF-32` 自动识别
- 未知编码自动回退为 `UTF-8`

## EmailHelper

基于 `FluentEmail.MailKit` 封装的邮件发送工具，支持纯文本 / HTML / 附件 / 抄送 / 密送。

> **`QrCodeHelper` 在 `JBase.Common` 中并不存在**，请在 `JBaseLibrary` 项目文档中查阅对应的二维码帮助类。

### 配置 appsettings.json

```json
{
  "EmailSender": {
    "Server": "smtp.qq.com",
    "Port": 465,
    "UseSsl": true,
    "UserName": "no-reply@example.com",
    "Password": "your-smtp-password-or-token",
    "FromAddress": "no-reply@example.com",
    "FromDisplayName": "系统通知"
  }
}
```

### EmailSenderOptions 配置类

```csharp
public class EmailSenderOptions
{
    public string  Server          { get; set; } = string.Empty;   // SMTP 地址
    public int     Port            { get; set; } = 465;           // SMTP 端口
    public bool    UseSsl          { get; set; } = true;          // 是否 SSL
    public string  UserName        { get; set; } = string.Empty;   // 登录账号
    public string  Password        { get; set; } = string.Empty;   // 登录密码/授权码
    public string  FromAddress     { get; set; } = string.Empty;   // 发件邮箱
    public string? FromDisplayName { get; set; }                   // 发件人显示名
}
```

### EmailSendRequest 请求体

```csharp
public class EmailSendRequest
{
    public IEnumerable<string>      To         { get; set; } = Enumerable.Empty<string>();  // 收件人
    public IEnumerable<string>?     Cc         { get; set; }                                 // 抄送
    public IEnumerable<string>?     Bcc        { get; set; }                                 // 密送
    public string                   Subject    { get; set; } = string.Empty;                 // 主题
    public string                   Body       { get; set; } = string.Empty;                 // 正文
    public bool                     IsHtmlBody { get; set; } = true;                        // 是否 HTML
    public IEnumerable<EmailAttachment>? Attachments { get; set; }                           // 附件
}

public class EmailAttachment
{
    public string  FileName    { get; set; } = string.Empty;                       // 文件名
    public Stream  Content     { get; set; } = Stream.Null;                        // 文件流
    public string  ContentType { get; set; } = "application/octet-stream";         // MIME
    public bool    IsInline    { get; set; }                                       // 是否内联
    public string? ContentId   { get; set; }                                       // 内联 ContentId
}
```

### 注册

```csharp
using JBase.Common.Helper;

builder.Services.Configure<EmailSenderOptions>(builder.Configuration.GetSection("EmailSender"));
builder.Services.AddSingleton(sp =>
    new EmailHelper(sp.GetRequiredService<IOptions<EmailSenderOptions>>().Value));
```

### 发送邮件

```csharp
public class NoticeService
{
    private readonly EmailHelper _email;
    public NoticeService(EmailHelper email) => _email = email;

    public async Task NotifyAsync(string to, string htmlBody)
    {
        var request = new EmailSendRequest
        {
            To         = new[] { to },
            Subject    = "系统通知",
            Body       = htmlBody,
            IsHtmlBody = true,
            Attachments = new[]
            {
                new EmailAttachment
                {
                    FileName    = "report.pdf",
                    Content     = File.OpenRead("report.pdf"),
                    ContentType = "application/pdf"
                }
            }
        };

        var result = await _email.SendAsync(request);

        if (!result.IsSuccessful)
        {
            throw new InvalidOperationException(string.Join(";", result.ErrorMessages));
        }
    }
}
```

### 常见用法

| 场景 | 代码 |
|------|------|
| 抄送 / 密送 | 填充 `EmailSendRequest.Cc` / `Bcc` |
| 纯文本邮件 | `IsHtmlBody = false` |
| 内联图片（HTML 中 `cid:xxx` 引用） | `IsInline = true` + `ContentId` 设为 `xxx` |
| 同步发送 | 调用 `Send(request)`（内部用 `GetAwaiter().GetResult()`） |

## ThrowHelper

`ThrowHelper` 是异常抛出的快捷工具类。

```csharp
public static class ThrowHelper
{
    public static void ThrowIfNull(object? argument, string? paramName = null, string? message = null);
    public static void ThrowIfNullOrEmpty(string? argument, string? paramName = null, string? message = null);
    public static void ThrowIfNullOrWhiteSpace(string? argument, string? paramName = null, string? message = null);
    public static void ThrowIfZeroOrNegative(int argument, string? paramName = null, string? message = null);
    public static void ThrowIfZeroOrNegative(long argument, string? paramName = null, string? message = null);
    public static void ThrowIfDefault<T>(T argument, string? paramName = null, string? message = null);
    public static void Throw(string message);
    public static void Throw(string message, Exception innerException);
}
```

### 使用示例

```csharp
public void UpdateUser(int id, string name)
{
    ThrowHelper.ThrowIfZeroOrNegative(id, nameof(id));
    ThrowHelper.ThrowIfNullOrWhiteSpace(name, nameof(name));
    // ...
}
```

## ValidateModelHelper

`ValidateModelHelper` 用于在业务代码中手动校验 DataAnnotations 标注的数据模型，并抛 `ValidationException`。

```csharp
public static class ValidateModelHelper
{
    /// <summary>
    /// 校验对象，校验失败抛出 ValidationException
    /// </summary>
    public static void ValidThrow(object model);

    /// <summary>
    /// 校验对象，校验失败抛出 ValidationException
    /// </summary>
    /// <param name="model">待校验对象</param>
    /// <param name="errorCode">业务错误码（当前实现未使用）</param>
    public static void ValidThrow(object model, string errorCode);
}
```

### 使用示例

```csharp
public class CreateUserReq
{
    [Required(ErrorMessage = "用户名不能为空")]
    [StringLength(20, MinimumLength = 3, ErrorMessage = "用户名长度需在 3-20 之间")]
    public string UserName { get; set; }

    [Required, EmailAddress]
    public string Email { get; set; }
}

public class UserService
{
    public void Create(CreateUserReq req)
    {
        ValidateModelHelper.ValidThrow(req);   // 校验失败会抛 ValidationException，被 ExceptionMiddleware 捕获
        // 执行业务
    }
}
```

> 依赖 `JBaseLibrary.Validate` 模块，内部使用 `Validator.TryValidateObject` + `DataAnnotations`。

## DateTimeJsonConverter / DateTimeNullableJsonConverter

针对 `DateTime` / `DateTime?` 的 Newtonsoft.Json 自定义转换器，统一序列化格式。

```csharp
[JsonConverter(typeof(DateTimeJsonConverter))]
public DateTime CreateTime { get; set; }

// 或全局注册
builder.Services.AddControllers().AddNewtonsoftJson(options =>
{
    options.SerializerSettings.Converters.Add(new DateTimeJsonConverter());
    options.SerializerSettings.Converters.Add(new DateTimeNullableJsonConverter());
});
```

> 默认序列化为 `yyyy-MM-dd HH:mm:ss`，可通过派生类重写 `Format` 属性调整。
