# 扩展方法

JBase.Common 提供丰富的扩展方法，简化常见的开发工作。

## IServiceCollectionExtensions

### BatchRegisterService - 批量注册服务

自动扫描程序集并批量注册服务。

#### 基本用法

```csharp
// Program.cs
public void ConfigureServices(IServiceCollection services)
{
    // 自动扫描并注册所有服务
    services.BatchRegisterService();

    // 或指定过滤条件
    services.BatchRegisterService(asm => asm.FullName.Contains("MyApp"));

    // 或指定服务生命周期
    services.BatchRegisterService(lifetime: ServiceLifetime.Singleton);
}
```

#### 注册规则

1. **接口自动匹配**：
   - 类名包含接口名时自动注册（如 `UserService` → `IUserService`）
   - 不区分大小写

2. **生命周期接口**：
   - 实现 `ISingleton` 接口 → 注册为单例
   - 实现 `IScoped` 接口 → 注册为作用域
   - 实现 `ITransient` 接口 → 注册为瞬态

3. **示例**：

```csharp
// 自动匹配（类名包含接口名）
public interface IUserService { }
public class UserService : IUserService { }
// → 注册 IUserService → UserService

// 使用生命周期接口
public class CacheService : ISingleton, ICacheHelper { }
// → 注册 ICacheHelper → CacheService (Singleton)

// 不符合规则不会被注册
public class SomeHelper { }  // 没有对应接口，不会注册
```

### AddJBaseCore - 添加基础服务

```csharp
public void ConfigureServices(IServiceCollection services)
{
    // 注册 JBase 核心服务
    services.AddJBaseCore();

    // 包括：
    // - HttpClient
    // - HttpContextAccessor
    // - MemoryCache
}
```

### AddCache - 添加缓存服务

```csharp
// 根据配置自动选择 Redis 或 Memory
services.AddCache();
```

### AddCache - 添加缓存服务

根据配置文件自动选择 Redis 或 Memory 缓存。

```csharp
// appsettings.json
{
  "Cache": {
    "Type": "Redis",              // Redis 或 Memory
    "RedisConnection": "localhost:6379"
  }
}

// 注册缓存服务（自动根据配置选择类型）
services.AddCache();
```

### AddPreventFilters - 添加防护过滤器

```csharp
// 注册防高频点击和防重复提交过滤器
services.AddPreventRapidFireFilter();
services.AddPreventDuplicateRequestsFilter();
```

### AddJobServices - 添加定时任务服务

```csharp
// 自动扫描程序集中的 IJob 实现
services.AddJobServices();

// 指定程序集
services.AddJobServices(typeof(MyJob).Assembly);
```

## CustomMiddlewareExtensions

### UseTraceId - 启用 TraceId 中间件

```csharp
public void Configure(IApplicationBuilder app)
{
    // 必须在最前面
    app.UseTraceId();

    app.UseRouting();
    app.UseAuthorization();
}
```

### UseJwt - 启用 JWT 中间件

```csharp
public void Configure(IApplicationBuilder app)
{
    app.UseTraceId();
    app.UseJwt();
}
```

### UseExceptionMiddleware - 启用异常处理中间件

```csharp
public void Configure(IApplicationBuilder app)
{
    app.UseTraceId();
    app.UseJwt();
    app.UseExceptionMiddleware();
}
```

## 完整服务注册示例

```csharp
using JBase.Common;
using JBase.Common.Extensions;
using JBase.Common.Filters;
using JBase.Common.Job;
using JBase.Common.LogModule;
using JBase.Common.Middleware;

namespace MyApp.API
{
    public class Program
    {
        public static void Main(string[] args)
        {
            var builder = WebApplication.CreateBuilder(args);

            // 初始化配置
            App.InitializeConfiguration(builder.Configuration);

            // 注册服务
            builder.Services.AddProjectServices(builder.Environment);

            var app = builder.Build();
            App.InitializeServices(app.Services);

            // 配置中间件
            app.ConfigureMiddleware();

            app.Run();
        }
    }

    /// <summary>
    /// 服务注册扩展类
    /// </summary>
    public static class ServiceCollectionExtensions
    {
        public static IServiceCollection AddProjectServices(
            this IServiceCollection services,
            IWebHostEnvironment environment)
        {
            #region 控制器&全局过滤器
            services.AddControllers(options =>
            {
                options.Filters.Add<ModelValidationFilter>();
                options.Filters.Add<RequestFilter>();
                options.Filters.Add<OperationLogActionFilter>();
            })
            .AddJsonOptions(opt =>
            {
                opt.JsonSerializerOptions.Converters.Add(new DatetimeJsonConverter());
            });
            #endregion

            #region Swagger（开发环境）
            if (environment.IsDevelopment())
            {
                services.AddSwaggerGen();
            }
            #endregion

            #region 缓存服务
            services.AddCache();
            #endregion

            #region 定时任务
            services.AddJobServices();
            JobAutoRegistrar.RegisterJobs();
            #endregion

            #region 全局异常中间件
            services.AddExceptionMiddleware<DatabaseExceptionHandler>(option =>
            {
                option.EnableCustomExceptionHandling = true;
            });
            #endregion

            #region 防止高频点击
            services.AddPreventRapidFireFilter();
            #endregion

            #region 防止重复提交
            services.AddPreventDuplicateRequestsFilter();
            #endregion

            #region 批量服务自动注册
            services.BatchRegisterService(x => x.FullName!.ToLower().Contains("myapp"));
            #endregion

            return services;
        }
    }

    /// <summary>
    /// 中间件管道扩展类
    /// </summary>
    public static class MiddlewareExtensions
    {
        public static WebApplication ConfigureMiddleware(this WebApplication app)
        {
            #region 基础中间件
            app.UseTraceId();
            app.UseCors();
            app.UseExceptionMiddleware();
            #endregion

            #region SwaggerUI
            if (app.Environment.IsDevelopment())
            {
                app.UseSwagger();
                app.UseSwaggerUI();
            }
            #endregion

            #region 路由
            app.UseRouting();
            #endregion

            #region API鉴权（仅对 /api 路径生效）
            app.UseWhen(ctx => ctx.Request.Path.StartsWithSegments("/api"), apiApp =>
            {
                apiApp.UseJwt();
                apiApp.UseMiddleware<CustomAuthorizeMiddleware>();
            });
            #endregion

            #region 终结点映射
            app.MapControllers();
            #endregion

            return app;
        }
    }
}
```

> **注意**：
> - 使用 `WebApplication.CreateBuilder()` 是 .NET 6+ 推荐的新式写法
> - 异常处理器 `DatabaseExceptionHandler` 需要实现 `IExceptionHandler` 接口
> - 授权中间件 `CustomAuthorizeMiddleware` 需要继承 `AppAuthorizationMiddlewareBase`

## 中间件执行顺序

```
请求进入
    ↓
┌────────────────────────────────────┐
│ 1. ResponseCompression             │ ← 响应压缩
└────────────────────────────────────┘
    ↓
┌────────────────────────────────────┐
│ 2. TraceIdMiddleware              │ ← 生成/传递 TraceId
└────────────────────────────────────┘
    ↓
┌────────────────────────────────────┐
│ 3. CorsMiddleware                 │ ← 跨域处理
└────────────────────────────────────┘
    ↓
┌────────────────────────────────────┐
│ 4. ExceptionMiddleware            │ ← 捕获所有异常
└────────────────────────────────────┘
    ↓
┌────────────────────────────────────┐
│ 5. StaticFiles                    │ ← 静态文件
└────────────────────────────────────┘
    ↓
┌────────────────────────────────────┐
│ 6. SwaggerUI                      │ ← 接口文档（开发环境）
└────────────────────────────────────┘
    ↓
┌────────────────────────────────────┐
│ 7. Routing                        │ ← 路由匹配
└────────────────────────────────────┘
    ↓
┌────────────────────────────────────┐
│ 8. JwtMiddleware                  │ ← JWT 验证（/api 路径）
└────────────────────────────────────┘
    ↓
┌────────────────────────────────────┐
│ 9. CustomAuthorizeMiddleware       │ ← 权限验证（/api 路径）
└────────────────────────────────────┘
    ↓
┌────────────────────────────────────┐
│ 10. Controller / Action Filter    │ ← 业务逻辑
└────────────────────────────────────┘
    ↓
响应返回
```

> **说明**：
> - `/api` 路径专属中间件（JWT、授权）使用 `UseWhen` 条件分支，不会影响 SignalR、静态文件等路径
> - `UseTraceId` 必须放在最前面，确保 TraceId 能贯穿整个请求链路

## 最佳实践

1. **服务注册顺序**：先注册基础设施，再注册业务服务
2. **中间件顺序**：严格按照推荐的顺序注册
3. **批量注册**：业务服务使用 `BatchRegisterService` 自动注册
4. **缓存选择**：生产环境推荐 Redis，单机开发可用 Memory
5. **异常处理**：始终使用 `UseExceptionMiddleware`
