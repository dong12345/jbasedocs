# 定时任务

JBase.Common 提供轻量级的定时任务框架，支持 Cron 表达式、间隔执行、每日定时、延时执行等多种触发方式，并内置分布式锁、重试机制。

## 核心组件

| 组件 | 说明 |
|------|------|
| `IJob` | 任务接口 |
| `JJobAttribute` | 任务配置特性 |
| `JobExecutionContext` | 任务执行上下文 |
| `JBaseJobBackgroundService` | 后台托管服务 |

## 定义任务

### 基础任务

```csharp
using JBase.Common.Job;
using JBase.Common.Job.Attributes;
using Microsoft.Extensions.Logging;
using System.Threading;
using System.Threading.Tasks;

[JJob("数据同步任务", Cron = "0 0 2 * * ?", Group = "数据处理")]
public class DataSyncJob : IJob
{
    private readonly ILogger<DataSyncJob> _logger;

    public DataSyncJob(ILogger<DataSyncJob> logger)
    {
        _logger = logger;
    }

    public async Task ExecuteAsync(JobExecutionContext context, CancellationToken cancellationToken = default)
    {
        // 任务逻辑
        await SyncDataAsync();

        // 通过依赖注入的记录器写日志（JobExecutionContext 本身不提供 Logger 属性）
        _logger.LogInformation($"任务执行完成: {context.JobName}");
    }
}
```

### 生命周期钩子

```csharp
[JJob("带生命周期的任务", IntervalSeconds = 60)]
public class LifecycleJob : IJob
{
    private readonly ICacheService _cache;
    private readonly ILogger<LifecycleJob> _logger;

    public LifecycleJob(ICacheService cache, ILogger<LifecycleJob> logger)
    {
        _cache = cache;
        _logger = logger;
    }

    // 执行前调用
    public async Task OnBeforeExecuteAsync(JobExecutionContext context, CancellationToken cancellationToken)
    {
        _logger.LogInformation("任务开始执行");
        await _cache.SetAsync($"job:status:{context.JobName}", "running", 120);
    }

    // 执行核心逻辑
    public async Task ExecuteAsync(JobExecutionContext context, CancellationToken cancellationToken)
    {
        // 执行业务逻辑
        await ProcessAsync();
    }

    // 执行后调用（无论成功或失败）
    public async Task OnAfterExecuteAsync(JobExecutionContext context, CancellationToken cancellationToken)
    {
        await _cache.SetAsync($"job:status:{context.JobName}", "completed", 60);
    }

    // 执行失败时调用
    public async Task OnFailedAsync(JobExecutionContext context, System.Exception exception, CancellationToken cancellationToken)
    {
        _logger.LogError(exception, "任务执行失败");
        await SendAlertAsync(exception);
    }
}
```

## 触发类型

### 1. Cron 表达式触发

```csharp
[JJob("Cron任务", Cron = "0 0 2 * * ?")]
public class CronJob : IJob { }

// Cron 表达式示例：
// - "0 0 * * * ?"     每小时整点执行
// - "0 0 2 * * ?"     每天凌晨2点执行
// - "0 0/5 * * * ?"   每5分钟执行一次
// - "0 30 9 * * 1-5"  工作日上午9:30执行
// - "0 0 1 1 * ?"     每月1日凌晨1点执行
// - "0 0/30 * * * ?"  每30秒执行一次
```

### 2. 间隔触发

```csharp
[JJob("间隔任务", TriggerType = TriggerType.Interval, IntervalSeconds = 30)]
public class IntervalJob : IJob { }
```

### 3. 每日定时触发

```csharp
[JJob("每日任务", TriggerType = TriggerType.Daily, DailyTime = "09:00")]
public class DailyJob : IJob { }
```

### 4. 延时触发（一次性）

```csharp
[JJob("延时任务", TriggerType = TriggerType.Delay, DelaySeconds = 3600)]
public class DelayJob : IJob
{
    public async Task ExecuteAsync(JobExecutionContext context, CancellationToken cancellationToken = default)
    {
        // 一次性延时任务，执行一次后自动结束
    }
}
```

### 配置项说明

| 配置项 | 类型 | 默认值 | 说明 |
|--------|------|--------|------|
| `Name` | string | null | 任务名称 |
| `Group` | string | "Default" | 任务分组 |
| `Description` | string | null | 任务描述 |
| `Cron` | string | null | Cron 表达式 |
| `TriggerType` | TriggerType | Cron | 触发类型 |
| `IntervalSeconds` | double | 0 | 间隔秒数，TriggerType=Interval 时使用 |
| `DelaySeconds` | double | 0 | 延时秒数，TriggerType=Delay 时使用 |
| `DailyTime` | string | null | 每日时间 (HH:mm) |
| `RunOnStart` | bool | false | 启动时立即执行 |
| `Enabled` | bool | true | 是否启用 |
| `EnableDistributedLock` | bool | true | 是否启用分布式锁 |
| `LockTimeoutSeconds` | int | 30 | 锁超时秒数 |
| `MaxRetries` | int | 0 | 最大重试次数 |
| `RetryIntervalSeconds` | int | 1 | 重试间隔秒数 |
| `TimeoutSeconds` | int? | null | 执行超时秒数 |
| `Priority` | int | 100 | 执行优先级 |
| `Tags` | string[] | null | 标签 |

## 注册任务

### 方式一：自动注册（推荐）

通过 `AutoRegister = true` 配置，`AddJBaseJobs` 会自动扫描所有程序集并注册标记了 `JJob` 特性的任务。

```csharp
// Program.cs
public void ConfigureServices(IServiceCollection services)
{
    // 自动扫描并注册所有带 JJob 特性的任务
    services.AddJBaseJobs(options =>
    {
        options.AutoRegister = true;
        options.AssemblyFilter = assembly => assembly.FullName.Contains("YourApp");
    });
}
```

### 方式二：自动注册 + 程序化注册

当需要通过 `IJobConfigurator` 接口对任务进行更灵活的运行时配置时，可以先调用 `JobAutoRegistrar.RegisterJobs()`，然后在 `AddJBaseJobs` 中自动将任务注册到 DI 容器。

```csharp
// Program.cs
public void ConfigureServices(IServiceCollection services)
{
    // 先通过 JobAutoRegistrar 扫描并注册任务
    JobAutoRegistrar.RegisterJobs();

    // AddJBaseJobs 会自动将已注册的任务类型添加到 DI 容器
    services.AddJBaseJobs(options =>
    {
        options.AutoRegister = true;
    });
}
```

> **注意**：`JobAutoRegistrar.RegisterJobs()` 必须在 `services.AddJBaseJobs()` 之前调用，否则任务类型不会被注册到 DI 容器，导致运行时错误 `MissingMethodException: No parameterless constructor defined`。

### 方式三：手动注册

手动注册单个任务并自定义配置：

```csharp
// Program.cs
public void ConfigureServices(IServiceCollection services)
{
    // 手动添加任务
    services.AddJBaseJob<DataSyncJob>(opt =>
    {
        opt.Name = "手动任务";
        opt.Cron = "0 0 3 * * ?";
        opt.Group = "手动任务组";
    });
}
```

## JobExecutionContext 上下文

`JobExecutionContext` 是任务运行时携带的上下文对象（**不包含 `Logger` 属性**，如需日志请通过构造函数注入 `ILogger<T>`）：

```csharp
public class MyJob : IJob
{
    public async Task ExecuteAsync(JobExecutionContext context, CancellationToken cancellationToken)
    {
        // 任务名称
        var jobName = context.JobName;

        // 任务分组
        var group = context.Group;

        // 任务开始/结束时间
        var startTime = context.StartTime;
        var endTime = context.EndTime;

        // 执行耗时（毫秒）
        var elapsed = context.ElapsedMilliseconds;

        // 执行状态
        var status = context.Status;

        // 触发方式 / Cron 表达式
        var trigger = context.TriggerType;
        var cron = context.CronExpression;

        // 下次执行时间
        var nextRun = context.NextRunTime;

        // 自定义参数
        context.SetParameter("key", "value");
        var customData = context.GetParameter<string>("key");
        var withDefault = context.GetParameter<int>("count", 0);

        // 检查是否取消
        if (cancellationToken.IsCancellationRequested)
        {
            return;
        }

        // 执行业务逻辑...
    }
}
```

## 分布式锁

默认启用分布式锁，防止多实例重复执行：

```csharp
[JJob("分布式任务", EnableDistributedLock = true, LockTimeoutSeconds = 60)]
public class DistributedJob : IJob { }
```

### 工作原理

```
实例A 获取锁成功 → 执行任务 → 释放锁
实例B 获取锁失败 → 跳过本次执行
```

> **注意**：需要使用 Redis 缓存才能实现真正的分布式锁。

## 重试机制

```csharp
[JJob("带重试的任务", MaxRetries = 3, RetryIntervalSeconds = 10)]
public class RetryJob : IJob
{
    public async Task ExecuteAsync(JobExecutionContext context, CancellationToken cancellationToken)
    {
        try
        {
            // 可能失败的逻辑
            await CallExternalApiAsync();
        }
        catch
        {
            // 抛出异常触发重试
            throw;
        }
    }

    public async Task OnFailedAsync(JobExecutionContext context, System.Exception exception, CancellationToken cancellationToken)
    {
        // 所有重试都失败后调用
        await SendAlertAsync(exception);
    }
}
```

## 完整示例

```csharp
using JBase.Common.Job;
using JBase.Common.Job.Attributes;
using System;
using System.Threading;
using System.Threading.Tasks;

namespace MyApp.Jobs
{
    /// <summary>
    /// 每日数据同步任务
    /// </summary>
    [JJob(
        Name = "每日数据同步",
        Group = "数据处理",
        Description = "从外部API同步客户数据",
        Cron = "0 0 2 * * ?",
        EnableDistributedLock = true,
        LockTimeoutSeconds = 60,
        MaxRetries = 3,
        RetryIntervalSeconds = 30,
        TimeoutSeconds = 600
    )]
    public class DailyDataSyncJob : IJob
    {
        private readonly ILogger<DailyDataSyncJob> _logger;
        private readonly IHttpClientFactory _httpClientFactory;

        public DailyDataSyncJob(
            ILogger<DailyDataSyncJob> logger,
            IHttpClientFactory httpClientFactory)
        {
            _logger = logger;
            _httpClientFactory = httpClientFactory;
        }

        public async Task OnBeforeExecuteAsync(JobExecutionContext context, CancellationToken cancellationToken)
        {
            _logger.LogInformation($"任务 [{context.JobName}] 开始执行");
        }

        public async Task ExecuteAsync(JobExecutionContext context, CancellationToken cancellationToken)
        {
            var client = _httpClientFactory.CreateClient("ExternalApi");
            var lastSyncTime = GetLastSyncTime();

            var customers = await FetchCustomersAsync(client, lastSyncTime, cancellationToken);

            foreach (var customer in customers)
            {
                await SaveCustomerAsync(customer, cancellationToken);
            }

            await UpdateLastSyncTimeAsync(DateTime.Now, cancellationToken);

            _logger.LogInformation($"同步完成，共处理 {customers.Count} 条数据");
        }

        public async Task OnAfterExecuteAsync(JobExecutionContext context, CancellationToken cancellationToken)
        {
            _logger.LogInformation($"任务 [{context.JobName}] 执行完成，耗时: {context.ElapsedMilliseconds}ms");
        }

        public async Task OnFailedAsync(JobExecutionContext context, System.Exception exception, CancellationToken cancellationToken)
        {
            _logger.LogError(exception, $"任务 [{context.JobName}] 执行失败");
            await SendAlertEmailAsync(exception);
        }
    }
}
```

## 注意事项

### DI 容器与 JobAutoRegistrar 的关系

定时任务框架通过依赖注入（DI）创建任务实例，因此任务类型必须先注册到 DI 容器才能正常工作：

| 注册方式 | JobRegistry 注册 | DI 容器注册 |
|----------|------------------|-------------|
| `services.AddJBaseJobs()` + `AutoRegister = true` | ✅ 自动 | ✅ 自动 |
| `services.AddJBaseJob<T>()` 手动注册 | ✅ 自动 | ✅ 自动 |
| `JobAutoRegistrar.RegisterJobs()` 仅扫描注册 | ✅ 自动 | ❌ 需配合 |

如果使用 `JobAutoRegistrar.RegisterJobs()` 扫描任务，必须在 `services.AddJBaseJobs()` 之前调用，这样框架才会将扫描到的任务类型自动注册到 DI 容器。

### 常见错误

**错误：`MissingMethodException: No parameterless constructor defined`**

原因：任务类型未被注册到 DI 容器，且任务类没有无参构造函数。

解决：确保在 `AddJBaseJobs()` 之前调用了 `JobAutoRegistrar.RegisterJobs()`，或者使用 `AutoRegister = true` 让框架自动处理。

## 任务基类与配置器

### JobBase / JobBase&lt;T&gt;

如果希望减少样板代码，框架提供两个可选基类：

```csharp
// 无参任务
public class MySimpleJob : JobBase
{
    private readonly IService _service;

    public MySimpleJob(IService service)
    {
        _service = service;
    }

    public override async Task ExecuteAsync(JobExecutionContext context, CancellationToken cancellationToken)
    {
        await _service.DoWorkAsync();
    }
}

// 带参数任务（参数通过 JobOptions.Parameters["Args"] 传入）
public class MyParamJob : JobBase<MyArgs>
{
    public override async Task ExecuteAsync(JobExecutionContext context, CancellationToken cancellationToken)
    {
        // 直接访问 Args
        var id = Args.Id;
    }
}
```

`JobBase` 还内置了 `OnBeforeExecuteAsync` / `OnAfterExecuteAsync` / `OnFailedAsync` 虚方法，需要时按需重写即可。

### IJobConfigurator

如果希望任务类在自动注册时按运行时规则动态调整配置，可以让任务同时实现 `IJobConfigurator`：

```csharp
public class MyJob : IJob, IJobConfigurator
{
    public void Configure(JobOptions options)
    {
        // 自动注册时会回调此方法，可在运行时根据环境调整 Cron / Tags 等
        options.Tags = new[] { "env:" + Environment.GetEnvironmentVariable("ASPNETCORE_ENVIRONMENT") };
    }

    public Task ExecuteAsync(JobExecutionContext context, CancellationToken cancellationToken)
    {
        return Task.CompletedTask;
    }
}
```
