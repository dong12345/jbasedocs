# 请求防护

JBase.Common 提供两种请求防护机制，防止重复操作对系统造成影响。

## 两种防护机制对比

| 特性 | PreventRapidFire | PreventDuplicateRequests | PreventOversell |
|------|------------------|---------------------------|-----------------|
| **原理** | 执行完后开始计时 | 执行期间加锁 | Redis DECR 原子操作 |
| **防止** | 执行完立刻再调用 | 正在执行时被重复调用 | 多用户同时抢导致超卖 |
| **适用场景** | 搜索、查询、提交后冷却 | 订单创建、支付等耗时操作 | 秒杀、抢购、限量商品 |
| **典型时长** | 1-5 秒（默认1秒） | 3-30 秒（默认3秒） | 一次扣减 1 |
| **存储依赖** | ICacheService | ICacheService | 仅 Redis（需原子操作） |

## PreventRapidFireAttribute - 防高频点击

### 工作原理

```
请求1 执行完成 → 开始冷却(5秒)
    ↓
冷却期内请求2进来 → 被拦截
    ↓
冷却期结束请求3进来 → 正常执行
```

### 基本用法

```csharp
[ApiController]
[Route("api/[controller]")]
public class SearchController : ControllerBase
{
    // 搜索接口，2秒冷却
    [HttpPost("search")]
    [PreventRapidFire(ExpiredSeconds = 2)]
    public async Task<IActionResult> Search([FromBody] SearchDto dto)
    {
        var results = await _searchService.SearchAsync(dto);
        return Ok(results);
    }
}
```

### 完整配置

```csharp
public class PreventRapidFireAttribute : Attribute, IFilterFactory
{
    /// <summary>
    /// 冷却时间（秒），默认 1 秒
    /// </summary>
    public int ExpiredSeconds { get; set; } = 1;

    /// <summary>
    /// 自定义错误提示语
    /// </summary>
    public string ErrorMessage { get; set; }

    /// <summary>
    /// 是否包含用户ID，默认 true
    /// </summary>
    public bool IncludeUserId { get; set; } = true;

    /// <summary>
    /// 自定义 key 前缀
    /// </summary>
    public string CustomKeyPrefix { get; set; }

    /// <summary>
    /// 是否忽略参数，默认 false
    /// </summary>
    public bool IgnoreParameters { get; set; } = false;

    /// <summary>
    /// 冷却结束回调
    /// </summary>
    public Func<PreventRapidFireContext, Task> OnCooldownEnd { get; set; }
}
```

### 使用示例

```csharp
// 示例1：基本用法，1秒冷却
[HttpPost("quick-action")]
[PreventRapidFire]
public async Task<IActionResult> QuickAction() { }

// 示例2：2秒冷却
[HttpPost("submit")]
[PreventRapidFire(ExpiredSeconds = 2)]
public async Task<IActionResult> Submit([FromBody] SubmitDto dto) { }

// 示例3：忽略参数，同一用户的任意参数共享冷却
[HttpGet("search")]
[PreventRapidFire(IgnoreParameters = true)]
public async Task<IActionResult> Search(string keyword) { }

// 示例4：全局冷却，所有用户共享
[HttpPost("global-action")]
[PreventRapidFire(IncludeUserId = false)]
public async Task<IActionResult> GlobalAction() { }

// 示例5：自定义 key（不同参数不共享冷却）
[HttpPost("action1")]
[PreventRapidFire(CustomKeyPrefix = "action_one")]
public async Task<IActionResult> Action1() { }

[HttpPost("action2")]
[PreventRapidFire(CustomKeyPrefix = "action_two")]
public async Task<IActionResult> Action2() { }

// 示例6：自定义错误提示
[HttpPost("export")]
[PreventRapidFire(ExpiredSeconds = 3, ErrorMessage = "导出操作太频繁，请稍后再试")]
public async Task<IActionResult> Export() { }

// 示例7：冷却结束回调
[HttpPost("send-sms")]
[PreventRapidFire(ExpiredSeconds = 60, OnCooldownEnd = async ctx =>
{
    // 冷却结束后的处理，如发送通知
    await _notificationService.NotifyAsync(ctx.UserId, "可以再次发送短信了");
})]
public async Task<IActionResult> SendSms([FromBody] SmsDto dto) { }
```

## PreventDuplicateRequestsAttribute - 防重复提交

### 工作原理

```
请求1 开始执行 → 加锁
    ↓
执行中请求2进来 → 获取锁失败 → 被拦截
    ↓
请求1 执行完成 → 释放锁
```

### 基本用法

```csharp
[ApiController]
[Route("api/[controller]")]
public class OrderController : ControllerBase
{
    // 创建订单，防止重复提交
    [HttpPost]
    [PreventDuplicateRequests]
    public async Task<IActionResult> CreateOrder([FromBody] CreateOrderDto dto)
    {
        var order = await _orderService.CreateAsync(dto);
        return Ok(order);
    }
}
```

### 完整配置

```csharp
public class PreventDuplicateRequestsAttribute : Attribute, IFilterFactory
{
    /// <summary>
    /// 自定义错误提示语
    /// </summary>
    public string ErrorMessage { get; set; }

    /// <summary>
    /// 是否忽略参数，全接口加锁，默认 false
    /// </summary>
    public bool UseGlobal { get; set; }

    /// <summary>
    /// 锁过期时间（秒），默认 3 秒
    /// </summary>
    public int ExpiredSeconds { get; set; } = 3;

    /// <summary>
    /// 构造函数
    /// </summary>
    /// <param name="factorNames">防重复参数选取（默认使用入参 json 字符串；可自定义，多个参数将使用 "_" 拼接）</param>
    public PreventDuplicateRequestsAttribute(params string[] factorNames) { }
}
```

### 使用示例

```csharp
// 示例1：默认防重复（使用全部参数，3秒锁）
[HttpPost]
[PreventDuplicateRequests]
public async Task<IActionResult> CreateOrder([FromBody] CreateOrderDto dto) { }

// 示例2：只用订单号防重（不同订单号互不影响）
[HttpPost("pay")]
[PreventDuplicateRequests("OrderNo")]
public async Task<IActionResult> Pay([FromBody] PayDto dto) { }

// 示例3：使用多个参数组合防重
[HttpPost("transfer")]
[PreventDuplicateRequests("FromAccount", "ToAccount", "Amount")]
public async Task<IActionResult> Transfer([FromBody] TransferDto dto) { }

// 示例4：全局锁（所有用户共享同一把锁）
[HttpPost("system-reset")]
[PreventDuplicateRequests(UseGlobal = true)]
public async Task<IActionResult> SystemReset() { }

// 示例5：自定义过期时间和提示语
[HttpPost("submit-form")]
[PreventDuplicateRequests(ExpiredSeconds = 10, ErrorMessage = "表单正在提交，请勿重复操作")]
public async Task<IActionResult> SubmitForm([FromBody] FormDto dto) { }
```

## 注册服务

```csharp
public void ConfigureServices(IServiceCollection services)
{
    // 注册防高频点击过滤器
    services.AddPreventRapidFireFilter();

    // 注册防重复提交过滤器
    services.AddPreventDuplicateRequestsFilter();
}
```

## 典型业务场景

### 场景1：搜索接口（快速响应）

```csharp
// 用户可能疯狂点击搜索，防高频
[HttpPost("search")]
[PreventRapidFire(ExpiredSeconds = 2)]
public async Task<IActionResult> Search([FromBody] SearchDto dto) { }
```

### 场景2：提交订单（耗时操作）

```csharp
// 订单创建可能涉及多个步骤，防重复
[HttpPost]
[PreventDuplicateRequests]
public async Task<IActionResult> Create([FromBody] CreateOrderDto dto) { }
```

### 场景3：点赞/收藏（快速响应）

```csharp
// 防止用户快速连续点赞
[HttpPost("like")]
[PreventRapidFire(ExpiredSeconds = 1)]
public async Task<IActionResult> Like([FromBody] LikeDto dto) { }
```

### 场景4：导出/生成报告（耗时操作）

```csharp
// 导出可能需要较长时间
[HttpPost("export")]
[PreventDuplicateRequests(ExpiredSeconds = 30)]
public async Task<IActionResult> Export([FromBody] ExportDto dto) { }
```

### 场景5：发送验证码（安全性）

```csharp
// 短信验证码，防止恶意刷验证码
[HttpPost("send-code")]
[PreventRapidFire(ExpiredSeconds = 60, OnCooldownEnd = async ctx =>
{
    await LogService.LogAsync($"验证码冷却结束: {ctx.UserId}");
})]
public async Task<IActionResult> SendCode([FromBody] SendCodeDto dto) { }
```

### 场景6：全局限流（如系统级操作）

```csharp
// 数据库备份等系统级操作
[HttpPost("backup")]
[PreventDuplicateRequests(UseGlobal = true, ExpiredSeconds = 3600)]
public async Task<IActionResult> Backup() { }
```

## PreventOversellAttribute - 防超卖

解决高并发场景下的库存超卖问题，基于 Redis 原子操作 `DECR` / `INCR` / `SETNX` 实现，确保多个请求同时到达时不会出现竞态条件。

### 工作原理

```
请求到达 → DECR 库存 key
    ↓
扣减后值 >= 0？ → 否 → INCR 回滚 + 抛异常
    ↓ 是
执行业务逻辑
    ↓
业务异常？ → 是 → INCR 回滚
```

### 注册过滤器

```csharp
// 必须注册过滤器（特性基于 IFilterFactory 从 DI 解析）
services.AddPreventOversellFilter();
```

### 基本用法

```csharp
// 以 ProductId 字段作为库存 key
[HttpPost("buy")]
[PreventOversell("ProductId")]
public async Task<IActionResult> Buy([FromBody] FlashSaleRequest req)
{
    // 库存已自动扣减，剩余库存可从 HttpContext.Items["OversellRemainingStock"] 读取
    var remaining = (long)HttpContext.Items["OversellRemainingStock"];
    return Ok(new { remaining });
}
```

### 完整配置

```csharp
[AttributeUsage(AttributeTargets.Method)]
public class PreventOversellAttribute : Attribute, IFilterFactory
{
    /// <summary>
    /// 自定义库存不足提示语
    /// </summary>
    public string ErrorMessage { get; set; }

    /// <summary>
    /// 初始库存值（当 key 不存在时自动初始化），默认 0 表示不初始化
    /// </summary>
    public long InitialStock { get; set; }

    /// <summary>
    /// 构造函数，指定用于构建库存 key 的字段名
    /// </summary>
    /// <param name="stockKeyFields">字段名（支持对象属性路径，如 req.ProductId）</param>
    public PreventOversellAttribute(params string[] stockKeyFields) { }
}
```

### 使用示例

```csharp
// 示例1：单字段库存 key
[HttpPost("buy")]
[PreventOversell("ProductId")]
public async Task<IActionResult> Buy([FromBody] BuyRequest req) { }

// 示例2：自动初始化库存
[HttpPost("flash-sale")]
[PreventOversell("ProductId", InitialStock = 100)]
public async Task<IActionResult> FlashSale([FromBody] BuyRequest req) { }

// 示例3：多字段组合 key
[HttpPost("warehouse-buy")]
[PreventOversell("ProductId", "WarehouseId", InitialStock = 50)]
public async Task<IActionResult> WarehouseBuy([FromBody] BuyRequest req) { }

// 示例4：自定义错误提示
[HttpPost("promotion")]
[PreventOversell("ProductId", InitialStock = 200, ErrorMessage = "活动太火爆，库存不足")]
public async Task<IActionResult> Promotion([FromBody] BuyRequest req) { }

// 示例5：对象属性路径
public class BuyRequest
{
    public FlashSaleInfo FlashSale { get; set; }
}
public class FlashSaleInfo
{
    public int ProductId { get; set; }
}

[HttpPost("path")]
[PreventOversell("FlashSale.ProductId")]
public async Task<IActionResult> BuyByPath([FromBody] BuyRequest req) { }
```

### 注意事项

1. **依赖 Redis**：`PreventOversell` 必须基于支持原子 `DECR` / `INCR` 的缓存实现，Memory 缓存会因无原子操作导致超卖
2. **库存 Key 格式**：`oversell:stock:{keyFields}`
3. **业务失败自动回滚**：业务执行抛出异常时，库存会自动 `INCR` 回滚
4. **成功不自动回滚**：扣减成功后即使后续 `OnActionExecuted` 出错也不会回滚，避免影响真实已售库存
5. **需注册过滤器**：`AddPreventOversellFilter()` 是必需的，否则启动时会报 `InvalidOperationException`
6. **字段路径**：支持直接 Action 参数名，也支持 `req.Property` 形式的嵌套对象属性路径

## 与缓存的结合

两种防护都基于 `ICacheService` 实现：

```csharp
// PreventRapidFire 使用 Exists + Set
if (_cache.Exists(cacheKey))
{
    throw new CommonException("操作太频繁");
}
await next();
_cache.Set(cacheKey, 1, ExpiredSeconds);

// PreventDuplicateRequests 使用 SetNX + Del
if (!await _cache.SetNXAsync(lockKey, 1, ExpiredSeconds))
{
    throw new CommonException("系统正在处理，请勿重复提交");
}
try
{
    await next();
}
finally
{
    _cache.Del(lockKey);
}
```

## 注意事项

1. **选择合适的防护类型**：根据业务特性选择
2. **设置合理的过期时间**：太短可能无效，太长影响体验
3. **使用 Redis 缓存**：多实例部署时保证一致性
4. **自定义 key 时避免冲突**：确保不同接口的 key 不会重复
5. **异步回调不阻塞请求**：OnCooldownEnd 在后台执行
