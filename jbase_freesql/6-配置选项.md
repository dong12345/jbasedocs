# 配置选项

配置选项位于 `JBase.FreeSql.Core.Options` 命名空间。

## 1. AuditOptions

审计配置选项，用于配置审计字段的默认值。

### 属性

| 属性 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| DefaultCreatedBy | string | "0" | 默认创建人ID（当无法获取当前用户时使用） |
| DefaultUpdatedBy | string | "0" | 默认更新人ID（当无法获取当前用户时使用） |

> **注意**：`DefaultCreatedBy` 和 `DefaultUpdatedBy` 的类型是 `string`，这是设计上的权衡——允许配置为任何类型的默认值字符串（如 `"0"`、`"system"`、`"00000000-0000-0000-0000-000000000000"`），然后在运行时根据实体字段的实际类型自动转换。

### 使用示例

```csharp
services.AddJBaseFreeSql<int>(
    DataType.MySql,
    connectionString,
    new AuditOptions
    {
        DefaultCreatedBy = "0",   // 系统创建
        DefaultUpdatedBy = "0"    // 系统更新
    });
```

### Guid 用户ID类型

```csharp
services.AddJBaseFreeSql<Guid>(
    DataType.MySql,
    connectionString,
    new AuditOptions
    {
        DefaultCreatedBy = Guid.Empty.ToString(),
        DefaultUpdatedBy = Guid.Empty.ToString()
    });
```

## 2. EnumMappingOptions

枚举映射配置选项，用于配置枚举类型到数据库字段的映射策略。

### EnumMappingStrategy 枚举

| 值 | 说明 |
|----|------|
| `Enum` | 映射为数据库原生枚举类型 |
| `Int` | 映射为整数类型（默认值） |
| `String` | 映射为字符串类型 |

### 属性

| 属性 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| DefaultStrategy | EnumMappingStrategy | EnumMappingStrategy.Int | 全局枚举映射策略 |

### 使用示例

#### 映射为整数（默认）

```csharp
services.AddJBaseFreeSql<int>(
    DataType.MySql,
    connectionString,
    null,  // auditOptions
    new EnumMappingOptions
    {
        DefaultStrategy = EnumMappingStrategy.Int
    });
```

#### 映射为字符串

```csharp
services.AddJBaseFreeSql<int>(
    DataType.MySql,
    connectionString,
    null,
    new EnumMappingOptions
    {
        DefaultStrategy = EnumMappingStrategy.String
    });
```

## 3. 完整配置示例

### MySQL 配置

```csharp
services.AddJBaseFreeSql<int>(
    DataType.MySql,
    "Server=localhost;Database=mydb;Uid=root;Pwd=123456;Charset=utf8mb4;",
    new AuditOptions
    {
        DefaultCreatedBy = "0",
        DefaultUpdatedBy = "0"
    },
    new EnumMappingOptions
    {
        DefaultStrategy = EnumMappingStrategy.Int
    });
```

### SQL Server 配置

```csharp
services.AddJBaseFreeSql<int>(
    DataType.SqlServer,
    "Server=localhost;Database=mydb;User=sa;Password=123456;TrustServerCertificate=True;",
    new AuditOptions
    {
        DefaultCreatedBy = "0",
        DefaultUpdatedBy = "0"
    },
    new EnumMappingOptions
    {
        DefaultStrategy = EnumMappingStrategy.Int
    });
```

### 使用 FreeSql 构建器

```csharp
services.AddJBaseFreeSql<int>(
    builder =>
    {
        builder.UseConnectionString(DataType.MySql, "Server=localhost;Database=mydb;Uid=root;Pwd=123456;")
               .UseAutoSyncStructure(true)           // 自动同步结构
               .UseLazyLoading(true)                 // 启用懒加载
               .UseNoneCommandParameter(true);      // 参数化查询
    },
    new AuditOptions
    {
        DefaultCreatedBy = "0",
        DefaultUpdatedBy = "0"
    },
    new EnumMappingOptions
    {
        DefaultStrategy = EnumMappingStrategy.Int
    });
```

## 4. 配置说明

### AuditOptions 何时使用

当发生以下情况时，使用 `AuditOptions` 中的默认值：

| 场景 | 使用的默认值 |
|------|-------------|
| 插入实体，获取不到当前用户 | `DefaultCreatedBy` |
| 更新实体，获取不到当前用户 | `DefaultUpdatedBy` |

### 获取当前用户的方式

当前用户通过 `IUser` 接口获取：

```csharp
public interface IUser
{
    /// <summary>
    /// 用户Id（string类型）
    /// </summary>
    string Id { get; }

    /// <summary>
    /// 用户名
    /// </summary>
    string Name { get; }

    /// <summary>
    /// 角色集合
    /// </summary>
    IEnumerable<string> Roles { get; }

    /// <summary>
    /// 邮箱
    /// </summary>
    string Email { get; }

    /// <summary>
    /// 手机号
    /// </summary>
    string Phone { get; }

    /// <summary>
    /// 是否已认证
    /// </summary>
    bool IsAuthenticated { get; }
}

/// <summary>
/// 泛型用户接口，Id属性为指定类型
/// </summary>
public interface IUser<TKey> : IUser
{
    /// <summary>
    /// 用户Id（指定类型）
    /// </summary>
    new TKey Id { get; }
}
```

> **注意**：使用 `AddJBaseFreeSql<TUserKey>` 注册服务时，系统会自动注册 `IUser<TUserKey>` 和 `IUser` 实现，无需自行实现。如果需要自定义用户信息，可实现 `IUser<TKey>` 接口替换默认实现。

**自定义用户实现示例（可选）**

```csharp
public class CurrentUser<TKey> : IUser<TKey>
{
    private readonly IHttpContextAccessor _accessor;

    public CurrentUser(IHttpContextAccessor accessor)
    {
        _accessor = accessor;
    }

    public TKey Id => GetId();

    // IUser.Id 实现
    string IUser.Id => Id?.ToString() ?? string.Empty;

    public string Name => GetClaimValue(ClaimTypes.Name);

    public IEnumerable<string> Roles =>
        _accessor.HttpContext?.User?.Claims
            ?.Where(x => x.Type == ClaimTypes.Role)
            .Select(x => x.Value) ?? Enumerable.Empty<string>();

    public string Email => GetClaimValue(ClaimTypes.Email);

    public string Phone => GetClaimValue(ClaimTypes.MobilePhone);

    public bool IsAuthenticated =>
        _accessor.HttpContext?.User?.Identity?.IsAuthenticated ?? false;

    private TKey GetId()
    {
        var val = GetClaimValue(ClaimTypes.NameIdentifier);
        if (typeof(TKey) == typeof(string)) return (TKey)(object)val;
        if (typeof(TKey) == typeof(long)) return (TKey)(object)long.Parse(val);
        if (typeof(TKey) == typeof(int)) return (TKey)(object)int.Parse(val);
        if (typeof(TKey) == typeof(Guid)) return (TKey)(object)Guid.Parse(val);
        throw new NotSupportedException($"不支持的主键类型: {typeof(TKey).Name}");
    }

    private string GetClaimValue(string claimType)
    {
        return _accessor.HttpContext?.User?.Claims
            ?.FirstOrDefault(x => x.Type == claimType)?.Value!;
    }
}
```

**注册自定义用户实现**

```csharp
// 使用 AddJBaseFreeSql 后，手动替换 IUser 实现
builder.Services.AddScoped<IUser<int>, CurrentUser<int>>();
builder.Services.AddScoped<IUser>(sp => sp.GetRequiredService<IUser<int>>());
```

### EnumMappingStrategy 说明

#### Int 策略（推荐）

```csharp
public enum Status
{
    Pending = 0,
    Active = 1,
    Disabled = 2
}

// 数据库字段类型: int
// 存储值: 0, 1, 2
```

#### String 策略

```csharp
public enum Status
{
    Pending,
    Active,
    Disabled
}

// 数据库字段类型: varchar
// 存储值: "Pending", "Active", "Disabled"
```

#### Enum 策略

```csharp
public enum Status
{
    Pending,
    Active,
    Disabled
}

// 数据库字段类型: enum('Pending','Active','Disabled')
// 仅部分数据库支持（如 MySQL）
```

## 5. 多数据库配置

### 同时支持 MySQL 和 SQL Server

```csharp
// MySQL
services.AddJBaseFreeSql<int>(
    DataType.MySql,
    "MySQL连接字符串",
    new AuditOptions(),
    new EnumMappingOptions());

// SQL Server（在同一应用中支持多数据库）
services.AddJBaseFreeSql<int>(
    builder => builder.UseConnectionString(DataType.SqlServer, "SQL Server连接字符串"),
    new AuditOptions(),
    new EnumMappingOptions());
```

## 6. 常见问题

### Q: 如何禁用审计功能？

A: 不继承 `AuditEntity`，改为继承 `BaseEntity` 即可：

```csharp
// 不记录审计信息
public class Config : BaseEntity
{
    public string Key { get; set; }
    public string Value { get; set; }
}
```

### Q: 如何只记录创建人不记录更新人？

A: 自定义实体基类：

```csharp
public abstract class CreateOnlyEntity : BaseEntity, IAuditCreated<int>
{
    public DateTime CreatedDate { get; set; }
    public int? CreatedBy { get; set; }
}

public class Log : CreateOnlyEntity
{
    public string Message { get; set; }
}
```
