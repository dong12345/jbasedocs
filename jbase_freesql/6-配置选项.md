# 配置选项

配置选项位于 `JBase.FreeSql.Core.Options` 命名空间。

## 1. AuditOptions

审计配置选项，用于配置审计字段的默认值。

### 属性

| 属性 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| DefaultCreatedBy | string | "0" | 默认创建人ID（当无法获取当前用户时使用） |
| DefaultUpdatedBy | string | "0" | 默认更新人ID（当无法获取当前用户时使用） |

### 使用示例

```csharp
services.AddJBaseFreeSql<int>(
    DataType.MySql,
    connectionString,
    new AuditOptions
    {
        DefaultCreatedBy = "0",   // 系统创建
        DefaultUpdatedBy = "0"    // 系统更新
    });
```

### Guid 用户ID类型

```csharp
services.AddJBaseFreeSql<Guid>(
    DataType.MySql,
    connectionString,
    new AuditOptions
    {
        DefaultCreatedBy = Guid.Empty.ToString(),
        DefaultUpdatedBy = Guid.Empty.ToString()
    });
```

## 2. EnumMappingOptions

枚举映射配置选项，用于配置枚举类型到数据库字段的映射策略。

### EnumMappingStrategy 枚举

| 值 | 说明 |
|----|------|
| `Enum` | 映射为数据库原生枚举类型 |
| `Int` | 映射为整数类型（默认值） |
| `String` | 映射为字符串类型 |

### 属性

| 属性 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| DefaultStrategy | EnumMappingStrategy | EnumMappingStrategy.Int | 全局枚举映射策略 |

### 使用示例

#### 映射为整数（默认）

```csharp
services.AddJBaseFreeSql<int>(
    DataType.MySql,
    connectionString,
    null,  // auditOptions
    new EnumMappingOptions
    {
        DefaultStrategy = EnumMappingStrategy.Int
    });
```

#### 映射为字符串

```csharp
services.AddJBaseFreeSql<int>(
    DataType.MySql,
    connectionString,
    null,
    new EnumMappingOptions
    {
        DefaultStrategy = EnumMappingStrategy.String
    });
```

## 3. 完整配置示例

### MySQL 配置

```csharp
services.AddJBaseFreeSql<int>(
    DataType.MySql,
    "Server=localhost;Database=mydb;Uid=root;Pwd=123456;Charset=utf8mb4;",
    new AuditOptions
    {
        DefaultCreatedBy = "0",
        DefaultUpdatedBy = "0"
    },
    new EnumMappingOptions
    {
        DefaultStrategy = EnumMappingStrategy.Int
    });
```

### SQL Server 配置

```csharp
services.AddJBaseFreeSql<int>(
    DataType.SqlServer,
    "Server=localhost;Database=mydb;User=sa;Password=123456;TrustServerCertificate=True;",
    new AuditOptions
    {
        DefaultCreatedBy = "0",
        DefaultUpdatedBy = "0"
    },
    new EnumMappingOptions
    {
        DefaultStrategy = EnumMappingStrategy.Int
    });
```

### 使用 FreeSql 构建器

```csharp
services.AddJBaseFreeSql<int>(
    builder =>
    {
        builder.UseConnectionString(DataType.MySql, "Server=localhost;Database=mydb;Uid=root;Pwd=123456;")
               .UseAutoSyncStructure(true)           // 自动同步结构
               .UseLazyLoading(true)                 // 启用懒加载
               .UseNoneCommandParameter(true);      // 参数化查询
    },
    new AuditOptions
    {
        DefaultCreatedBy = "0",
        DefaultUpdatedBy = "0"
    },
    new EnumMappingOptions
    {
        DefaultStrategy = EnumMappingStrategy.Int
    });
```

## 4. 配置说明

### AuditOptions 何时使用

当发生以下情况时，使用 `AuditOptions` 中的默认值：

| 场景 | 使用的默认值 |
|------|-------------|
| 插入实体，获取不到当前用户 | `DefaultCreatedBy` |
| 更新实体，获取不到当前用户 | `DefaultUpdatedBy` |

### 获取当前用户的方式

当前用户通过 `IUser` 接口获取：

```csharp
public interface IUser
{
    T GetUserId<T>();
    string GetUserName();
    // 其他用户信息...
}
```

需要自行实现 `IUser` 接口并注册到容器：

```csharp
public class CurrentUser : IUser
{
    private readonly IHttpContextAccessor _accessor;

    public CurrentUser(IHttpContextAccessor accessor)
    {
        _accessor = accessor;
    }

    public int GetUserId<int>()
    {
        var claim = _accessor.HttpContext?.User?.FindFirst(ClaimTypes.NameIdentifier);
        return claim != null ? int.Parse(claim.Value) : 0;
    }

    public string GetUserName()
    {
        return _accessor.HttpContext?.User?.Identity?.Name ?? "Anonymous";
    }
}

// 注册
builder.Services.AddHttpContextAccessor();
builder.Services.AddScoped<IUser, CurrentUser>();
```

### EnumMappingStrategy 说明

#### Int 策略（推荐）

```csharp
public enum Status
{
    Pending = 0,
    Active = 1,
    Disabled = 2
}

// 数据库字段类型: int
// 存储值: 0, 1, 2
```

#### String 策略

```csharp
public enum Status
{
    Pending,
    Active,
    Disabled
}

// 数据库字段类型: varchar
// 存储值: "Pending", "Active", "Disabled"
```

#### Enum 策略

```csharp
public enum Status
{
    Pending,
    Active,
    Disabled
}

// 数据库字段类型: enum('Pending','Active','Disabled')
// 仅部分数据库支持（如 MySQL）
```

## 5. 多数据库配置

### 同时支持 MySQL 和 SQL Server

```csharp
// MySQL
services.AddJBaseFreeSql<int>(
    DataType.MySql,
    "MySQL连接字符串",
    new AuditOptions(),
    new EnumMappingOptions());

// 或者使用命名连接
services.AddJBaseFreeSql<int>("mysql", builder =>
{
    builder.UseConnectionString(DataType.MySql, "MySQL连接字符串");
});
```

## 6. 常见问题

### Q: 如何禁用审计功能？

A: 不继承 `AuditEntity`，改为继承 `BaseEntity` 即可：

```csharp
// 不记录审计信息
public class Config : BaseEntity
{
    public string Key { get; set; }
    public string Value { get; set; }
}
```

### Q: 如何只记录创建人不记录更新人？

A: 自定义实体基类：

```csharp
public abstract class CreateOnlyEntity : BaseEntity, IAuditCreated<int>
{
    public DateTime CreatedDate { get; set; }
    public int? CreatedBy { get; set; }
}

public class Log : CreateOnlyEntity
{
    public string Message { get; set; }
}
```
