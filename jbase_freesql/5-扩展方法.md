# 扩展方法

扩展方法位于 `JBase.FreeSql.Core.Extensions` 命名空间，提供依赖注入、分页、事务等核心功能。

## 1. FreeExtensions

核心扩展类，提供所有静态扩展方法。

### 1.1 静态属性

| 属性 | 类型 | 说明 |
|------|------|------|
| User | IUser | 当前用户 |
| FreeSql | IFreeSql | FreeSql 实例 |
| ContextAccessor | IHttpContextAccessor | HTTP 上下文访问器 |
| AuditOptions | AuditOptions | 审计配置 |
| EnumMappingOptions | EnumMappingOptions | 枚举映射配置 |
| AsyncContext | AsyncOrmContext | 异步上下文（事务管理） |

### 1.2 依赖注入扩展方法

#### AddJBaseFreeSql\<TUserKey\>

注册 FreeSql 服务到依赖注入容器。

**泛型约束**

`TUserKey` 支持任意值类型或引用类型作为用户ID类型，包括：`int`、`long`、`Guid`、`string` 等。系统会自动注册对应类型的 `IUser<TUserKey>` 和 `IUser` 实现。

**重载一：指定连接字符串**

```csharp
public static IServiceCollection AddJBaseFreeSql<TUserKey>(
    this IServiceCollection services,
    DataType dataType,
    string connectionString,
    AuditOptions auditOptions = null,
    EnumMappingOptions enumMappingOptions = null)
    where TUserKey : struct;
```

**使用示例**

```csharp
services.AddJBaseFreeSql<int>(
    DataType.MySql,
    "Server=localhost;Database=mydb;Uid=root;Pwd=123456;",
    new AuditOptions { DefaultCreatedBy = "0" },
    new EnumMappingOptions { DefaultStrategy = EnumMappingStrategy.Int }
);
```

**重载二：使用 FreeSql 构建器**

```csharp
public static IServiceCollection AddJBaseFreeSql<TUserKey>(
    this IServiceCollection services,
    Action<FreeSqlBuilder> configure,
    AuditOptions auditOptions = null,
    EnumMappingOptions enumMappingOptions = null)
    where TUserKey : struct;
```

**使用示例**

```csharp
services.AddJBaseFreeSql<Guid>(
    builder => builder
        .UseConnectionString(DataType.MySql, "...")
        .UseAutoSyncStructure(true)
        .UseLazyLoading(true),
    new AuditOptions(),
    new EnumMappingOptions()
);
```

#### UseJBaseFreeSql

初始化 JBaseFreeSql，从容器获取依赖。

```csharp
public static void UseJBaseFreeSql(this IApplicationBuilder app);
```

**使用示例**

```csharp
var app = builder.Build();

app.UseJBaseFreeSql();

app.Run();
```

### 1.3 分页扩展方法

#### GetPage / GetPageAsync

对 ISelect 进行分页查询。

**同步版本**

```csharp
public static PageOut<T> GetPage<T>(this ISelect<T> select, int pageIndex, int pageSize)
    where T : class;
```

**异步版本**

```csharp
public static Task<PageOut<T>> GetPageAsync<T>(
    this ISelect<T> select,
    int pageIndex,
    int pageSize,
    CancellationToken cancellationToken = default)
    where T : class;
```

**使用示例**

```csharp
var orm = GetRequiredService<IFreeSql>();

var page = orm.Select<User>()
    .Where(x => x.Status == 1)
    .OrderByDescending(x => x.CreatedDate)
    .GetPage(pageIndex: 1, pageSize: 10);

Console.WriteLine($"总记录数: {page.Total}");
Console.WriteLine($"总页数: {page.TotalPages}");
foreach (var user in page.Result)
{
    Console.WriteLine(user.Name);
}
```

#### ToPage

转换为分页结果并返回总数。

```csharp
public static ISelect<T> ToPage<T>(
    this ISelect<T> select,
    int pageIndex,
    int pageSize,
    out long total)
    where T : class;
```

**使用示例**

```csharp
var orm = GetRequiredService<IFreeSql>();

var query = orm.Select<User>()
    .Where(x => x.Status == 1)
    .OrderByDescending(x => x.CreatedDate)
    .ToPage(1, 10, out long total);

Console.WriteLine($"总记录数: {total}");

var users = await query.ToListAsync();
```

### 1.4 事务扩展方法

#### TransactionAsync\<T\>

异步执行事务（带返回值）。

```csharp
public static async Task<T> TransactionAsync<T>(
    this IFreeSql fsql,
    Func<Task<T>> action,
    IsolationLevel isolationLevel = IsolationLevel.ReadCommitted)
{
    // 实现逻辑
}
```

**使用示例**

```csharp
var orm = GetRequiredService<IFreeSql>();

var result = await orm.TransactionAsync(async () =>
{
    var user = await _userService.InsertAsync(new User { Name = "张三" });
    var order = await _orderService.InsertAsync(new Order { OrderNo = "20240101" });
    return new { UserId = user.Id, OrderId = order.Id };
});
```

#### TransactionAsync

异步执行事务（无返回值）。

```csharp
public static async Task TransactionAsync(
    this IFreeSql fsql,
    Func<Task> action,
    IsolationLevel isolationLevel = IsolationLevel.ReadCommitted);
```

**使用示例**

```csharp
await orm.TransactionAsync(async () =>
{
    await _userService.InsertAsync(new User { Name = "李四" });
    await _roleService.InsertAsync(new Role { Name = "Admin" });
});
```

#### Transaction\<T\>

同步执行事务（带返回值）。

```csharp
public static T Transaction<T>(
    this IFreeSql fsql,
    Func<T> action,
    IsolationLevel isolationLevel = IsolationLevel.ReadCommitted);
```

#### Transaction

同步执行事务（无返回值）。

```csharp
public static void Transaction(
    this IFreeSql fsql,
    Action action,
    IsolationLevel isolationLevel = IsolationLevel.ReadCommitted);
```

### 1.5 仓储获取扩展

#### GetRepository

获取对应实体的仓储实例。

```csharp
public static IBaseRepository<TEntity> GetRepository<TEntity>(
    this IFreeSql fsql)
    where TEntity : BaseEntity<int>, new();

public static IBaseRepository<TEntity, TPrimaryKey> GetRepository<TEntity, TPrimaryKey>(
    this IFreeSql fsql)
    where TEntity : BaseEntity<TPrimaryKey>, new()
    where TPrimaryKey : notnull;
```

**使用示例**

```csharp
var orm = GetRequiredService<IFreeSql>();

// 获取 int 主键仓储
var userRepo = orm.GetRepository<User>();

// 获取指定主键类型仓储
var orderRepo = orm.GetRepository<Order, long>();
```

## 2. ServiceExtensions

服务层扩展方法。

### Where 扩展

```csharp
public static ISelect<TEntity> Where<TEntity, TPrimaryKey>(
    this IBaseService<TEntity, TPrimaryKey> service,
    Expression<Func<TEntity, bool>> predicate)
    where TEntity : IBaseEntity, new()
    where TPrimaryKey : notnull;
```

**使用示例**

```csharp
var select = _userService.Where(x => x.Status == 1 && x.Age > 20);
var users = await select.ToListAsync();
```

> **注意**：此扩展方法要求 service 实例的类型必须是 `BaseService<TEntity, TPrimaryKey>` 或其子类。如果服务是通过依赖注入创建的，则自动满足条件。

## 3. RepositoryExtensions

仓储层扩展方法。

### Where 扩展

```csharp
public static ISelect<TEntity> Where<TEntity, TPrimaryKey>(
    this IBaseRepository<TEntity, TPrimaryKey> repository,
    Expression<Func<TEntity, bool>> predicate)
    where TEntity : IBaseEntity, new()
    where TPrimaryKey : notnull;
```

**使用示例**

```csharp
var select = _userRepository.Where(x => x.IsDeleted == false);
var users = await select.ToListAsync();
```

> **注意**：此扩展方法要求 repository 实例的类型必须是 `BaseRepository<TEntity, TPrimaryKey>` 或其子类。

## 5. 嵌套事务支持

FreeExtensions 实现了嵌套事务支持：

```csharp
await orm.TransactionAsync(async () =>
{
    await InsertUserAsync();

    await orm.TransactionAsync(async () =>  // 嵌套事务，不会真正开启新事务
    {
        await UpdateOrderAsync();
    });
});  // 只有最外层提交
```

实现原理：使用 `AsyncContext.TranCounter` 计数器管理事务嵌套层级。
