# 实体基类

实体层位于 `JBase.FreeSql.Core.Entity` 命名空间，提供了丰富的基类和接口来满足不同的业务场景。

## 1. 接口定义

### IBaseEntity

空接口，作为所有实体的标记接口。

```csharp
public interface IBaseEntity { }
```

### IAuditDeleted

软删除审计接口，实现此接口的实体支持软删除。

```csharp
public interface IAuditDeleted
{
    bool IsDeleted { set; get; }
}
```

### IAuditCreated\<TUserKey\>

创建审计接口。

```csharp
public interface IAuditCreated<TUserKey>
{
    DateTime CreatedDate { get; set; }
    TUserKey? CreatedBy { get; set; }
}
```

### IAuditUpdated\<TUserKey\>

更新审计接口。

```csharp
public interface IAuditUpdated<TUserKey>
{
    DateTime? UpdatedDate { get; set; }
    TUserKey? UpdatedBy { get; set; }
}
```

### IAuditEntity\<TUserKey\>

完整的审计接口，继承自 `IBaseEntity`、`IAuditCreated<TUserKey>`、`IAuditUpdated<TUserKey>`、`IAuditDeleted`。

```csharp
public interface IAuditEntity<TUserKey> :
    IBaseEntity,
    IAuditCreated<TUserKey>,
    IAuditUpdated<TUserKey>,
    IAuditDeleted
{ }
```

## 2. 基础实体类

### BaseEntity\<TPrimaryKey\>

仅包含主键的实体基类。

```csharp
public class BaseEntity<TPrimaryKey> : IBaseEntity
    where TPrimaryKey : notnull
{
    [Column(IsPrimary = true, IsIdentity = true)]
    public TPrimaryKey Id { get; set; }
}
```

| 属性 | 类型 | 特性 | 说明 |
|------|------|------|------|
| Id | TPrimaryKey | `[Column(IsPrimary = true, IsIdentity = true)]` | 主键字段 |

### 非泛型基础实体类

| 类名 | 主键类型 | 说明 |
|------|----------|------|
| `BaseEntity` | int | 最常用的实体基类 |
| `BaseGuidEntity` | Guid | 使用 Guid 作为主键 |
| `BaseLongEntity` | long | 使用 long 作为主键 |
| `BaseStringEntity` | string | 使用 string 作为主键 |

### BaseEntity 使用示例

```csharp
// int 主键
public class Category : BaseEntity
{
    public string Name { get; set; }
}

// Guid 主键
public class Session : BaseGuidEntity
{
    public string Token { get; set; }
    public DateTime ExpiresAt { get; set; }
}

// long 主键
public class Log : BaseLongEntity
{
    public string Message { get; set; }
    public string Level { get; set; }
}

// string 主键（如自定义编码）
public class Config : BaseStringEntity
{
    public string Key { get; set; }
    public string Value { get; set; }
}
```

## 3. 审计实体类

### AuditEntity\<TPrimaryKey, TUserKey\>

包含完整审计字段的实体基类。

```csharp
public class AuditEntity<TPrimaryKey, TUserKey> :
    BaseEntity<TPrimaryKey>,
    IAuditEntity<TUserKey>
{
    public DateTime CreatedDate { get; set; }
    public TUserKey? CreatedBy { get; set; }
    public bool IsDeleted { get; set; }
    public DateTime? UpdatedDate { get; set; }
    public TUserKey? UpdatedBy { get; set; }
}
```

| 属性 | 类型 | 说明 |
|------|------|------|
| CreatedDate | DateTime | 创建日期 |
| CreatedBy | TUserKey? | 创建人ID |
| IsDeleted | bool | 是否删除（软删除标记） |
| UpdatedDate | DateTime? | 更新日期 |
| UpdatedBy | TUserKey? | 更新人ID |

### 非泛型审计实体类

| 类名 | 主键类型 | 用户ID类型 | 说明 |
|------|----------|------------|------|
| `AuditEntity` | int | int | 最常用的审计实体 |
| `AuditLongEntity` | long | long | 长整型主键和用户ID |
| `AuditGuidEntity` | Guid | Guid | Guid 主键和用户ID |
| `AuditStringEntity` | string | string | 字符串主键和用户ID |

### AuditEntity 使用示例

```csharp
// 推荐：使用默认的 int 类型
public class User : AuditEntity
{
    public string Name { get; set; }
    public string Email { get; set; }
    public string PasswordHash { get; set; }
}

// 如果用户ID是 Guid 类型
public class Order : AuditGuidEntity
{
    public string OrderNo { get; set; }
    public decimal TotalAmount { get; set; }
}
```

## 4. 实体继承体系图

```
┌─────────────┐
│ IBaseEntity │
└─────────────┘
       ▲
       │ implements
┌──────┴──────────────────┐
│     BaseEntity<T>       │
├──────────────────────────┤
│ + Id: T                 │
└──────────────────────────┘
       │
       ├──► BaseEntity (T=int)
       ├──► BaseGuidEntity (T=Guid)
       ├──► BaseLongEntity (T=long)
       └──► BaseStringEntity (T=string)
               │
               │ extends
               ▼
┌──────────────────────────────────────────────────┐
│           AuditEntity<T, U>                      │
├──────────────────────────────────────────────────┤
│ + Id: T (from BaseEntity)                       │
│ + CreatedDate: DateTime                         │
│ + CreatedBy: U?                                 │
│ + IsDeleted: bool                               │
│ + UpdatedDate: DateTime?                        │
│ + UpdatedBy: U?                                 │
└──────────────────────────────────────────────────┘
               │
               ├──► AuditEntity (T=int, U=int)
               ├──► AuditLongEntity (T=long, U=long)
               ├──► AuditGuidEntity (T=Guid, U=Guid)
               └──► AuditStringEntity (T=string, U=string)
```

## 5. 特性说明

### Column 特性

实体基类中的 `Id` 属性使用了 FreeSql 的 `[Column]` 特性：

| 属性 | 值 | 说明 |
|------|-----|------|
| IsPrimary | true | 标记为主键 |
| IsIdentity | true | 自增列（仅对数值类型有效） |

> **注意**：`IsIdentity` 对 string 类型的 Guid 主键无效，需要手动设置主键值。

## 6. 最佳实践

### 选择合适的实体基类

| 场景 | 推荐基类 |
|------|----------|
| 简单的增删改查表 | `BaseEntity` |
| 需要审计的表（用户、时间戳） | `AuditEntity` |
| 需要软删除的表 | `AuditEntity` |
| 微服务/分布式场景 | `BaseGuidEntity` 或 `AuditGuidEntity` |
| 超大表（超过 int 范围） | `BaseLongEntity` 或 `AuditLongEntity` |

### 审计实体使用建议

1. **统一用户ID类型**：建议整个项目使用统一的用户ID类型（推荐 `int` 或 `Guid`）
2. **合理设置默认值**：通过 `AuditOptions.DefaultCreatedBy` 和 `DefaultUpdatedBy` 设置合理的默认值
3. **避免频繁更新**：审计字段更新频繁的表，建议单独拆分或使用数据库触发器
