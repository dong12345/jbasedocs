# 服务层

服务层位于 `JBase.FreeSql.Core.Service` 命名空间，是业务逻辑的核心层，封装了仓储层的操作。

## 1. 接口定义

### IBaseService

服务接口，继承自 `IBaseRepository`，提供所有数据操作方法。

#### 泛型约束

| 接口 | 约束 | 说明 |
|------|------|------|
| `IBaseService<TEntity, TPrimaryKey>` | `where TEntity : IBaseEntity, new()` | 通用服务 |
| `IBaseService<TEntity>` | `where TEntity : BaseEntity<int>, new()` | int 主键服务 |
| `IBaseLongService<TEntity>` | `where TEntity : BaseEntity<long>, new()` | long 主键服务 |
| `IBaseGuidService<TEntity>` | `where TEntity : BaseEntity<Guid>, new()` | Guid 主键服务 |
| `IBaseStringService<TEntity>` | `where TEntity : BaseEntity<string>, new()` | string 主键服务 |

## 2. 服务实现类

### BaseService 类

```csharp
public class BaseService : IBaseService
{
    // 基础服务实现
}

public class BaseService<TEntity, TPrimaryKey> : BaseService, IBaseService<TEntity, TPrimaryKey>

    // 具体服务实现

```

#### 继承结构

```
BaseService
├── BaseService<TEntity>         (TPrimaryKey = int)
├── BaseLongService<TEntity>      (TPrimaryKey = long)
├── BaseGuidService<TEntity>      (TPrimaryKey = Guid)
└── BaseStringService<TEntity>    (TPrimaryKey = string)
```

## 5. 服务方法

服务层方法与仓储层完全一致，所有方法都是 `virtual` 的，可被子类重写。

### 使用示例

```csharp
public class UserService : BaseService<User>
{
    public async Task<User> GetActiveUserAsync(int id)
    {
        var user = await GetAsync(id);
        if (user == null || user.IsDeleted)
            return null;
        return user;
    }

    public async Task<List<User>> GetAdultsAsync()
    {
        return await GetListAsync(x => x.Age >= 18);
    }

    public override async Task<int> DeleteAsync(int id)
    {
        // 自定义删除逻辑（如记录日志）
        await LogAsync($"删除用户: {id}");
        return await base.DeleteAsync(id);
    }
}
```

## 6. 继承仓储方法

服务层直接继承所有仓储层方法：

### 查询方法

```csharp
public class UserService : BaseService<User>
{
    public async Task Usage()
    {
        // 查询单个
        var user = await GetAsync(1);
        var user = await GetAsync(x => x.Name == "张三");

        // 查询列表
        var users = await GetListAsync();
        var users = await GetListAsync(x => x.Status == 1);
        var users = await GetListAsync(new[] { 1, 2, 3 });

        // 获取总数
        long count = await GetCountAsync();
        long count = await GetCountAsync(x => x.Status == 1);

        // 判断是否存在
        bool exists = await AnyAsync(x => x.Email == "test@example.com");
        bool exists = await AnyAsync();

        // 分页
        var page = await GetPageAsync(1, 10);
    }
}
```

### 增删改方法

```csharp
public class UserService : BaseService<User>
{
    public async Task Usage()
    {
        // 插入
        var id = await InsertIdentityAsync(new User { Name = "张三" });
        await InsertAsync(new User { Name = "李四" });

        // 更新
        var user = await GetAsync(1);
        user.Name = "王五";
        await UpdateAsync(user);

        // 删除
        await DeleteAsync(1);
        await HardDeleteAsync(2);
    }
}
```

### DTO 方法

```csharp
public class UserService : BaseService<User>
{
    public async Task Usage()
    {
        // ========== 查询单个 DTO ==========
        // 根据主键获取 DTO
        var dto = await GetAsync<UserDto>(1);

        // 根据条件获取 DTO
        var dto = await GetAsync<UserDto>(x => x.Name == "张三");

        // 根据主键获取 DTO（包含导航属性）
        var dto = await GetLazyAsync<UserDto>(1);

        // 根据主键获取指定字段（SQL层面优化）
        var dto = await GetAsync<UserDto>(1, x => new UserDto { Id = x.Id, Name = x.Name });

        // 根据条件获取指定字段（SQL层面优化）
        var dto = await GetAsync<UserDto>(x => x.Status == 1, x => new UserDto { Id = x.Id, Name = x.Name });

        // ========== 查询 DTO 列表 ==========
        // 获取所有 DTO 列表
        var dtos = await GetListAsync<UserDto>();

        // 条件查询 DTO 列表
        var dtos = await GetListAsync<UserDto>(x => x.Status == 1);

        // 根据主键集合获取 DTO 列表
        var dtos = await GetListAsync<UserDto>(new[] { 1, 2, 3 });

        // 条件查询 DTO 列表（包含导航属性）
        var dtos = await GetListLazyAsync<UserDto>(x => x.Status == 1);

        // 获取指定字段列表（SQL层面优化）
        var dtos = await GetListAsync<UserDto>(x => new UserDto { Id = x.Id, Name = x.Name });

        // 条件查询指定字段列表（SQL层面优化）
        var dtos = await GetListAsync<UserDto>(x => x.Status == 1, x => new UserDto { Id = x.Id, Name = x.Name });

        // ========== 更新返回 DTO ==========
        var result = await UpdateAsync<ResponseDto>(new { Id = 1, Name = "新名称" });

        // ========== 分页查询 DTO ==========
        var page = await GetPageAsync<UserDto>(1, 10);
        var page2 = await GetPageAsync<UserDto>(1, 10, x => x.Status == 1);

        // 使用 BaseReqPage 分页对象
        var reqPage = new BaseReqPage { PageIndex = 1, PageSize = 10 };
        var page3 = await GetPageAsync<UserDto>(reqPage);
        var page4 = await GetPageAsync<UserDto>(reqPage, x => x.Status == 1);

        // 分页查询指定字段（SQL层面优化）
        var page5 = await GetPageAsync<UserDto>(
            1, 10,
            x => new UserDto { Id = x.Id, Name = x.Name },
            x => x.Status == 1
        );

        // 使用 BaseReqPage 进行分页查询指定字段
        var page6 = await GetPageAsync<UserDto>(
            reqPage,
            x => new UserDto { Id = x.Id, Name = x.Name },
            x => x.Status == 1
        );
    }
}
```

## 7. 服务扩展方法

### ServiceExtensions

```csharp
public static class ServiceExtensions
{
    public static ISelect<TEntity> Where<TEntity, TPrimaryKey>(
        this IBaseService<TEntity, TPrimaryKey> service,
        Expression<Func<TEntity, bool>> predicate)
        where TEntity : IBaseEntity, new()
    {
        return service.Repository.AsSelect().Where(predicate);
    }
}
```

### 使用示例

```csharp
var select = _userService.Where(x => x.Status == 1);
var users = await select.ToListAsync();
```

## 8. 服务层最佳实践

### 8.1 服务层职责

| 层级 | 职责 |
|------|------|
| 实体层 | 定义数据结构 |
| 仓储层 | 数据访问封装 |
| **服务层** | **业务逻辑编排、事务管理** |
| 控制器层 | HTTP 请求处理 |

### 8.2 事务边界

服务层是事务的边界，建议在服务层方法内处理事务：

```csharp
public class OrderService : BaseService<Order>
{
    public async Task CreateOrderAsync(CreateOrderDto dto)
    {
        // 所有操作在同一个事务中
        await Orm.TransactionAsync(async () =>
        {
            var order = new Order { OrderNo = dto.OrderNo };
            await InsertAsync(order);

            foreach (var item in dto.Items)
            {
                await _orderItemService.InsertAsync(new OrderItem
                {
                    OrderId = order.Id,
                    ProductId = item.ProductId,
                    Quantity = item.Quantity
                });
            }
        });
    }
}
```

### 8.3 服务方法设计

```csharp
public class UserService : BaseService<User>
{
    // ✅ 推荐：业务方法以 Async 结尾
    public async Task<User> GetActiveUserAsync(int id)
    {
        var user = await GetAsync(id);
        return user?.IsDeleted == false ? user : null;
    }

    // ✅ 推荐：支持链式调用
    public IBaseService<User> Active()
    {
        return Where(x => !x.IsDeleted);
    }

    // ✅ 推荐：复合操作在服务层
    public async Task<bool> RegisterAsync(RegisterDto dto)
    {
        if (await AnyAsync(x => x.Email == dto.Email))
            return false;

        var user = new User
        {
            Name = dto.Name,
            Email = dto.Email,
            PasswordHash = HashPassword(dto.Password)
        };

        await InsertAsync(user);
        return true;
    }
}
```
