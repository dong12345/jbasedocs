# 更新日志

所有重要的版本更新都会在此记录。

## v3.2.0

**发布日期**：2024年

### 新增功能

- 支持 `AuditEntity<TPrimaryKey, TUserKey>` 泛型审计实体，支持自定义主键和用户ID类型组合
- 新增 `BaseEntity<TPrimaryKey>` 泛型基类，支持任意主键类型
- 仓储层增加 DTO 批量更新并返回功能
- 分页查询支持 `BaseReqPage` 对象参数

### 改进优化

- 优化 DTO 映射性能，使用 IL 动态生成映射代码
- 改进审计字段自动检测逻辑
- 事务处理支持嵌套事务

### 依赖更新

- FreeSql 版本升级至 3.5.211
- 目标框架保持 netstandard2.1
