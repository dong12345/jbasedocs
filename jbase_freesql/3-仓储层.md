# 仓储层

仓储层位于 `JBase.FreeSql.Core.Repository` 命名空间，提供数据访问的核心能力。

## 1. 接口定义

### IBaseRepository

仓储接口，定义所有数据操作方法。

#### 泛型约束

| 接口 | 约束 | 说明 |
|------|------|------|
| `IBaseRepository<TEntity, TPrimaryKey>` | `where TEntity : IBaseEntity, new()` | 通用仓储 |
| `IBaseRepository<TEntity>` | `where TEntity : BaseEntity<int>, new()` | int 主键仓储 |
| `IBaseLongRepository<TEntity>` | `where TEntity : BaseEntity<long>, new()` | long 主键仓储 |
| `IBaseGuidRepository<TEntity>` | `where TEntity : BaseEntity<Guid>, new()` | Guid 主键仓储 |
| `IBaseStringRepository<TEntity>` | `where TEntity : BaseEntity<string>, new()` | string 主键仓储 |

#### 公开属性

| 属性 | 类型 | 说明 |
|------|------|------|
| IsAuditUpdate | bool | 是否是更新审计实体 |
| IsAuditDelete | bool | 是否是删除审计实体 |
| IsAuditInsert | bool | 是否是插入审计实体 |

## 2. 删除操作

### 根据主键删除

```csharp
// 同步
int count = _repository.Delete(1);

// 异步
int count = await _repository.DeleteAsync(1);
```

### 根据主键集合删除

```csharp
// 同步
int count = _repository.Delete(new[] { 1, 2, 3 });

// 异步
int count = await _repository.DeleteAsync(new[] { 1, 2, 3 });
```

### 根据条件删除

```csharp
// 同步
int count = _repository.Delete(x => x.Status == 0);

// 异步
int count = await _repository.DeleteAsync(x => x.Status == 0);
```

### 硬删除（强制物理删除）

```csharp
// 硬删除单个（同步）
int count = _repository.HardDelete(1);

// 硬删除单个（异步）
int count = await _repository.HardDeleteAsync(1);

// 硬删除多个（同步）
int count = _repository.HardDelete(new[] { 1, 2, 3 });

// 硬删除多个（异步）
int count = await _repository.HardDeleteAsync(new[] { 1, 2, 3 });

// 硬删除条件匹配项（同步）
int count = _repository.HardDelete(x => x.IsDeleted);

// 硬删除条件匹配项（异步）
int count = await _repository.HardDeleteAsync(x => x.IsDeleted);
```

### 删除行为说明

| 实体类型 | 删除方式 | 说明 |
|----------|----------|------|
| 实现 `IAuditDeleted` | 软删除 | 设置 `IsDeleted = true` |
| 未实现 | 硬删除 | 物理删除记录 |

## 3. 插入操作

### 插入实体

```csharp
var user = new User { Name = "张三", Email = "zhangsan@example.com" };

// 同步
int affected = _repository.Insert(user);

// 异步
int affected = await _repository.InsertAsync(user);
```

### 插入并返回自增主键

```csharp
// 同步
long id = _repository.InsertIdentity(user);

// 异步
long id = await _repository.InsertIdentityAsync(user);
```

### 批量插入实体

```csharp
var users = new List<User>
{
    new User { Name = "张三" },
    new User { Name = "李四" },
    new User { Name = "王五" }
};

int count = await _repository.InsertAsync(users);
```

### 插入 DTO

```csharp
var dto = new { Name = "赵六", Email = "zhaoliu@example.com" };

// 同步
int affected = _repository.Insert(dto);

// 异步
int affected = await _repository.InsertAsync(dto);
```

### 插入并返回 DTO

```csharp
var dto = new { Name = "孙七", Email = "sunqi@example.com" };

// 同步
var result = _repository.Insert<ResponseDto>(dto);

// 异步
var result = await _repository.InsertAsync<ResponseDto>(dto);
```

## 4. 更新操作

### 更新实体

```csharp
var user = await _repository.GetAsync(1);
user.Name = "张三（已修改）";

int affected = await _repository.UpdateAsync(user);
```

### 更新 DTO

```csharp
var dto = new { Id = 1, Name = "更新后的名称" };

int affected = await _repository.UpdateAsync(dto);
```

### 条件更新

```csharp
// 将所有 Status=0 的记录更新为 Status=1
var dto = new { Status = 1 };
int affected = await _repository.UpdateAsync(x => x.Status == 0, dto);
```

### 更新并返回 DTO

```csharp
var dto = new { Id = 1, Name = "新名称" };

// 单个
var result = await _repository.UpdateAsync<ResponseDto>(dto);

// 多个（条件匹配）
var results = await _repository.UpdateAsync<ResponseDto>(x => x.Status == 0, dto);
```

## 5. 查询操作

### 根据主键查询

```csharp
// 同步
var user = _repository.Get(1);

// 异步
var user = await _repository.GetAsync(1);
```

### 根据条件查询单个

```csharp
var user = await _repository.GetAsync(x => x.Name == "张三");
```

### 查询返回 DTO

#### 根据主键查询 DTO

```csharp
// 根据主键获取 DTO（同步）
var dto = _repository.Get<UserDto>(1);

// 根据主键获取 DTO（异步）
var dto = await _repository.GetAsync<UserDto>(1);

// 根据主键获取 DTO（包含导航属性，异步）
var dto = await _repository.GetLazyAsync<UserDto>(1);
```

#### 根据条件查询 DTO

```csharp
// 根据条件获取单个 DTO（同步）
var dto = _repository.Get<UserDto>(x => x.Name == "张三");

// 根据条件获取单个 DTO（异步）
var dto = await _repository.GetAsync<UserDto>(x => x.Name == "张三");

// 根据条件获取单个 DTO（包含导航属性，异步）
var dto = await _repository.GetLazyAsync<UserDto>(x => x.Status == 1);
```

#### 查询 DTO 列表

```csharp
// 根据主键集合获取 DTO 列表（同步）
var dtos = _repository.GetList<UserDto>(new[] { 1, 2, 3 });

// 根据主键集合获取 DTO 列表（异步）
var dtos = await _repository.GetListAsync<UserDto>(new[] { 1, 2, 3 });

// 获取所有 DTO 列表（同步）
var dtos = _repository.GetList<UserDto>();

// 获取所有 DTO 列表（异步）
var dtos = await _repository.GetListAsync<UserDto>();

// 条件查询 DTO 列表（同步）
var dtos = _repository.GetList<UserDto>(x => x.Status == 1);

// 条件查询 DTO 列表（异步）
var dtos = await _repository.GetListAsync<UserDto>(x => x.Status == 1);

// 条件查询 DTO 列表（包含导航属性，异步）
var dtos = await _repository.GetListLazyAsync<UserDto>(x => x.Status == 1);
```

### 指定字段查询（SQL层面优化）

使用 `selector` 表达式指定要查询的字段，只查询必要的字段，显著提升查询性能：

```csharp
// 根据主键获取指定字段（同步）
var dto = _repository.Get<UserDto>(1, x => new UserDto { Id = x.Id, Name = x.Name });

// 根据主键获取指定字段（异步）
var dto = await _repository.GetAsync<UserDto>(1, x => new UserDto { Id = x.Id, Name = x.Name });

// 根据条件获取指定字段（同步）
var dto = _repository.Get<UserDto>(x => x.Status == 1, x => new UserDto { Id = x.Id, Name = x.Name });

// 根据条件获取指定字段（异步）
var dto = await _repository.GetAsync<UserDto>(x => x.Status == 1, x => new UserDto { Id = x.Id, Name = x.Name });
```

生成的 SQL（只查询指定的字段）：
```sql
SELECT Id, Name FROM User WHERE Id = @id
```


#### 指定字段列表查询（SQL层面优化）

```csharp
// 获取指定字段列表（同步）
var dtos = _repository.GetList<UserDto>(x => new UserDto { Id = x.Id, Name = x.Name });

var dtos = await _repository.GetListAsync<UserDto>(x => new UserDto { Id = x.Id, Name = x.Name });

var dtos = await _repository.GetListAsync<UserDto>(x => x.Status == 1, x => new UserDto { Id = x.Id, Name = x.Name });
```

生成的 SQL：

## 6. 分页查询

### 基本分页

```csharp
// 同步
var page = _repository.GetPage(pageIndex: 1, pageSize: 10);

// 异步
var page = await _repository.GetPageAsync(1, 10);

// 带条件分页
var page = await _repository.GetPageAsync(1, 10, x => x.Status == 1);

// 排序分页
var page = await _repository.GetPageAsync(1, 10, x => x.Status == 1, x => x.CreatedDate, false);
```

### 使用分页对象

```csharp
// BaseReqPage 只包含分页基本信息，条件查询和排序作为额外参数传入
var reqPage = new BaseReqPage
{
    PageIndex = 1,
    PageSize = 10
};

// 基础用法
var page = await _repository.GetPageAsync(reqPage);

// 带条件查询
var page = await _repository.GetPageAsync(reqPage, x => x.Status == 1);

// 带条件查询和排序
var page = await _repository.GetPageAsync(reqPage, x => x.Status == 1, x => x.CreatedDate, false);

// 分页查询返回 DTO
var page = await _repository.GetPageAsync<UserDto>(reqPage, x => x.Status == 1);

// 分页查询返回 DTO 并指定字段（SQL层面优化）
var page = await _repository.GetPageAsync<UserDto>(
    reqPage,
    x => new UserDto { Id = x.Id, Name = x.Name },
    x => x.Status == 1
);
```

> **注意**：`BaseReqPage` 是一个简单的分页请求类，仅包含 `PageIndex` 和 `PageSize` 属性。查询条件 `Where`、排序字段 `Order` 和排序方向 `Asc` 需要作为额外参数传入对应的方法。

### 分页返回 DTO

```csharp
var page = await _repository.GetPageAsync<UserDto>(1, 10, x => x.Status == 1);
```

### 分页查询指定字段（SQL层面优化）

分页时只查询必要的字段，显著提升大表分页查询性能：

```csharp
// 使用 selector 只查询指定字段
var page = await _repository.GetPageAsync<UserDto>(
    1,                                          // 页码
    10,                                         // 每页大小
    x => new UserDto { Id = x.Id, Name = x.Name },  // 指定字段
    x => x.Status == 1                          // 查询条件（可选）
);

// 支持排序的分页查询
var page = await _repository.GetPageAsync<UserDto>(
    1,
    10,
    x => new UserDto { Id = x.Id, Name = x.Name, CreatedDate = x.CreatedDate },
    x => x.Status == 1,
    x => x.CreatedDate,                        // 排序字段
    false                                       // 降序
);

// 使用 BaseReqPage 对象
var reqPage = new BaseReqPage { PageIndex = 1, PageSize = 10 };
var page = await _repository.GetPageAsync<UserDto>(
    reqPage,
    x => new UserDto { Id = x.Id, Name = x.Name },
    x => x.Status == 1
);
```

生成的 SQL（高效分页）：
```sql
SELECT Id, Name FROM User WHERE Status = 1 LIMIT 10 OFFSET 0
```

### PageOut 分页结果

```csharp
var page = await _repository.GetPageAsync<UserDto>(1, 10);

Console.WriteLine($"总记录数: {page.Total}");
Console.WriteLine($"总页数: {page.TotalPages}");
Console.WriteLine($"当前页: {page.PageIndex}");
Console.WriteLine($"每页条数: {page.PageSize}");
foreach (var item in page.Result)
{
    Console.WriteLine(item.Name);
}
```

## 7. 复杂查询

### 获取 ISelect 进行复杂查询

```csharp
var select = _repository.AsSelect();

// 链式调用
var results = await _repository.AsSelect()
    .Where(x => x.Age > 20)
    .WhereIf(true, x => x.Name.Contains("张"))
    .OrderByDescending(x => x.CreatedDate)
    .Select(x => new
    {
        x.Id,
        x.Name,
        x.Email
    })
    .ToListAsync();
```

## 8. 仓储实现类

### BaseRepository 属性

| 属性 | 类型 | 说明 |
|------|------|------|
| Orm | IFreeSql | FreeSql ORM 实例 |
| User | IUser | 当前登录用户 |
| IsAuditUpdate | bool | 是否启用更新审计 |
| IsAuditDelete | bool | 是否启用删除审计 |
| IsAuditInsert | bool | 是否启用插入审计 |

### 自动检测行为

`BaseRepository` 在构造时会自动检测实体类型是否实现了审计接口：

```csharp
if (typeof(IAuditUpdated<>).IsAssignableFrom(typeof(TEntity)))
    IsAuditUpdate = true;

if (typeof(IAuditDeleted).IsAssignableFrom(typeof(TEntity)))
    IsAuditDelete = true;

if (typeof(IAuditCreated<>).IsAssignableFrom(typeof(TEntity)))
    IsAuditInsert = true;
```

> **注意**：代码使用 `IsAssignableFrom` 方法进行接口检测，这比使用 `GetProperty` 更加可靠，能够正确识别继承树中实现的接口。

```csharp
var select = _repository.Where(x => x.Status == 1);

```

## 10. DTO 映射

仓储层内置了高性能的 DTO 映射功能：

```csharp
// 使用 MapperGenerator 内部映射
// 支持同名属性自动映射
// 支持可空类型转换
// 支持数值类型隐式转换

var dto = await _repository.GetAsync<UserDto>(1);
```

映射特性：
- 使用 IL 动态生成映射代码
- 首次调用时生成，之后缓存复用
- 性能接近直接调用
